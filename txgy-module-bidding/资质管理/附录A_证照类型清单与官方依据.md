## 一、核心结论：设计漏掉的 6 类证照

| # | 漏掉的证照 | 严重程度 | 说明 |
| --- | --- | --- | --- |
| 1 | **防水防腐保温工程专业承包资质** | 🔴 严重 | 这是"防腐保温"企业**最核心的主业资质**，设计方案通篇只写了"市政公用工程施工总承包"，等于漏了主赛道 |
| 2 | **外省企业进陕承揽业务登记**（入陕备案） | 🔴 严重 | 若企业注册地不在陕西，这是**在陕投标的前置门槛**，无此登记不得承揽业务；属电子登记表，无纸质证 |
| 3 | **排污许可证** | 🟠 重要 | 热力生产和供应属发证行业，燃煤锅炉未取得排污许可证排放污染物**已有行政处罚典型案例** |
| 4 | **特种设备使用登记证** | 🟠 重要 | 锅炉按台（套）登记，与"生产许可证"是两回事：前者是**用**设备的证，后者是**装/改/修**设备的证 |
| 5 | **建筑机电安装工程专业承包资质** | 🟡 建议 | 换热站设备、线路、管道安装直接对应此资质 |
| 6 | **安全生产考核合格证书（A/B/C 三类人员）** | 🟡 建议 | 设计方案只笼统写"安全员证"，实际陕西是 A/B/C 三类分证，且**与安全生产许可证强绑定**（人员不足会触发安许证预警） |

## 二、企业资质类（陕西口径）

### 2.1 供热经营许可证 ✅

| 项 | 内容 |
| --- | --- |
| 性质 | 核心中的核心，无此证不得从事供热服务；不得转让、出借、出租 |
| 陕西实施机关 | **市城管局**（西安市为"城市管理和综合执法局"，行政审批处）；高新区由"高新区城市管理和综合执法局燃气热力管理部"办理 |
| 发证层级 | ⚠️ 分级发证。《〈西安市集中供热条例〉实施细则》第二条明确"市、区（县）和开发区管委会分别对各自发证的集中供热企业"进行考核，说明市/区县/开发区各自发证 |
| 法定办结时限 | 20 个工作日 |
| 承诺办结时限 | 10 个工作日（一般流程）/ 6 个工作日（部分区县）/ 0 工作日（告知承诺制，高新区） |
| 到现场次数 | 一般流程 1 次；告知承诺制 0 次（全程网办） |
| 办理入口 | 陕西政务服务网（西安市）"集中供热经营许可证核发" |
| 法规依据 | 《西安市集中供热条例》（2007-12-26 西安市人大通过，2008-04-02 陕西省人大常委会批准，2018-04-01 陕西省十三届人大常委会第二次会议修订通过，2018-07-01 施行）+《〈西安市集中供热条例〉实施细则》（2019-05-27 西安市政府办公厅印发） |
| **有效期** | ⛔ **多源矛盾，未确认陕西口径**。用户提供的《证书资格业务项目.docx》称"通常 3-5 年"；山东淄川区规范性文件称"有效期为五年"。**2026-09-07 再次核实：陕西本地有效期仍无官方条文**——注意易混点：西安《集中供热条例》实施细则中"有效期 5 年"指**文件本身**而非许可证；供热特许经营协议"30 年"是特许经营权而非许可证年限。需以许可证正本载明日期为准 |
| 经营要求 | 需实行热源、管网、换热站经营管理一体化，直供到户 |
| **设计影响** | `validity_type` 字段必需（证书上会注明供热区域和面积，且有效期不确定）；预警天数应设为最高档（建议 180 天） |

### 2.2 建筑业企业资质证书 ⛔（等级口径存在政策过渡期矛盾）

| 项 | 内容 |
| --- | --- |

| 现行等级 | 施工总承包：**特级、一级、二级、三级**；专业承包：一级、二级、三级（各类别不同） |

| 改革内容 | ✅ 官方原文：施工资质分为**综合资质、施工总承包资质、专业承包资质、专业作业资质**四类；10 类施工总承包特级资质调整为施工综合资质（不分等级，可承担各行业各等级施工总承包业务）；保留 12 类施工总承包资质；36 类专业承包资质整合为 18 类；施工劳务企业资质改为专业作业资质，**审批制改备案制**；综合资质和专业作业资质不分等级，施工总承包资质、专业承包资质等级**原则上压减为甲、乙两级**（部分专业承包资质不分等级）；施工总承包甲级资质在本行业内承揽业务规模不受限制；设置 1 年过渡期，到期后按新旧对应关系**简单换证，不再重新核定** |
| ⛔ **落地状态矛盾** | 部分来源称 2026 年 3 月起取消三级、统一甲乙两级、新办企业可直接申请乙级；另有来源称"甲乙级划分仅为改革规划，**截至 2026 年 4 月新资质标准尚未正式出台**，现行审批中施工总承包三级资质依然存在，且是新手企业新办的核心选择"。住建部官网 2026 年仍在按批次发布"建筑业企业资质核准名单"，现行标准仍是建市〔2014〕159号 |
| **设计影响** | `level` 字段**必须用 varchar 自由文本，不能用枚举**，且需同时容纳"特级/一级/二级/三级"和"综合/甲级/乙级"两套口径；建议增加 `level_standard` 字段标注该等级所属标准版本（2014版 / 改革后），否则资质升级换证时数据会错乱 |

### 2.7 特种设备生产许可证（锅炉安装、改造、修理） ✅

| 项 | 内容 |
| --- | --- |
| 证书名称 | 《中华人民共和国特种设备生产许可证》/ Production License of Special Equipment |
| 编号格式 | ✅ `TS3` + 数字，例：`TS3161025B2028`（陕西煤化机电安装有限公司，锅炉安装含修理、改造 B 级） |
| 许可分级 | ✅ **A 级**：额定工作压力 ≥ 3.8MPa 的锅炉；**B 级**：额定工作压力 < 3.8MPa 的锅炉 |
| 法规依据 | 《特种设备安全法》（2013 年主席令第 4 号）第十八条；《特种设备生产和充装单位许可规则》TSG 07-2019 |
| 办理入口 | ✅ 国家市场监督管理总局政务服务平台 `zwfw.samr.gov.cn` → 特种设备生产单位许可；陕西省内可经西咸新区市场监督管理局等属地入口 |
| 收费 | ✅ 不收费 |
| **有效期** | ✅ **已核实：4 年**（2026-09-07 官网核实）。依据市场监管总局《特种设备生产和充装单位许可规则》TSG 07-2019 第 1.5 条原文"其有效期均为 4 年"；有效期届满需换证，期满前 6 个月提出申请（江西等多地办事指南同口径）。**设计影响：录入按 4 年校验，warn_days 建议 180（对应提前 6 个月换证）** |
| 企业条件 | 独立法人资格 + 合规营业执照；固定办公场所、资料档案室、仪器设备室、仓库；符合 TSG 07-2019 的质量保证体系（质量保证手册、焊接工艺评定）；技术负责人具备工程师以上职称 + 3 年以上锅炉安装技术管理经历；无损检测人员至少 1 名持 RT 或 UT Ⅱ级证书（分包无损检测时仅需设责任人员） |
| 申请材料 | 申请书中的"申请许可项目表"（法定代表人签字 + 公章，扫描提交）；原许可证（仅增项、改变许可级别或换证且无法在线核验时）；分公司单独申请需法人书面授权文件扫描件 |

### 2.8 特种设备使用登记证 ✅【v1.1/v2.0 遗漏】

| 项 | 内容 |
| --- | --- |
| 与生产许可证的区别 | **生产许可证**=可以安装/改造/修理特种设备的资格；**使用登记证**=自己在用某台设备的合法登记。两者不可互相替代 |
| 登记单位 | ✅ 锅炉、压力容器（气瓶除外）、电梯、起重机械、客运索道、大型游乐设施、场（厂）内专用机动车辆应当**按台（套）**向登记机关办理使用登记；车用气瓶以车为单位 |
| 陕西监管依据 | ✅《陕西省特种设备安全监察条例》（2009-05-27 陕西省第十一届人大常委会第八次会议通过，2009-10-01 施行；2014-11-27 陕西省第十二届人大常委会第十四次会议修正，修正版自公布之日起施行） |
| 陕西监管分工 | ✅ 省、市、县三级特种设备安全监督管理部门分级负责安全监察及高耗能特种设备节能监管。**例外**：房屋建筑工地和市政工程工地用起重机械、场（厂）内专用机动车辆由**建设行政主管部门**监管（不是市场监管部门） |

## 四、项目承包等级类

- 防水防腐保温工程专业承包资质 → 一级、二级
- 市政公用工程施工总承包资质 → 特级、一级、二级、三级（改革后甲、乙）
- 建筑机电安装工程专业承包资质 → 一级、二级、三级
- 特种设备生产许可证（锅炉） → A 级、B 级

1. v2.0 方案中把"项目承包等级"设为一级分类是**语义错误**——它会和"企业资质"分类产生大量重叠（同一张市政公用工程施工总承包二级证书，既属企业资质又属承包等级）。
2. 建议改为：**取消"项目承包等级"一级分类**，将等级信息作为 `bid_certificate.level` 字段承载；若组长坚持保留该分类，应将其重定义为"**承包工程范围登记表**"（记录某资质等级对应的可承接业务范围与合同额上限），而非证照本身。
3. `level` 字段必须支持两套口径并存（见 §2.2 矛盾说明），建议配套字典表 `bid_cert_level_dict` 维护"资质类别 → 可用等级列表"，前端做级联选择而非自由输入。
