## 1. 需求与范围

**组长原始需求**：管理员登录后的电子证照管理库和模板管理库的设计。电子证照包含企业资质、功能证书、项目承包等级等，证照的照片或原文件都要存进去。

| # | 延伸需求 | 状态 |
| --- | --- | --- |
| E1 | 证照类型可选，复用官方清单 27 项（发证机关+依据），禁止编造 | ✅ 前端 `certificate-types.ts` |
| E2 | 空白表单，选类型自动回填分类/持有人类型/发证机关/等级 | ✅ `data.ts` 自动回填 |
| E3 | 模板→选择→填内容→证照自动更新闭环 | 🔧 开发中 |
| E4 | 同一证照可被多份标书引用，避免重复录入 | 🔧 开发中 |
| E5 | 过期/失效证照拦截，不能拿来投标 | 🔧 开发中 |
| E6 | 模板有内容字段 `bid_template.content` | ✅ 已建表 |
| E7 | 建标书编制记录表 `bid_document` | ✅ 已建表 |
| E8 | 反查：证照被哪些标书引用 | 🔧 开发中 |

**硬约束**：标书编制模块对 `bid_certificate` **只允许 SELECT**（校验存在、取名称快照），禁止 insert/update/delete；证照增改删只走电子证照管理库接口。

## 4. 证照分类（陕西口径，评审建议）

```
企业行政许可类：供热经营许可证[180] / 安全生产许可证[90，3年，动态核查ABC三级预警] / 排污许可证[≥90，法定下限60]
建筑业企业资质类：防水防腐保温工程专业承包★主业(一级/二级) / 市政公用工程施工总承包 / 建筑机电安装工程专业承包 / 其他
特种设备许可类：特种设备生产许可证[4年，180] / 特种设备使用登记证[按台套，量大]
功能证书类：管理体系认证(ISO9001/14001/45001)[最长3年，年审独立管理] / 计量认证CMA / 信用等级证书[issuer必填]
人员证书类：安管人员考核合格证A/B/C(C分C1/C2/C3) / 特种作业人员证 / 注册建造师(一级/二级)[注册3年，电子化] / 特种设备作业人员证G1/G2/G3[4年，届满前1个月复审] / 现场管理人员岗位证
跨区域经营备案类：外省企业进陕承揽业务登记[电子登记表，分企业入库+项目备案两阶段]
```

**与组长原话的差异点**：
1. 「项目承包等级」非独立证照 = 资质证书上的等级标注（特/一/二/三级，改革后综合/甲/乙），取消独立分类，由 `level` + `level_standard` 字段承载（官方核实）。
2. 遗漏主业资质：**防水防腐保温工程专业承包**（一级/二级，原三级取消）必须入分类。
3. 「模板管理库」语义 = **标书模板**（技术标/商务标 Word）；证照版式模板不在本期。

官方查验平台白名单（防假冒，禁止自由填 URL，见附录 A §5.3）：四库一平台、全国工程质量安全监管信息平台、全国特种设备公示信息查询平台、全国排污许可证管理信息平台、全国认证认可信息公共服务平台、中国建造师网、陕西住建电子证书查询入口。

## 5. 模板→填写→证照自动入库闭环

```
模板管理库 bid_template ──配置所需证照清单──→ bid_template_cert（模板要求哪些证照/必填?）
       │ 用户选择模板
       ▼
标书编制 bid_document：选模板→自动带出证照清单→逐项从证照库【只读】引用→
过期/失效/作废证照拦截标红→填正文 content→保存时写引用明细
       ▼
bid_document_cert（document_id + certificate_id + 名称快照）→ 证照侧反查"被 N 份标书引用"
```

| 场景 | 处理 |
| --- | --- |
| 清单项在证照库有有效证照 | 下拉选择引用（只读），保存写 `bid_document_cert` |
| 清单项证照库无记录 | 提示"去电子证照管理库先录入"，不自动插入（硬约束） |
| 清单项证照已过期/失效/作废 | 禁止引用，标红显示剩余天数/失效原因 |
| 证照被多份标书引用 | 正常（复用去重 E4），详情显示"被 N 份标书引用"（E8） |
| 证照信息变更 | 标书侧自动联动（单一数据源），无需改标书 |

## 6. 到期提醒与状态计算

**状态计算（11 行判定，按序）**：

| 顺序 | 条件 | status | 展示 |
| --- | --- | --- | --- |
| 1 | status=3（人工作废） | 3 | ⚫ 已作废 |
| 2 | risk_flag=3（失效预警，ABC全0） | 4 | ⛔ 已失效 |
| 3 | risk_flag=2（红色预警，任一类为0） | 4 | ⛔ 已失效 |
| 4 | annual_review_date < today | 4 | ⛔ 已失效 |
| 5 | expire_date < today | 2 | 🔴 已过期 |
| 6 | expire_date <= today + warn_days | 1 | 🟡 即将到期(剩N天) |
| 7 | annual_review_date <= today + 30 | 1 | 🟡 年审临近 |
| 8 | validity_type=1（长期有效） | 0 | 🟢 长期有效 |
| 9 | validity_type=3（待确认） | 0 | ⚪ 待确认 |
| 10 | risk_flag=1（黄）或 4（异常标注） | 0 | 🟢 有效⚠️角标 |
| 11 | 其他 | 0 | 🟢 有效 |

**预警天数：三级取值（证照→分类→全局默认90）+ 法定下限保护（保存时拦截）**：

| 证照 | 法定时限 | 下限 | 逾期后果 |
| --- | --- | --- | --- |
| 排污许可证 | 届满 60 日前申请延续 | 60 | 依法注销，原证自动作废 |
| 特种设备作业人员证 | 4 年，届满前 1 个月复审 | 60 | 逾期未复审自动失效 |
| 特种设备生产许可证 | 4 年，期满前 6 个月换证 | 180 | 需重新申请 |
| 安全生产许可证 | 3 年，期满前 3 个月延期 | 90 | 过期无法投标，擅自施工罚 10-50 万 |
| 一级建造师注册证 | 3 年，届满前 30 日延续 | 90 | 注册失效 |

定时任务（📋）：状态全量刷新（每日 1:00）、到期/失效站内信提醒（每日 9:00，Redis 去重）、年审独立提醒、安许证 ABC 人员达标校验（每周一）。

## 7. 附件存储与文件安全

- ✅ 已落地：`bid_certificate.file_url` + `file_name` 单字段，走 `/infra/file/upload`。
- ✅ 表已建：附件子表 `bid_certificate_file`（biz_type 区分证照/模板/业绩；file_type 照片/扫描件/原件/年审记录；file_hash SHA256 防篡改；sort=0 主附件）——功能 🔧。
- ⚠️ 当前限制：单字段只能存一份附件，不满足"照片**和**原文件都要存"；公开 URL 无鉴权——待附件子表功能落地解决。
- **约束**：单对象附件 ≤20；单文件 ≤20MB；扩展名白名单**必须含 `ofd`**（陕西住建电子资质证书为 OFD 格式）；证照保存附件 ≥1（错误码 `CERTIFICATE_FILE_REQUIRED`）；下载走 bid-server 受控接口（权限+租户+审计日志）。
