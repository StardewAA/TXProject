## 1. 当前目标（进行中）
实现爬虫**下载器**：栏目定时轮询（间隔 ≥2 分钟，防封）→ 列表解析 → 条目建任务 → 抓取详情/全文 → 解析 → ingest 落库待审。解析器插件与测试接口已完成（见 §4）。

## 2. 两个站点机制（全部实测确认）
### 秦源 qyzb.shccmg.com
- 栏目目录（壳页）：`https://qyzb.shccmg.com/cms/default/webfile/{cat}/index.html`，cat∈1ywgg/2ywgg/3ywgg/zbgs/zbgg/qtgg；
- **数据接口（列表+全文 JSON）**：POST `https://qyzb.shccmg.com/cms/api/dynamicData/queryContentPage`，JSON body `{pageNo,pageSize:10,dto:{siteId:'725',categoryId:'X'}}`；响应 `{code:0,res:{rows:[{title,url(栏目相对),text(全文HTML),publishDate,categoryName}],pageNo,hasNext}}`；
- 栏目→categoryId：**203=1ywgg / 204=2ywgg / 205=3ywgg / 321=zbgs / 322=zbgg / 323=qtgg**；详情 URL 绝对化=`https://qyzb.shccmg.com/cms/default/webfile`+row.url；rows.text 为全文（可直存或详情页再解析）；
- 对应解析器：`QYZB_JSON`（列表 JSON）与 `QYZB_SHCCMG`（详情 HTML，view-source 自动还原）。

### 国信 gx.e-bidding.org
- 列表（服务端 HTML）：GET `https://gx.e-bidding.org/sxyczscms/category/bulletinListNew.html?dates=300&categoryId=2&tenderMethod=01&tabName=依法招标&page=N`（翻页改 page）；列表体 `ul.newslist > li > a[href=/sdny_bulletin/{date}/{id}.html]`；
- 详情：`/sdny_bulletin/{date}/{id}.html` 内 pdf.js iframe → PDF 直链 `…/openFileById?fileType=2&id={uuid}`（file 参数双重 URL 编码）；正文在 PDF；
- 对应解析器：`GX_E_BIDDING`（列表/详情 PDF 直链）与 `PDF_TEXT_GENERIC`（PDF→文本公告字段，标题断行拼接/双编号/落款日期已校准）。
