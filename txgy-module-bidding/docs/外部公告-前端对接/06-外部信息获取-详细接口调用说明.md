# 06-外部信息获取-详细接口调用说明（curl/TS 示例）

> 用途：给前端一份"照着调就能通"的接口调用说明。后端 URL/权限码与旧爬虫模块一致（见 05），本文件给每个端点的完整请求/响应示例。
> 环境：服务 48110（本地）/ 网关 48080（容器）；管理端需登录 token + tenant-id 头。

## 0. 通用约定

```bash
# 登录拿 token（走 system 服务）
curl -X POST http://127.0.0.1:48087/admin-api/system/auth/login \
  -H "Content-Type: application/json" -H "tenant-id: 1" \
  -d '{"username":"admin","password":"admin123","captchaVerification":""}'
# → data.accessToken = <TOKEN>

# 之后所有 bidding 接口：
curl http://127.0.0.1:48110/admin-api/bidding/... \
  -H "Authorization: Bearer <TOKEN>" -H "tenant-id: 1"
```

## 1. 信息获取源（原采集源）

### 1.1 分页查询 GET /bidding/crawl-source/page
```bash
curl "http://127.0.0.1:48110/admin-api/bidding/crawl-source/page?pageNo=1&pageSize=10&sourceCode=QYZB" \
  -H "Authorization: Bearer <TOKEN>" -H "tenant-id: 1"
```
响应 data：
```json
{
  "list": [{
    "id": 1790000000000000001,
    "sourceCode": "QYZB",
    "sourceName": "秦源电子招投标",
    "baseUrl": "https://qyzb.shccmg.com",
    "fetchType": "API",                 // 本轮新增：API=接口直取 / CRAWLER=爬虫
    "apiConfigJson": "{...}",          // 本轮新增：API 源配置 JSON 字符串
    "entryUrlsJson": "[{\"name\":\"招标公告\",...}]",

    "parserCodeDefault": "QYZB_JSON",

```

### 1.2 新建 POST /bidding/crawl-source/create
```bash
curl -X POST http://127.0.0.1:48110/admin-api/bidding/crawl-source/create \
  -H "Authorization: Bearer <TOKEN>" -H "tenant-id: 1" -H "Content-Type: application/json" \
  -d '{
    "sourceCode": "SD-YANTAI",
    "sourceName": "山东公共数据开放-烟台招投标",
    "baseUrl": "https://data.sd.gov.cn",
    "fetchType": "API",
    "apiConfigJson": "{\"method\":\"GET\",\"url\":\"https://data.sd.gov.cn/gateway/api/1/kfsjjk444\",
       \"headers\":{\"X-Client-Id\":\"xxx\",\"X-Timestamp\":\"{ts}\",\"X-Nonce\":\"{nonce}\",\"X-Signature\":\"{sign}\",
       \"pageParam\":\"page\",\"sizeParam\":\"size\",\"pageSize\":10,\"rowsPath\":\"data\",
       \"mapping\":{\"title\":\"notice_name\",\"url\":\"url\",\"date\":\"publish_time\"}}",
    "channelCode": "GENERIC",
    "fetchIntervalSeconds": 3600,
    "enabled": false
  }'
```
- 说明：fetchType 缺省 CRAWLER；fetchType=API 时 apiConfigJson 必填（后端校验 JSON 对象）；
- 动态签名头（X-Signature）需代码适配器（当前仅静态头）——见 05 契约；
- sourceCode 创建后不可改；enabled=true 才进入 /go 外链白名单。

### 1.3 更新 PUT /bidding/crawl-source/update（body 同 create + id）
```bash
curl -X PUT http://127.0.0.1:48110/admin-api/bidding/crawl-source/update \
  -H "Authorization: Bearer <TOKEN>" -H "tenant-id: 1" -H "Content-Type: application/json" \
  -d '{"id":1790000000000000001,"sourceCode":"QYZB","sourceName":"秦源电子招投标",...}'
```

### 1.4 启用/停用 POST /bidding/crawl-source/enabled
```bash
curl -X POST "http://127.0.0.1:48110/admin-api/bidding/crawl-source/enabled?id=1790000000000000001&enabled=true" \
  -H "Authorization: Bearer <TOKEN>" -H "tenant-id: 1"
```
- 停用守卫：源被 ACTIVE 公告引用或存在未终态任务时拒绝（先处理数据再停用）。

### 1.5 删除 DELETE /bidding/crawl-source/delete?id=
```bash
curl -X DELETE "http://127.0.0.1:48110/admin-api/bidding/crawl-source/delete?id=..." \
  -H "Authorization: Bearer <TOKEN>" -H "tenant-id: 1"
```

### 1.6 立即采集 POST /bidding/crawl-source/run?sourceCode=
```bash
curl -X POST "http://127.0.0.1:48110/admin-api/bidding/crawl-source/run?sourceCode=QYZB" \
  -H "Authorization: Bearer <TOKEN>" -H "tenant-id: 1"
```
响应（同步模式，默认）：
```json
{
  "code": 0,
  "data": {
    "sourceCode": "QYZB",
    "startedAt": "2026-09-09T10:00:00",
    "finishedAt": "2026-09-09T10:02:49",
    "totalIngested": 86,
    "totalFailed": 0,
    "categories": [
      {"name":"招标公告","fetched":66,"ingested":66,"failed":0},
      {"name":"采购公告","fetched":12,"ingested":12,"failed":0},
      {"name":"变更公告","fetched":8,"ingested":8,"failed":0}
    ]
  }
}
```
- 首跑自动全量（60 天窗口可配），之后增量（见 04 契约）；
- 异步模式（后端配置开启后）：响应 totalIngested=已入队数，job 保持 RUNNING，落库进度看批次/任务（见 05 第六节）。

## 2. 信息获取任务

### 2.1 分页 GET /bidding/crawl-task/page
```bash
curl "http://127.0.0.1:48110/admin-api/bidding/crawl-task/page?pageNo=1&pageSize=10&jobId=1790000000000000002&status=PENDING" \
  -H "Authorization: Bearer <TOKEN>" -H "tenant-id: 1"
```
响应 data.list[]：
```json
{
  "id": 9000000000000000001,
  "jobId": 1790000000000000002,
  "sourceCode": "QYZB",
  "url": "https://qyzb.shccmg.com/cms/default/webfile/3ywgg/20260908/x.html",
  "parserCode": "QYZB_JSON",
  "status": "PENDING",        // PENDING/RUNNING/SUCCESS/FAILED/SKIPPED
  "attempt": 0,
  "payloadJson": "{\"title\":\"...\",\"url\":\"...\",\"rawFileUrl\":\"http://file/...\"}",  // 本轮新增
  "createTime": "2026-09-09T10:00:00"
}
```
- 筛选项：jobId/sourceCode/status/channelCode/url(模糊)/beginTime/endTime。
