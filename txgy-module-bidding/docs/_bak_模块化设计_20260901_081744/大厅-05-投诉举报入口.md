# 大厅-05 投诉举报入口（公共服务大厅）

## 定位
公众投诉举报提交、进度查询、材料补正的统一入口（不处理，只转交监管）。

## 依据
- 《招标投标法实施条例》第 60 条：投诉渠道与时限。
- 《陕西省实施〈招标投标法〉办法》：省内投诉程序。
- 数据规范 V2.0 表122 投诉信息数据集（提交字段子集）。

## 功能

| 功能 | 说明 |
|---|---|
| 投诉举报提交 | 公众匿名填写、上传证据附件 |
| 进度查询 | 凭编号查询处理进度与结果 |
| 材料补正 | 按监管要求补充材料 |
| 受理告知 | 显示是否受理及理由（监管回推） |

## 视图

功能视图：公众=提交/查进度/补正；监管=接收方。
流程视图：提交 → 登记生成编号 → 转监管投诉模块 → 进度回推 → 公众查询。

## 接口

- REST：POST /admin-api/bidding/hall/compent/submit（@PermitAll）；GET /compent/progress（@PermitAll）。
- 跨模块 API：ComplaintEntryApi.submit(ComplaintSubmitReqVO)；ComplaintEntryApi.updateProgress(监管回推)。
