# 监管-05 专家库监管（监管系统）

## 定位
评标专家入库审核、信息维护、抽取监督与履职信用。

## 依据
- 《招标投标法实施条例》第 46、48 条：专家库随机抽取、回避。
- 《陕西省实施〈招标投标法〉办法》《陕西省公共资源交易平台管理办法》。
- 数据规范 V2.0 表113~119 专家信息与信用数据集。

## 功能

| 功能 | 说明 |
|---|---|
| 入库审核 | 专家申请、资格审核、入库/退回 |
| 信息维护 | 类别、专业、单位等变更审核 |
| 抽取监督 | 接收并留存企业后台的专家抽取记录 |
| 履职与信用 | 出勤、违规、奖惩、限制行为登记 |

## 项目框架落点

## 视图

功能视图：监督人员=审核/维护/登记信用；专家本人=申请/维护联系方式；招标人（评标模块）=抽取与查询。
流程视图：申请 → 审核入库 → 评标模块随机抽取（记录回传）→ 评审 → 履职回填 → 违规记信用 → 供下次抽取核验。

## 接口

- REST：POST /admin-api/bidding/sup/expert/audit（审核）；GET /expert/page。
- 跨模块 API：ExpertApi.listByCondition(条件)；ExpertApi.checkCredit(expertCode)；ExpertApi.receiveDrawRecord(抽取记录)。抽取前名单保密：接口只按条件返回候选，不返回名单。
