# 05 接口设计文档（详细）

> 约定：接口编号 BID-{系统}-{模块}-{序号}；报文 JSON，字段名用《表设计2》英文名称；字段的七要素以表设计2对应数据集为准（映射见 02 文件）。鉴权：企业后台/监管系统接口要求登录令牌；大厅公开接口匿名。所有写接口幂等（幂等键=业务编号+data_timestamp）。错误统一返回：错误码+中文说明。**本文件只设计接口，不含代码。**

## 一、公共规则

1. 公开级别裁剪：接口出参必须按调用方公开级别返回字段子集；社会公开字段（可入大厅/ES）、政务公开字段（企业后台↔监管）、模块内部字段（不出模块）。
2. 时间：所有业务时间字段 varchar(14)，格式 yyyyMMddHHmmss。
3. 分页：列表接口统一 pageNo/pageSize，返回 total。
4. 状态锁定：跨阶段状态由状态机控制（各模块文件已定义），接口只做校验，锁定状态返回"操作不允许（当前阶段）"。

## 二、跨系统三大流转接口（字段级）

### 2.1 备案推送（企业后台 → 监管-01）

| 项 | 内容 |
|---|---|
| 接口 | BID-ENT-REG-01 备案信息提交 |
| 方向 | 企业后台（项目登记/公告与文件/中标与合同）→ 监管系统 |
| 入参 | 备案类型、项目编号、招标项目编号、统一交易标识码、招标方式、组织形式、监督部门名称/代码、提交时间、data_timestamp、附件列表 |
| 出参 | 备案受理号、受理状态、受理时间 |
| 规则 | 政务公开字段；幂等键=备案类型+项目编号；受理状态后续由监管回推 |

### 2.2 公开同步（企业后台/监管 → 大厅 ES）

| 项 | 内容 |
|---|---|
| 接口 | BID-SUP-GATHER-02 公开信息同步 |
| 方向 | 企业后台（公告/公示/结果）、监管（信用公示）→ 监管-06 → ES |
| 入参 | 文档类型（公告/公示/结果/信用/合同公开）、业务编号、标题、内容、类型代码、地区、行业、发布时间、截止时间、**仅社会公开字段** |
| 出参 | 同步任务编号、状态 |
| 规则 | 同步服务做字段白名单校验；失败重试 3 次后转人工；更正/撤销以追加文档处理 |

### 2.3 投诉转办（大厅 → 监管-02）

| 项 | 内容 |
|---|---|
| 接口 | BID-HALL-COMP-01 投诉举报提交 |
| 方向 | 公共服务大厅 → 监管系统 |
| 入参 | 投诉内容、被投诉主体名称/代码、项目编号（选填）、联系方式、附件列表、提交时间 |
| 出参 | 投诉编号、受理状态（待受理） |
| 规则 | 匿名可提交；监管 3 个工作日内回推受理结果；大厅凭投诉编号查询进度 |

## 四、错误码约定（设计层）

| 码 | 含义 |
|---|---|
| BID-1001 | 参数校验失败（值域/必填/格式，按表设计2数据集） |
| BID-1002 | 当前阶段不允许该操作（状态锁定） |
| BID-1003 | 无权限/公开级别不允许 |
| BID-1004 | 重复提交（幂等命中，返回原结果） |
| BID-1005 | 数据不存在 |
| BID-1006 | 时限不满足（20 日/15 日/3 日等，附缺失天数） |
| BID-1007 | 附件校验失败（哈希不一致/未签名） |
| BID-1008 | ES 服务不可用（仅大厅检索返回） |
