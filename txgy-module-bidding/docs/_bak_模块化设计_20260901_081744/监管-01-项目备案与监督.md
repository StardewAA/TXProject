# 监管-01 项目备案与监督（监管系统）

## 定位
监督部门在线接收、审查依法必招项目的登记、方案、公告备案与定标后 15 日书面报告。

## 依据
- 《招标投标法》第 47 条：15 日内提交书面报告。
- 《电子招标投标办法》第 3 条：行政监督平台定位。
- 《陕西省实施〈招标投标法〉办法》《陕西省公共资源交易平台管理办法》。
- 数据规范 V2.0 表120 行政监管事项信息、表126 交易方式代码。

## 功能

| 功能 | 说明 |
|---|---|
| 备案接收 | 接收企业后台推送的登记/方案/公告/变更/报告备案（政务公开字段） |
| 备案审查 | 监督人员核对必招范围、方式、时限，出具意见 |
| 变更备案 | 交易方式变更、延期、终止的备案 |
| 报告登记 | 书面报告接收、归档登记 |

## 视图

功能视图：监督人员=查看/审查/出意见；招标人（企业后台）=提交/收意见；公众=不可见（政务级）。
流程视图：后台提交备案 → 接收登记 → 审查 → 通过/退回补正 → 留痕归档。

## 接口

- REST：POST /admin-api/bidding/sup/filing/submit（企业后台调用）、GET /filing/page（查询）。
- 跨模块 API：FilingApi.submit(FilingSubmitReqVO)；FilingApi.getStatus(projectCode)。
