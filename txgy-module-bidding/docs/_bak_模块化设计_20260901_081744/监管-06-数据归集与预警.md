# 监管-06 数据归集与预警（监管系统）

## 定位
三系统交换数据按 V2.0 数据集归集，做完整性校验、异常预警、统计与公开同步。

## 依据
- 《电子招标投标办法》第 3 条；《公共资源交易平台管理暂行办法》。
- 《陕西省公共资源交易平台管理办法》。
- 数据规范 V2.0：统一交易标识码（第 4 章）、各数据集、表121 报警、表127 报警等级。

## 功能

| 功能 | 说明 |
|---|---|
| 数据接收 | 按数据集接收交换数据，校验格式与必填 |
| 完整性校验 | 按项目→招标项目→标段→开标→评标→中标→合同链路校验 |
| 异常预警 | 时限不足、多次流标、报价异常、主体关联等规则预警 |
| 统计报表 | 地区/行业/时间维度统计 |
| 公开同步 | 社会公开字段白名单校验后送 ES 同步服务 |

## 项目框架落点

| 类型 | 类名 | 说明 |

| Api | GatherApi / GatherApiImpl（数据接收、公开同步、报警推送） | api |

## 视图

功能视图：系统=自动归集/校验/预警；监督人员=看预警/报表；大厅=收社会公开数据。
流程视图：后台推送 → 接收校验 → 按统一交易标识码归集 → 链路校验 → 规则命中生成报警 → 推送监督检查 → 公开字段白名单校验 → 送 ES。

## 接口

- REST：POST /admin-api/bidding/sup/gather/exchange（接收）；GET /alert/page；GET /stat。
- 跨模块 API：GatherApi.receiveExchange(数据集 VO)；GatherApi.pushAlert(表121 VO)；GatherApi.syncPublic(doc)（仅社会公开字段）。
