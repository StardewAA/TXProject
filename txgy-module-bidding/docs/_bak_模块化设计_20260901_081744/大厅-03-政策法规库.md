# 大厅-03 政策法规库（公共服务大厅）

## 定位
集中公开国家与陕西省招标投标、公共资源交易法规文件。

## 依据
- 《政府信息公开条例》；《招标公告和公示信息发布管理办法》。
- 《陕西省实施〈招标投标法〉办法》《陕西省公共资源交易平台管理办法》《陕西省公共资源交易目录（2024 年版）》（本库收录来源）。

## 功能

| 功能 | 说明 |
|---|---|
| 法规目录 | 国家/陕西、法律/法规/规章/规范性文件分层 |
| 全文查看 | 正文浏览、下载、全文检索（ES） |
| 关联标注 | 文件与交易环节关联（如保证金↔条例第 26 条） |
| 更新维护 | 运营录入、效力状态（现行/废止/修订）、版本保留 |

## 项目框架落点

| 类型 | 类名 | 说明 |
|---|---|---|
| 包 | cn.iocoder.yudao.module.bidding.hall.law | controller.app / controller.admin / service / dal |
| DO | LawDO、LawContentDO、LawRelateDO | 继承 BaseDO |
| VO | LawSaveReqVO、LawRespVO、LawPageReqVO | controller/admin/law/vo |
| Service | LawService / LawServiceImpl | service |
| Api | LawApi / LawApiImpl（供检索模块统一入口） | api |
| Controller | LawController（查询 @PermitAll；维护 bidding:hall:law:manage） | 大厅 |
| 错误码 | 段 1_100_302_xxx | enums |

## 视图

功能视图：公众=浏览/检索/下载；运营=录入/修订标注。
流程视图：录入 → 标注效力 → 发布（正文同步 ES）→ 废止/修订更新状态、历史保留。

## 接口

- REST：GET /admin-api/bidding/hall/law/page（@PermitAll）；POST /law/save（运营）。
- 跨模块 API：LawApi.search(条件)；LawApi.getDetail(code)。
