# 后台-02 项目登记（企业后台管理系统）

## 定位
项目入场登记：目录判定、项目/招标项目/标段建档、生成统一交易标识码。

## 依据
- 《必须招标的工程项目规定》（发改委令第 16 号）。
- 《陕西省公共资源交易目录（2024 年版）》；《公共资源交易平台管理暂行办法》。
- 数据规范 V2.0 第 4 章统一交易标识码、表10/11/12、表2 分类类目。

## 功能

| 功能 | 说明 |
|---|---|
| 目录判定 | 按陕西目录判定进场与交易分类 |
| 项目登记 | 项目信息录入、立项批文上传、项目编号生成 |
| 招标项目与标段 | 建立招标项目、划分标段、生成统一交易标识码 |
| 登记推送 | 政务字段推监管备案，社会字段推大厅 |

## 项目框架落点

| 类型 | 类名 | 说明 |
|---|---|---|
| 包 | cn.iocoder.yudao.module.bidding.ent.project | 结构同 07 约定 |
| DO | ProjectDO、TenderProjectDO、BidSectionDO | 继承 TenantBaseDO |

| Service | ProjectService / ProjectServiceImpl（含统一交易标识码生成器） | service |
| Mapper | ProjectMapper 等 | dal/mysql |

| Controller | ProjectController | bidding:ent:project:query/create/update |
| 错误码 | 段 1_100_101_xxx | enums |

## 视图

功能视图：招标人/代理=登记维护；监管=收备案；大厅=看社会公开项目信息。
流程视图：立项文件上传 → 目录判定 → 项目登记 → 招标项目 → 标段划分 → 生成标识码 → 推送备案与公开。

## 接口

- REST：POST /admin-api/bidding/project/create；POST /tender-project/create；POST /bid-section/create。
- 跨模块 API：ProjectApi.get(projectCode)；ProjectApi.getSection(sectionCode)。
