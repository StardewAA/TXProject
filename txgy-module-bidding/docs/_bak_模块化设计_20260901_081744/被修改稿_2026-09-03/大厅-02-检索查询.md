# 大厅-02 检索查询（公共服务大厅）

## 定位
为公众提供项目、标段、主体、专家公开信息的全文检索与组合过滤。

## 依据
- 《电子招标投标办法》第 3 条；《公共资源交易平台管理暂行办法》。
- 《陕西省公共资源交易平台管理办法》。
- 数据规范 V2.0 第 14/15 章社会公开字段为可检索范围。

## 功能

| 功能 | 说明 |
|---|---|
| 全文检索 | 关键字+类型/地区/行业/时间过滤，高亮返回 |
| 主体/专家检索 | 名称、统一社会信用代码、资质、专业 |
| 结果导出 | 按公开范围导出列表 |
| 检索日志 | 只记条件与数量，不含敏感信息 |

## 视图

功能视图：公众=检索/查看/导出；监管=经内部接口使用同一能力（政务级另有入口）。
流程视图：用户条件 → ES 查询 → 高亮分页返回 → 日志留存（不含内容）。

## 接口

- REST：GET /admin-api/bidding/hall/search（@PermitAll）；GET /search/subject；GET /search/export。
- 跨模块 API：SearchApi.search(SearchReqVO)；SearchApi.searchSubject(条件)。


## 涉及的数据对象（VO 完整字段表）

> 下表逐字照录《VO数据对象规范（国家V2.0模版·陕西适配全量版）.md》对应数据集的全量字段（8 列，含公开范围）。
> 该规范为国家级 V2.0（发改办法规〔2018〕1156号）与陕西省 V2.0 的合并速查版：同名数据集以陕西为准，「英文名称」照录原文（含拼写瑕疵，勿改）；只列字段清单，不含建表 DDL，也不绑定 Java record。

> 检索查询基于 ES 索引，索引字段取各规范 VO 的社会公开字段子集裁剪，规范未单列检索 VO；字段定义以各业务模块 VO 表格为准，本模块不与规范冲突、亦不新增字段。

## 技术复用

依赖 web；ES 查询统一走 bidding server 检索组件的公开检索接口，不直连 ES；分词 ik_max_word/ik_smart，标题加权>正文。
