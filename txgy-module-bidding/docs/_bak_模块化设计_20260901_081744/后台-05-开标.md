# 后台-05 开标（企业后台管理系统）

## 定位
截止同一时间开标：解密、唱标、当场异议答复、开标记录归档。

## 依据
- 《招标投标法》第 34~36 条；《实施条例》第 44 条。
- 数据规范 V2.0 表16 开标记录、表17 开标明细、表42 开标结果、表43 异议类型。

## 功能

| 功能 | 说明 |
|---|---|
| 开标大厅 | 线上开标，投标人在线确认 |
| 自动解密 | 到点自动解密（线下为当众拆封记录） |
| 唱标 | 系统生成唱标清单（名称/报价/保证金/工期） |
| 开标异议 | 当场提问当场答复，全部入档 |
| 记录归档 | 生成记录、签署、推送监管与大厅 |

## 项目框架落点

| 类型 | 类名 | 说明 |
|---|---|---|
| 包 | cn.iocoder.yudao.module.bidding.ent.open | 结构同 07 约定 |
| DO | BidOpenDO、BidOpenItemDO、OpenDissentDO | 继承 TenantBaseDO |
| VO | BidOpenRespVO、BidOpenItemRespVO、OpenDissentSaveReqVO | controller/admin/open/vo |
| Service | BidOpenService / BidOpenServiceImpl（开标调度） | service |
| Api | BidOpenApi / BidOpenApiImpl（开标记录查询、结果推送） | api，供评标模块 |
| Controller | BidOpenController | bidding:ent:open:query/start |
| 错误码 | 段 1_100_104_xxx | enums |

## 视图

功能视图：招标人/代理=主持；投标人=观看/确认/当场异议；监管=在线监督收记录。
流程视图：截止到点 → 自动触发 → 解密 → 生成唱标清单 → 确认 → 异议答复 → 记录签署归档 → 推送。

## 接口

- REST：POST /admin-api/bidding/open/start（系统触发+主持确认）；GET /open/record。
- 跨模块 API：BidOpenApi.getRecord(openCode)；BidOpenApi.pushResult(表16/17 VO)。
