# 后台-04 投标递交（企业后台管理系统）

## 定位
投标文件加密递交、保证金登记、截止锁定与开标前保密。

## 依据
- 《招标投标法》第 22、27~29 条；《实施条例》第 26、35、38 条。
- 数据规范 V2.0 表12 保证金字段、表39 保证金缴纳方式、表28/29 附件集。

## 功能

| 功能 | 说明 |
|---|---|
| 加密递交 | 加密上传、电子签章、递交时间戳 |
| 保证金登记 | 金额校验（≤估算价 2%）、保函验真记录 |
| 截止锁定 | 到点自动锁：拒收逾期、禁止修改撤回 |
| 撤回修改 | 截止前可撤回重传，版本全保留 |
| 开标前保密 | 任何人只能看递交状态，不能看内容 |

## 视图

功能视图：投标人=递交/撤回/缴保证金；招标人=看清单验封；监管=看递交情况（不含内容）。
流程视图：加密上传 → 缴保证金 → 接收登记 → 截止锁定 →（开标前内容不可见）→ 清单交开标模块。

## 接口

- REST：POST /admin-api/bidding/bid/submit；PUT /bid/withdraw；POST /bid/margin。
- 跨模块 API：BidSubmitApi.getSubmitList(sectionCode)；BidSubmitApi.decryptAtOpen(sectionCode, openTime)（仅开标窗口内有效）。

## 技术复用

依赖 web、security、mybatis、biz-tenant、redis（截止锁与密钥）；文件加密存储于文件服务，密钥独立管理，开标时发放；截止时间取自公告模块接口。

## 陕西省 V2.0 增补（2026-08-31）

依据陕西省 V2.0《变更记录》（新增 1.4.3、2.4.3 相关字段），本模块涉及：

| VO | 变更类型 | 关键内容 | 落点 |
|---|---|---|---|
| BidOpenDetailVO（递交侧字段） | 陕V2.0新增 | "投标文件递交时间" CHECKIN_TIME（必填）纳入开标明细推送；递交环节须留存投标人 IP、机器码（macaddress）、文件创建标识码（Createguid） | 递交记录表增列 ip_address、mac_address、create_guid，开标时随明细推送监管 |

围串标防控数据（IP/机器码/创建标识码/解密IP）按 VO 文件 BidOpenDetailVO 定义采集，仅推监管系统，不对投标人与公众公开。
