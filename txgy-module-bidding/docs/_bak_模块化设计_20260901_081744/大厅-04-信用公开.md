# 大厅-04 信用公开（公共服务大厅）

## 定位
向社会公众公开市场主体与专家的信用信息（黑名单、违法违规、奖励等社会公开部分）。

## 依据
- 《招标投标法实施条例》信用公告要求；《公共资源交易平台管理暂行办法》。
- 《陕西省公共资源交易平台管理办法》。
- 数据规范 V2.0 表128~133 信用数据集的"社会公开"字段、表115 专家信用记录。

## 功能

| 功能 | 说明 |
|---|---|
| 黑名单公示 | 列入/撤销黑名单、限制行为、期限 |
| 违法违规公示 | 主体、行为、处罚结果 |
| 奖励公示 | 奖励主体与事项 |
| 专家信用公示 | 专家奖惩与限制（社会公开部分） |

## 视图

功能视图：公众=查询公示详情；监管=发布方（社会公开字段同步）。
流程视图：监管信用模块推送 → 归集白名单校验 → ES 索引 tbd_credit → 公众查询；撤销不删除、置状态并追加撤销文档。

## 接口

- REST：GET /admin-api/bidding/hall/creditpub/query（@PermitAll）。
- 跨模块 API：CreditPubApi.query(subjectCode/name)。

## 技术复用

依赖 web、ES 公开检索接口；只展示社会公开字段，证件号等敏感字段不入本模块；撤销用新文档关联原文档。
