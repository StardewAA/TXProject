# 后台-06 评标（企业后台管理系统）

## 定位
组建评标委员会、封闭评审、澄清、评标报告与中标候选人排序。

## 依据
- 《招标投标法》第 37~40 条；《实施条例》第 46~53 条。
- 数据规范 V2.0 表18 评标专家、表19 评标报告、表20 中标候选人、表34/41/44 代码。

## 功能

| 功能 | 说明 |
|---|---|
| 专家抽取 | 调监管专家库随机抽取，抽取留痕 |
| 封闭评审 | 专家只读本项目文件，互相不可见打分 |
| 评审打分 | 初评/详评，提交即锁定 |
| 澄清管理 | 含义不清处澄清，投标人限时回复 |
| 评标报告 | 汇总生成、电子签字、锁定 |

## 项目框架落点

| 类型 | 类名 | 说明 |
|---|---|---|
| 包 | cn.iocoder.yudao.module.bidding.ent.evaluation | 结构同 07 约定 |

| Service | EvaluationService / EvaluationServiceImpl（组成校验、打分锁定） | service |
| Api | EvaluationApi / EvaluationApiImpl（报告查询、候选人名单） | api，供中标模块 |
| Controller | EvaluationController | bidding:ent:eval:query/score/report |
| 错误码 | 段 1_100_105_xxx | enums |

## 视图

功能视图：专家=评审/打分/签署；招标人/代理=组织不打分；投标人=仅回澄清；监管=监督收报告。
流程视图：抽取（留痕）→ 封闭评审 → 初评否决 → 澄清 → 打分锁定 → 汇总 → 报告签字锁定 → 推送。

## 接口

- REST：POST /admin-api/bidding/eval/score/submit；POST /eval/report/sign；GET /eval/report。
- 跨模块 API：EvaluationApi.getReport(reportCode)；EvaluationApi.getCandidates(reportCode)。
