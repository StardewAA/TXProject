# 后台-03 公告与文件（企业后台管理系统）

## 定位
公告发布、文件发售、澄清修改与文件异议处理；管理法定时限（20 日/15 日/3 日）。

## 依据
- 《招标投标法》第 16、19、24 条；《实施条例》第 21、22 条。
- 《招标公告和公示信息发布管理办法》（发改委令第 10 号）。
- 数据规范 V2.0 表13/14/15、表24/25/26、表32/33/40、表43。

## 功能

| 功能 | 说明 |
|---|---|
| 公告发布 | 编制、审定、发布（时间戳留痕） |
| 文件发售 | 上传、购标、下载登记 |
| 澄清修改 | 通知全部购标人、必要时顺延截止 |
| 文件异议 | 3 日内答复，答复前暂停流程 |

## 项目框架落点

| 类型 | 类名 | 说明 |
|---|---|---|
| 包 | cn.iocoder.yudao.module.bidding.ent.notice | 结构同 07 约定 |
| DO | NoticeDO、TenderDocDO、ClarifyDO、DocPurchaseDO、DocDissentDO | 继承 TenantBaseDO |
| VO | NoticeSaveReqVO、NoticeRespVO、NoticePageReqVO、ClarifySaveReqVO 等 | controller/admin/notice/vo |
| Service | NoticeService / NoticeServiceImpl（时限统一计算） | service |
| Api | NoticeApi / NoticeApiImpl（公告查询、购标校验、截止时间查询） | api |
| Controller | NoticeController | bidding:ent:notice:query/create/update/publish |
| Job | DeadlineNotifyJob | 截止/澄清到期提醒 |
| 错误码 | 段 1_100_102_xxx | enums |

## 视图

功能视图：招标人/代理=发布/澄清/答复；投标人=购标/下载/提异议；大厅=社会公开；监管=备案。
流程视图：编制 → 审定 → 发布 → 发售（登记）→ 澄清/异议 → 截止时间管理 → 分级推送。

## 接口

- REST：POST /admin-api/bidding/notice/publish；POST /clarify/send；POST /doc-dissent/reply。
- 跨模块 API：NoticeApi.getPurchaseList(sectionCode)；NoticeApi.getDeadline(sectionCode)。
