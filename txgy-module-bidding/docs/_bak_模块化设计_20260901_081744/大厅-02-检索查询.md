# 大厅-02 检索查询（公共服务大厅）

## 定位
为公众提供项目、标段、主体、专家公开信息的全文检索与组合过滤。

## 依据
- 《电子招标投标办法》第 3 条；《公共资源交易平台管理暂行办法》。
- 《陕西省公共资源交易平台管理办法》。
- 数据规范 V2.0 第 14/15 章社会公开字段为可检索范围。

## 功能

| 功能 | 说明 |
|---|---|
| 全文检索 | 关键字+类型/地区/行业/时间过滤，高亮返回 |
| 主体/专家检索 | 名称、统一社会信用代码、资质、专业 |
| 结果导出 | 按公开范围导出列表 |
| 检索日志 | 只记条件与数量，不含敏感信息 |

## 项目框架落点

| 类型 | 类名 | 说明 |

| 错误码 | 段 1_100_301_xxx | enums |

## 视图

功能视图：公众=检索/查看/导出；监管=经内部接口使用同一能力（政务级另有入口）。
流程视图：用户条件 → ES 查询 → 高亮分页返回 → 日志留存（不含内容）。

## 接口

- REST：GET /admin-api/bidding/hall/search（@PermitAll）；GET /search/subject；GET /search/export。
- 跨模块 API：SearchApi.search(SearchReqVO)；SearchApi.searchSubject(条件)。
