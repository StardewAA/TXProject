# 大厅-01 信息公开（公共服务大厅）

## 定位
面向公众展示公告、公示、结果等社会公开信息；公开文档数据源为 ES。

## 依据
- 《招标公告和公示信息发布管理办法》（发改委令第 10 号）。
- 《电子招标投标办法》第 3 条；《陕西省公共资源交易平台管理办法》。
- 数据规范 V2.0 各数据集"公开范围=社会公开"的字段。

## 功能

| 功能 | 说明 |
|---|---|
| 公告展示 | 招标/资格预审/更正公告、采购公告 |
| 公示展示 | 候选人公示、结果公示、异常情况报告 |
| 结果与合同公开 | 中标结果、合同主要信息（社会公开字段） |
| 订阅通知 | 按地区/行业订阅，新文档通知 |

## 项目框架落点

| 类型 | 类名 | 说明 |
|---|---|---|
| 包 | cn.iocoder.yudao.module.bidding.hall.info | controller.app（公众）/ controller.admin（运营）/ service / dal / convert |
| DO | PublicDocDO、SubscribeDO | 继承 BaseDO（无租户）；公开文档主存储为 ES，MySQL 只存订阅 |
| VO | PublicDocQueryReqVO、PublicDocRespVO、SubscribeSaveReqVO | controller 下 vo |
| Service | PublicDocService / PublicDocServiceImpl（读 ES） | service |
| Api | PublicDocApi / PublicDocApiImpl（供检索模块） | api |
| Controller | PublicDocController（@PermitAll 匿名访问） | 大厅公开接口 |
| 错误码 | 段 1_100_300_xxx | enums |

权限：公开接口全部 @PermitAll；运营复核接口需 bidding:hall:info:manage。

## 视图

功能视图：公众=浏览/订阅；企业后台与监管=发布方（经数据归集同步 ES）；运营=格式复核。
流程视图：归集校验 → ES 写入 → 本模块按索引读取 → 公众浏览/订阅 → 更正追加新文档、历史保留。

## 接口

- REST：GET /admin-api/bidding/hall/doc/detail（@PermitAll）、/doc/page；POST /subscribe。
- 跨模块 API：PublicDocApi.query(PublicDocQueryReqVO)；PublicDocApi.getDetail(code)。
