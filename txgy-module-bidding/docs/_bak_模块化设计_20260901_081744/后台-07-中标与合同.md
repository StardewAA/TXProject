# 后台-07 中标与合同（企业后台管理系统）

## 定位
候选人公示、定标、中标通知书、合同签订与保证金退还，控制 3/3/30/5/15 日时限。

## 依据
- 《招标投标法》第 45、46、47 条；《实施条例》第 54、55、57、58 条。
- 数据规范 V2.0 表21 候选人公示、表22 中标结果公示、表23 合同、表35 公示类型。

## 功能

| 功能 | 说明 |
|---|---|
| 候选人公示 | 报告后 3 日内发布，公示期≥3 日 |
| 异议处理 | 3 日内答复，答复前锁定定标 |
| 定标 | 期满无有效异议后定标（国有资金限排名第一） |
| 通知书 | 中标通知书签署、未中标通知 |
| 合同与保证金 | 合同一致性比对、履约保证金（≤10%）、投标保证金退还（5 日内）、15 日报告提醒 |

## 项目框架落点

| 类型 | 类名 | 说明 |
|---|---|---|

| Api | WinApi / WinApiImpl（结果查询、合同查询） | api |
| Controller | WinController | bidding:ent:win:query/publicity/award |
| Job | ContractDeadlineJob、MarginRefundJob | 倒计时提醒 |
| 错误码 | 段 1_100_106_xxx | enums |

## 视图

功能视图：招标人=公示/答复/定标/通知书/签约/退保；投标人=看公示/提异议/收通知；监管=收报告；大厅=社会公开。
流程视图：报告 → 3 日内公示 →（异议 3 日答复、暂停）→ 期满定标 → 通知书 → 30 日签约 → 5 日退保 → 履约保证金 → 15 日报告。

## 接口

- REST：POST /admin-api/bidding/win/publicity/publish；POST /win/award；POST /win/contract/save。
- 跨模块 API：WinApi.getResult(sectionCode)；WinApi.getContract(contractCode)。
