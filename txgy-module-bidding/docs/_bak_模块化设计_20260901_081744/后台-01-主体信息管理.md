# 后台-01 主体信息管理（企业后台管理系统）

## 定位
招标人、投标人、代理机构三类主体的注册、实名、信息维护与资格状态。

## 依据
- 《招标投标法》第 25、26 条；《电子招标投标办法》实名认证要求。
- 《陕西省公共资源交易平台管理办法》。
- 数据规范 V2.0 表89~112 主体信息数据集与附件集。

## 功能

| 功能 | 说明 |
|---|---|
| 注册与实名 | 注册、统一社会信用代码校验、实名认证 |
| 信息维护 | 基本信息与扩展信息维护、变更留痕 |
| 资质附件 | 营业执照、资质、执业人员证书上传管理 |
| 状态管理 | 正常/暂停/注销，与信用状态联动 |

## 项目框架落点

| 类型 | 类名 | 说明 |
|---|---|---|
| 包 | cn.iocoder.yudao.module.bidding.ent.subject | controller/admin / service / dal / convert / api / enums / framework |
| DO | SubjectDO、SubjectExtDO、SubjectCertDO | 继承 TenantBaseDO（一企业一租户） |
| VO | SubjectSaveReqVO、SubjectRespVO、SubjectPageReqVO | controller/admin/subject/vo |
| Service | SubjectService / SubjectServiceImpl | service |
| Mapper | SubjectMapper 等（继承 BaseMapperX） | dal/mysql |
| Api | SubjectApi / SubjectApiImpl（信息查询、状态核验） | api，供评标等模块调用 |
| Controller | SubjectController | @PreAuthorize("@ss.hasPermission('bidding:ent:subject:query')") 等 |
| 错误码 | ErrorCodeConstants 段 1_100_100_xxx | enums |

权限码：bidding:ent:subject:query/create/update/delete。租户隔离：查询强制 tenant_id，唯一索引含 tenant_id。

## 视图

功能视图：三类主体=注册/维护本人；监管=经接口查政务公开信息；大厅=展示社会公开信息。
流程视图：注册 → 实名认证 → 审核 → 启用 → 变更申请 → 审核生效 → 状态随信用联动。

## 接口

- REST：POST /admin-api/bidding/subject/create；PUT /subject/update；GET /subject/page。
- 跨模块 API：SubjectApi.get(subjectCode)；SubjectApi.checkStatus(subjectCode)。
