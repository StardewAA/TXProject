## 权威数据规范（不落盘，按此规整字段）

- 国家《公共资源交易平台系统数据规范 V2.0》/ 陕西省平台数据规范 V2.0：
  - **表89 法人基本信息**：LEGAL_NAME（单位名称，必填）、LEGAL_CODE（统一社会信用代码 C18，必填，GB 32100-2015）、
    LEGAL_REPRESENT（法定代表人姓名，必填）、LEGAL_TYPE（法人机构类别 C1，必填）、REGION_CODE（行政区划 C6，必填，GB/T 2260）、
    LEGAL_INDUSTRY（行业代码 C3，GB/T 4754-2011）、REG_CAPITAL / REG_CAP_CURRENCY（注册资本及币种，GB/T 12406-2008）、
    LEGAL_CONTACT / LEGAL_CONTACT_PHONE（联系人/电话，必填）。
  - 招标人侧主体：ProjectSubjectExtVO（DANWEI_TYPE 11=招标人 / 18=招标代理）。
- 对应模块旧稿字段全集：docs/_bak_模块化设计_20260901_081744/后台-01-主体信息管理.md（表89 字段级清单）。

## 代码引用标记约定

新代码（subject 域 + 门槛接线）按下列标记注明依据：

```java
// [依据] docs/法规依据/00-索引：招标投标法 第25/26条（投标资格）、电子招标投标办法 第24条（注册登记+如实递交+验证）
```

## 需求口径 → 依据对照（本模块主体域）

| 需求 | 落地规则 | 依据 |
| --- | --- | --- |
| 管理端显示已授权投标人并支持管理 | bidding_subject_auth（G 轨）+ 经办用户 bidding_subject_user | 需求 + 招标投标法 第25条（投标人资格由平台核发） |
| 仅授权尚不充分，被授权后仍须完善信息 | bidding_subject_profile（T 轨）必填清单全齐=complete_flag | 电子招标投标办法 第24条、第14条（如实递交并经验证） |
| 未完善 → 不能在本项目投标，但可关注/订阅/浏览 | 资格门只拦截投标/发布动作；关注域仅权限控制 | 招标投标法 第26条 + 平台内部流程设计（本条为平台流程约定） |
| 管理/关注/订阅不需要完善，有权限即可 | 档案/授权/关注接口不做 complete 校验 | 需求口径 |
| 招标人同构：授权+完善后方可发布项目公告/备案 | Notice/Filing 服务入口断言 | 招标投标法 第8/16条、实施条例 第15条、10号令 第5条 |
