## 本轮（2026-09-28）变更：资格审查委员会强制组建（条例第18条，国有资金项目）

### 背景

说明书 §6.6 原判定：资格预审子域缺少「资格审查委员会强制组建」。此前国有资金占控股或主导地位
的依法必招项目，未组建资格审查委员会即可审查，违反《实施条例》第18条。本轮补齐：

- 新增委员会成员表 `bidding_prequal_committee` 与 2 个接口（保存/列表）；
- 新增资金来源字典 `fund_source`（项目登记 FUND_SOURCE 字段改为字典代码，01/02/03=国有资金）；
- 审查前置强制校验：资格预审所属项目为国有资金（fund_source∈{01,02,03}）时，**未组建资格审查
  委员会禁止审查**（review 接口返回错误码 `1060115008`）；
- 组成校验（条例第37条）：成员数须为 **5 人以上单数**，技术/经济专家不少于成员总数 **2/3**，
  不满足抛 `1060115009`。

### 新增接口（前缀 `/admin-api/bidding/prequal/committee`）

| 方法 | 路径 | 权限码 | 说明 |
| --- | --- | --- | --- |
| POST | `/save` | `bidding:prequal:committee` | 保存资格审查委员会（整单覆盖：先删后插；组成校验同上） |
| GET | `/list` | `bidding:prequal:query` | 委员会成员列表（按资格预审） |

### save 请求体

```json
{
  "prequalId": 7001,
  "members": [
    { "memberName": "张三", "memberCategory": "TECH_EXPERT", "memberRole": "LEADER",
      "memberOrg": "某设计院", "memberTitle": "高级工程师", "sort": 1, "remark": "" }
  ]
}
```

- `memberCategory`：`TENDERER_REP`（招标人代表）/ `TECH_EXPERT`（技术专家）/ `ECON_EXPERT`（经济专家）；
- `memberRole`：`LEADER`（组长）/ `MEMBER`（成员），可空；
- 整单覆盖：每次 save 用入参整单替换既有成员（先删后插），幂等由 @Idempotent 兜底。

### list 响应（data 为数组）

```json
[
  { "id": 3001, "prequalId": 7001, "memberName": "张三", "memberCategory": "TECH_EXPERT",
    "memberRole": "LEADER", "memberOrg": "某设计院", "memberTitle": "高级工程师",
    "sort": 1, "remark": "", "createTime": "2026-09-28T10:00:00" }
]
```

### 资金来源字典 `fund_source`（新增，经 `/bidding/meta/dicts?types=fund_source` 下发）

| dict_value | dict_label | 是否国有资金（触发强制委员会） |
| --- | --- | --- |
| 01 | 财政性资金 | ✅ 是 |
| 02 | 国有企事业单位资金 | ✅ 是 |
| 03 | 国有控股/主导混合资金 | ✅ 是 |
| 04 | 非国有资金 | 否 |
| 99 | 其他 | 否 |

**项目登记 FUND_SOURCE 字段**：建议改为下拉选择本字典（存量自由文本数据不受影响；
后端按 exact 匹配字典值判定国有资金）。

### 影响：review 接口（既有）新增前置校验

- 路径不变：`POST /bidding/prequal/review`；
- 新增失败码：`1060115008`（未组建委员会）、`1060115009`（组成不合规）；
- 前端应在「审查」操作前提示组建委员会（若项目资金来源为 01/02/03）。

### 菜单/权限码

- 新增按钮权限点 `bidding:prequal:committee`（已注册 system_menu，挂项目台账 6771）；
- 既有 `bidding:prequal:query` 复用（list 接口）。
