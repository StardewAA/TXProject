## 2. 前端改动清单（已落地）

### 2.1 新增 API 客户端

`apps/web-antd/src/api/bidding/subject/index.ts`

```ts
/** 契约：DELETE /bidding/subject/profile/license —— 清除本租户档案的营业执照影像…… */
export function deleteSubjectLicense() {
  return requestClient.delete<boolean>('/bidding/subject/profile/license', {
    headers: { 'X-Silent-Error': 'true' },
  });
}
```

- 传 `X-Silent-Error` 关闭全局错误红条：404 由页面按契约口径明确提示（避免同一次失败弹两条），其他错误同样由页面统一提示。
- 注释完整记录 B1 语义与「为什么必须专用端点」。

### 2.2 更换 = 上传后自动保存（契约 §3.2，推荐方案）

`views/bidding/subjectProfile/index.vue` 的 `beforeLicenseUpload` 上传成功绑定表单后：

- **必填齐全（validate() 通过）** → 自动 `await doSave()`：toast「营业执照影像已上传（file_id=…）」+「档案已保存（信息完善）」，**用户不点「保存档案」也落库**；
- **必填缺失（validate() 失败）** → toast「影像已上传并绑定，但档案尚未生效：<缺失项>，补齐必填项后点『保存档案』」——**不给「已生效」假象**。

### 2.3 移除 = 二次确认 + 调后端（契约 §3.1 + §3.3）

`clearLicense()` 改为：

1. 先 `Modal.confirm` 二次确认（danger 按钮「确认移除」，误删成本高）；
2. 确认后调 `deleteSubjectLicense()`：
   - **成功**：清空 `licenseFileId/licenseFileName/licenseUploadedUrl` + toast「营业执照影像已移除」；
   - **失败 404 / 请求地址不存在**（当前端点尚未上线的实测形态）：toast「移除失败：后端清除端点尚未上线（契约 B1），本次未做任何变更，影像仍保留。」，**不清空本地变量、不改库**（杜绝旧行为「删了其实没删」的假象）；
   - 其余错误：形状鲁棒提取（data.code / data.msg / response.status / message 无论字符串还是对象）后如实提示，避免出现 `[object Object]` 式提示；
   - 首次 404 后记录 `licenseClearUnsupported` 标记：**再次点「移除」不再发必然失败的请求**，直接 `Modal.info` 提示「后端清除端点（契约 B1）待上线」——端点上线后此分支自动失效，无需再改前端。
