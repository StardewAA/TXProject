## 本轮（2026-09-28）变更：新增定标书面报告子域

### 影响范围：新增 3 个接口（提交 + 查询）

**背景**：《招标投标法》第 47 条——依法必须进行招标的项目，招标人应当自**确定中标人之日起 15 日内**
向有关行政监督部门提交招标投标情况的书面报告。

**接口清单**（前缀 `/admin-api/bidding/report`）：

| 方法 | 路径 | 权限码 | 说明 |
| --- | --- | --- | --- |
| POST | `/submit` | `bidding:report:submit` | 提交定标书面报告（招标人调用） |
| GET | `/get` | `bidding:report:query` | 报告详情 |
| GET | `/page` | `bidding:report:query` | 报告台账分页（含超期未提交标记） |

**关键行为（后端已实现）**：
- **定标时间锚点**：取该项目**中标结果公告（`WIN_RESULT_PUBLICITY`）的发布时间**作为"确定中标人之日"；
  未定位到（缺公告/外部采集）→ 容错跳过时限校验（warn 日志，不误拦）。
- **超期提交告警**：提交时若距定标时间已超 **15 日** → warn 日志（招标投标法第47条；不阻断——报告必须补交）。
- **超期未提交标记**：台账/详情 `reportOverdue = true`（未提交且定标后超 15 日，前端黄色标记提醒）。

**字段说明（以响应字段集合为准，前端只取下列字段）**：
- 请求（submit）6 字段：`tenderProjectCode`、`bidSectionCode`（可空）、`reportCode`、`reportName`、`fileId`、`remark`。
- 响应 12 字段：`id`、`tenderProjectCode`、`bidSectionCode`、`reportCode`、`reportName`、`fileId`、`submitTime`、`awardTime`、`status`、`reportOverdue`、`remark`、`createTime`。
  `awardTime` = 定标时间（中标结果公告发布时间）；`reportOverdue` = 超期未提交标记。

**错误码**：
| code | 说明 |
| --- | --- |
| `1060117000` | 定标书面报告不存在 |

**前端需要做什么**：
- 菜单/按钮权限码登记：`bidding:report:submit`、`bidding:report:query`（2 个）。
- 页面接线：招标方「报告台账」（`reportOverdue` 黄色标记）+ 上传报告文件提交。
- 提交失败时展示错误码 `1060117000` 的 msg（记录不存在）。
