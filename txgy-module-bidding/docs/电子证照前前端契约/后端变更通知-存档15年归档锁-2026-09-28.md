## 本轮（2026-09-28）变更：合同归档只读锁定 + 保存期限（15 年）自动计算与提醒

### 背景

说明书 §12.2 第 3 条将「存档（15 年）等法定时限的自动计算与提醒」列为合规校验待补项：
合同登记后无归档动作、归档后仍可被修改、无 15 年保存期限自动计算与到期提醒。本轮补齐。

### 数据模型：bidding_contract 新增 3 列（DDL：sql/history/2026-09-28-contract-archive.sql）

| 列 | 说明 | 取值来源 |
| --- | --- | --- |
| archive_time | 归档时间 | archive 接口调用时点（SIGNED→ARCHIVED） |
| retention_until | 保存到期时间 | **自动计算** = 归档时间 + 15 年（电子办法技术规范 存档≥15 年） |
| retention_warn | 保存期限提醒标记 | **自动计算**：NORMAL 正常 / EXPIRING_SOON 临期（距到期 ≤90 天）/ EXPIRED 已到期 |

### 新增接口

`POST /bidding/contract/archive?id=`（权限 `bidding:contract:archive`，幂等）：

- SIGNED → ARCHIVED：落归档时间 + 保存到期（归档 + 15 年自动计算）；
- 重复归档直接成功（幂等，不再写库）；
- 非 SIGNED 状态归档抛 1-060-103-005（仅 SIGNED 可归档）。

### 归档锁（只读锁定）

- 合同状态 = ARCHIVED 后，**登记接口 save 不再允许修改**（1-060-103-004 已归档只读锁定）；
- save 直接带 status=ARCHIVED 被拒（归档必须走 archive 接口，保证保存到期正确落库）；
- 日志留痕仍走既有证书/合同变更审计（只追加不覆盖），本轮不新增事件表。

### 前端需要做什么

1. 合同台账/详情增加「归档」操作（按钮权限 `bidding:contract:archive`）：点击后调 archive 接口；
2. 展示保存期限：`retentionUntil`（保存到期日）与 `retentionWarn` 提醒标记——
   EXPIRING_SOON 显示「保存期将满」、EXPIRED 显示「已过保存期」（列表/详情均可用）；
3. 已归档（ARCHIVED）合同：前端**禁用编辑入口**（后端已强制只读，防呆提示「已归档只读锁定」）。

### 错误码（新增 2 条）

| 错误码 | 含义 |
| --- | --- |
| 1-060-103-004 | 合同已归档只读锁定，禁止修改（存档 ≥15 年，电子办法技术规范） |
| 1-060-103-005 | 合同归档状态不允许该操作（仅 SIGNED 可归档） |
