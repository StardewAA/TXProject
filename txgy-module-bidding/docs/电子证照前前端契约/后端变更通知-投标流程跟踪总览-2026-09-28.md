## 本轮（2026-09-28）变更：投标流程跟踪管理端总览 4 个读接口 + 负责人/公司快照列落地

### 背景

09-28 核对清单 A2/A3/A4/A5：页面要的「公司 → 意向项目 → 负责人 → 事件史」台账缺后端支撑——
`bidding_process_track` 无负责人/公司快照列（A3），page/stats/options 未实现、get 未返回事件史（A2），
阶段/事件字典命名未对齐（A4），菜单权限未归位（A5）。本轮全部落地。

### 数据模型：bidding_process_track 新增 8 个快照列（09-18 契约 §3 方案 B）

| 列 | 说明 | 取值来源 |
| --- | --- | --- |
| owner_user_id | 负责人用户ID | 建档时点 = 投标员工 userId |
| owner_name | 负责人姓名快照 | AdminUserApi 建档时点取值（避免逐行 RPC 与改名漂移） |
| owner_post / owner_phone | 职务/联系方式（可空） | 待主体档案完善后回填（当前显示 —） |
| tenant_name | 公司名快照 | 平台授权 SubjectAuth.tenantName 时点取值 |
| region / amount | 地区 / 预算金额 | BidSection.regionCode / contractReckonPrice 建档时点取值 |
| deadline | 投标截止 | bid_end_time 时点取值（flow-timer 域 DO 同步后回填） |

### 新增接口（前缀 `/admin-api/bidding/process-track`，权限 `bidding:process-track:query`）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/page` | 总览分页（项目粒度，出参自带公司/负责人；keyword/state/tenantId/ownerUserId 筛选） |
| GET | `/stats` | KPI：tenantCount/projectCount/ongoing/bidded/terminated/ownerCount/byState（ongoing=意向+审核+待投标三态和） |
| GET | `/options` | 筛选项：owners[{value=ownerUserId,label=姓名,extra=公司名}] + tenants（**仅超管下发**） |
| GET | `/detail?id=` | 详情：ProcessTrackItemVO + **events[] 操作记录事件史**（只读，按时间升序） |

**租户隔离（09-18 契约 §6，硬要求）**：

- 非超管：后端强制 `tenant_id = 当前租户` 过滤，`tenantId` 入参忽略；
- 超管：跨租户查询走 `TenantUtils.executeIgnore`，`tenantId` 入参生效，`tenants` 候选下发；
- **超管判定**：登录用户 scopes 含 `bidding:process-track:overview`（仅绑 super_admin，role_id=1）即超管。

### 操作记录跟踪（用户关切：怎么跟踪操作记录）

- `bidding_process_event` 事件表原有留痕（event_type/from/to/operator_id/operation_desc/event_time），
  本轮补：**operator_name 操作人名称快照**（事件写入时 AdminUserApi 取值落库）；
- `GET /detail?id=` 返回 `events[]`：eventType/eventName/fromState/toState/operatorName/operationDesc/occurredAt；
- 前端详情大页直接渲染事件史（页面无「手动推进状态」入口，只读）。

### 字典注册（09-18 契约 §4.1，消灭前端硬编码）

| dict type | 取值 |
| --- | --- |
| `bidding_process_state` | INTENTION 意向投标 / QUALIFICATION_REVIEW 资质审核 / PENDING_BID 待投标 / BIDDED 已投标 / TERMINATED 流程结束 |
| `bidding_process_event` | CREATE 新建意向 / REGISTER 报名投标 / APPROVE 审核通过 / REJECT 审核不通过 / UPLOAD_DOCUMENT 上传标书 / CANCEL 取消投标 |

经 `/bidding/meta/dicts?types=bidding_process_state,bidding_process_event` 读取；
存量 `process_track_status` 字典保留兼容（新口径以 bidding_process_state 为准）。

### 菜单权限归位（09-18 契约 §6.4）

1. 菜单 **6748** `permission`：`bidding:notice-external:query` → **`bidding:process-track:query`**（页面 v2 已不调用 notice-external）；
2. 新增按钮权限点 `bidding:process-track:overview`（**仅超管**，system_menu 60006222 挂 6748 下 + role_menu 绑 super_admin role_id=1）。

### 前端需要做什么

1. 删除 `demoData.ts`，改调 `fetchProcessTrackPage / Stats / Options / Detail` 四个函数；
2. 阶段/事件中文改读字典 `bidding_process_state` / `bidding_process_event`（删除 STATE_TEXT/EVENT_TEXT 硬编码）；
3. **类型约束**：`id`/`tenantId`/`ownerUserId`/`followItemId` 一律 String（雪花 ID 超 JS 安全整数，禁止 Number()）；
4. 超管视图：页头「平台视图 · 全租户」由前端判断 `userRoles` 含 `super_admin`（呈现层），真实数据隔离由后端 §6 强制。
