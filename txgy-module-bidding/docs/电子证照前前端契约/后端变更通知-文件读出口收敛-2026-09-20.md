# 后端变更通知 - 文件读出口收敛（2026-09-20）

> 契约沟通文档（append-only）。承接《31-文件上传下载更新接口口径对账与收敛建议》（前端侧对账）。
> 后端实施依据：《32-文件接口收敛方案-后端实施篇-2026-09-20》。

## 一、一句话口径

> **上传只走 `/bidding/file/upload`；关联只认 `fileId`；取文件只走 `GET /bidding/file/download?id=`；不要再使用 `/infra/file/get`。**

## 二、新增接口（本次唯一新增）

### `GET /bidding/file/download?id={fileId}`

| 项 | 说明 |
| --- | --- |
| 方法 | GET |
| 路径 | `/admin-api/bidding/file/download` |
| 入参 | `id`（fileId，必填） |
| 鉴权 | `isAuthenticated()` —— **登录即可，无需 `infra:file:query`**（权限倒挂修复） |
| 响应 | **文件字节流**（非 JSON）；`Content-Type` 取文件 MIME；`Content-Disposition: inline; filename=...`（中文 RFC 5987 编码） |
| 适用 | 预览（PDF/图片）与下载均可直接用 |

**前端用法**（无需任何特殊处理，浏览器自动带登录态）：

```html
<!-- 直接打开/下载 -->
<a :href="'/admin-api/bidding/file/download?id=' + fileId" target="_blank">查看</a>
```
```ts
// 或程序式打开
window.open(`/admin-api/bidding/file/download?id=${fileId}`, '_blank')
```

**要点**：
- 该接口**不下发任何 url**（URL 即凭据，属红线 8 管控），前端**拿不到**也**不需要**文件地址；
- 后端统一处理病毒拦截：`virusStatus=INFECTED` 时返回业务错误 `1-060-101-021`（**不返回文件内容**）；
- 未登记/坐标缺失分别返回 `1-060-101-020` / `1-060-101-022`。

## 三、废弃与替代

| 原做法 | 处置 |
| --- | --- |
| `GET /infra/file/get?id=`（**需 infra:file:query，业务账号没有**） | ❌ **废弃**，改用 `/bidding/file/download?id=` |
| `PdfPreview.vue` 的 infra 兜底分支 | ❌ 删除，统一走新接口 |
| 前端把出参 `url` 同源化下载 | 🔧 保留用于**上传后即时预览**（刚上传时有 url）；**历史数据预览一律走新接口** |
| `/infra/file/upload`（只回 url 无 id） | ⚠️ **业务禁用**，仅平台组件（头像/知识库）可用 |

## 四、上传接口（不变，无需改动）

`POST /admin-api/bidding/file/upload`（multipart `file`）→ `{fileId, url, name, type, size, sha256}`

- `fileId` 是**唯一关联键**（业务表落库）；
- `url` 仅用于上传后即时预览，**不要落库、不要持久化到业务字段**（规范 §5 三-5：url 为回显快照，不作一致性依据）。

## 五、错误码

| 码 | 含义 |
| --- | --- |
| `1_060_101_020` | 文件不存在或未登记存储坐标（fileId={}） |
| `1_060_101_021` | 文件未通过病毒扫描，禁止预览/下载（virusStatus=INFECTED） |
| `1_060_101_022` | 文件存储坐标解析失败（地址非法或非本平台文件服务） |
| `1_060_101_023` | 文件内容读取失败，请稍后重试 |
