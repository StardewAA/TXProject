| 端点 | 风险 |

**本次已全部补齐权限**（模板类→`:import` 码；数据读类→`:query` 码；不新增权限点，前端无需改）。

### 原因 2：**同一个动作，权限码不统一**

| 现象 | 例子 | 说明 |
| --- | --- | --- |
| 有动作后缀 | `bidding:certificate:query` `create` `update` | 规范写法 |
| **无动作后缀** | `bidding:certificate:file` `qualification:element` `qualification:standard` `qualification:permit` | 一个码管一个子域的全部动作 |
| **动作混用** | `qualification:create` 同时管 `POST /create` 与 `PUT /update` | update 用 create 的码 |
| 多权限任一 | `hasAnyPermissions('...:query','...:element')` | 两个码任一即可 |

**这就是"搞不懂怎么用"的根源**——同一件事在不同子域走不同规则。

### 原因 3：**没有"操作人视角"的出口**

- 证照域**没有**独立的历史/操作日志接口（`/bidding/certificate` 下无 `history`/`log`）
- 操作人信息只在**跨域**的 `GET /bidding/flow/logs` 里，且**只覆盖状态机流转的域**
- 证照文件版本有"版本历史"（`/certificate/file/list`），但**没有"谁改的"**

## 三、"文件能不能回头查看"——根因与修复

### 你描述的现象
> 上传之后，刷新就不能查看了；能查看时也是直接下载，而不是预览。

### 根因（三条，都已定位）
1. **证照文件版本出参不含 url**（`CertFileVersionRespVO` 只有 `fileId/fileHash/size`…）
   —— 这是**规范要求**（红线 8：url 为回显快照、不作一致性依据；且原实现直出 DO 会外发 tenantId 等内部列）。
   后果：**上传瞬间前端手里有 url 能预览；一刷新只剩 fileId，无从预览**。
2. **旧兜底走 `/infra/file/get`** —— 需 `infra:file:query`，业务账号没有；且该端点 `Content-Disposition: attachment`（**强制下载**，不是预览）。
3. **缺"按 fileId 取文件"的业务出口** —— 这是平台 FileApi 从未对外设计的能力（`getFile(id)`/`getFileContent` 只在 infra 内部）。

### 修复（本次，仅电子证照域）
| 改动 | 效果 |
| --- | --- |
| 证照文件登记时**自动登记存储坐标**到 `bidding_file` | 刷新后仍可按 fileId 取文件 |
| 新增 `downloadable` 出参 | 前端据此**禁用**不可预览的按钮（不再点了才报错） |
| 新增 `previewUrl` 出参（业务受控地址） | 前端**直接用**，无需自己拼、也不是裸 url |
| 统一出口 `GET /bidding/file/download?id=` | **`inline` 内联预览**（PDF/图片直接看），非下载；无需 infra 权限 |

> 注：`previewUrl` 形如 `/admin-api/bidding/file/download?id=3072`——它是**业务出口**，不是对象存储裸 url（红线 8 不破）。

## 四、给你的"管理感"建议（前端侧，非后端改动）

你感觉"管不住"，很大程度是**界面没把关系摆出来**。基于后端能力，建议前端这样呈现：

1. **证照详情页固定"三块"**：主档（状态+乐观锁版本）｜**文件版本列表**（含`downloadable`+预览按钮）｜**生命周期流程**（apply→audit→effect 的状态）
2. **文件列表直接给预览按钮**：用 `previewUrl` + `downloadable`，悬浮显示 `virusStatus`（PENDING 标"待扫描"、INFECTED 标红不可点）
3. **状态用色**：`ACTIVE` 绿 / `EXPIRING_SOON` 黄 / `EXPIRED` 橙 / `SUSPENDED` 灰 / `REVOKED`·`CANCELLED` 红（**终态不给操作按钮**，因为状态机不允许流转）
4. **权限可见**：按用户实际权限码**隐藏**对应按钮（后端 84 端点已全部有码可依）
