## 二、逐子域接线清单（后端已实现，前端待接）

### 2.1 投标保证金 /admin-api/bidding/deposit

| 方法 | 路径 | 权限码 | 说明 |
|---|---|---|---|
| POST | /save | bidding:deposit:save | 登记（金额 <= 标段估算价*2%，条例26条；同标段同主体幂等；超额抛 1060116001；标段缺失 1060116002） |
| GET | /get | bidding:deposit:query | 详情（含 refundOverdue 超期标记） |
| GET | /page | bidding:deposit:query | 台账分页（招标方） |
| POST | /refund | bidding:deposit:refund | 退还（已退还再退抛 1060116003；合同签订后 5 日内退还，条例58条） |

- 请求（save）8 字段：bidSectionCode、subjectId、amount、currencyCode、payType、status、fileId、remark。
- 响应 15 字段（含 refundOverdue）。前端页面：招标方台账 + 投标方登记入口。

### 2.2 合同签署 /admin-api/bidding/contract

| 方法 | 路径 | 权限码 | 说明 |
|---|---|---|---|
| POST | /save | bidding:contract:save | 登记（履约保证金 <= 合同价10%，条例57条→1060103002；签约 <= 中标通知书 30 日，招投标法46条→1060103003） |
| GET | /get | bidding:contract:query | 详情 |
| GET | /page | bidding:contract:query | 台账分页 |

- 请求（save）11 字段：tenderProjectCode、bidSectionCode、contractCode、contractName、contractPrice、performanceBond、winNoticeTime、signTime、fileId、status、remark。
- 响应 13 字段。前端页面：招标方「合同登记」页。

### 2.3 定标书面报告 /admin-api/bidding/report

| 方法 | 路径 | 权限码 | 说明 |
|---|---|---|---|
| POST | /submit | bidding:report:submit | 提交（定标后 15 日内，招投标法47条；超期 warn 不阻断；记录不存在 1060117000） |
| GET | /get | bidding:report:query | 详情（含 awardTime=中标结果公告发布时间、reportOverdue） |
| GET | /page | bidding:report:query | 台账分页（reportOverdue 黄色标记） |

- 请求（submit）6 字段：tenderProjectCode、bidSectionCode、reportCode、reportName、fileId、remark。
- 前端页面：招标方「报告台账」+ 上传文件提交。

### 2.4 投标异议 /admin-api/bidding/objection

| 方法 | 路径 | 权限码 | 说明 |
|---|---|---|---|
| POST | /propose | bidding:objection:propose | 提出（资格预审文件 2 日前 / 招标文件 10 日前，条例22条；超期 1060118001） |
| POST | /reply | bidding:objection:reply | 答复（3 日内；已答复重复答 1060118002） |
| GET | /get | bidding:objection:query | 详情（replyOverdue 标记） |
| GET | /page | bidding:objection:query | 台账分页 |

- 请求（propose）6 字段：tenderProjectCode、bidSectionCode、objectionType（PREQUAL_FILE/TENDER_FILE）、subjectId、content、remark。
- 前端页面：投标方「提出异议」入口 + 招标方「答复/台账」。

### 2.5 资格预审 /admin-api/bidding/prequal（9 接口）

save / publish / close / get / page（招标方）+ apply / review / apply-list / apply-page（投标方/审查方）。

关键：publish 校验申请期>=5 日（条例17条，1060114002）；apply 校验截止前可交（1060114003）；通过者<3 家 warn 应重新招标（条例19条）。
