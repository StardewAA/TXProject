# 后端变更请求：平台审查任务中心（2026-09-20）

> 说明：本契约**替换**《后端变更请求-平台企业资质审查与录入方式扩展-2026-09-20.md》中的"平台人工审查"模型（其缺口 A2/A3/A4 作废）。
> 旧的"审查员按租户逐个点开查看"不再是审查方式；本改动将企业录入动作与审查动作解耦为**审查任务**。

## 1. 目标流程

企业（租户）在录入侧完成证照/资质建档后，**后端自动生成一条审查任务**，任务进入超管公司（平台）审查中心；
超管在公司共享的"平台审查中心"界面统一筛选并逐项审查（通过 / 驳回，驳回原因必填留痕）；
审查结果与原因**回传租户**，租户在同一界面只读查看**本企业**任务的状态与原因。

## 2. 数据模型（bidding_review_task）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint | 主键 |
| biz_type | varchar(32) | 业务类型：QUALIFICATION 企业资质 / CERTIFICATE 证照 / PERSON_CERT 员工证书 |
| biz_id | bigint | 关联业务主键（资质 id / 证照 id） |
| ent_id | bigint | 提交企业 id（索引，租户隔离维度） |
| ent_name | varchar(128) | 提交企业名称（快照，审查者可一眼区分来源企业） |
| ent_uscc | varchar(32) | 提交企业统一社会信用代码（快照） |
| ref_no | varchar(64) | 关联证书编号 / 资质证书编号（快照） |
| submit_time | datetime | 任务产生（企业录入）时间 |
| status | varchar(16) | PENDING 待审查 / APPROVED 已通过 / REJECTED 已驳回 |
| reviewer | varchar(64) | 审查人（通过/驳回后回填） |
| review_time | datetime | 审查时间（通过/驳回后回填） |
| reason | varchar(512) | 驳回原因（REJECTED 必填留痕，租户可见） |
| remark | varchar(512) | 提交时的备注（如有） |
| version | int | 乐观锁（§0.7：通过/驳回必须回传） |
| deleted | bit | 逻辑删除 |

索引：ent_id+status、status、submit_time。

## 3. 状态机

`PENDING 待审查 ──通过──▶ APPROVED 已通过`
`PENDING 待审查 ──驳回（reason 必填）──▶ REJECTED 已驳回`

补充口径：
- 驳回后企业可在录入侧修正并**重新提交**，产生**新的**审查任务（不覆盖原任务，历史可追溯）；
- 通过后该证照/资质**方可被其他接口引用**（配证 / 申报类接口）；
- 状态字典 review_task_status：PENDING 待审查 / APPROVED 已通过 / REJECTED 已驳回；
- 业务类型字典 review_biz_type：QUALIFICATION 企业资质 / CERTIFICATE 证照 / PERSON_CERT 员工证书。

## 4. 权限与租户隔离

| 权限码 | 归属 | 作用 |
|---|---|---|
| bidding:review:query | 超管 + 租户（共享） | 页面可见（菜单 60005600） |
| bidding:review:approve | 仅超管 | 审查通过 |
| bidding:review:reject | 仅超管 | 审查驳回 |

- 租户：page/get/stats **按当前登录租户过滤**，只能看到本企业任务；只读（前端不渲染任何审查操作）；
- 超管：跨企业查询，可按 企业关键字 / 业务类型 / 状态 / 提交时间范围 筛选；
- 后端 @PreAuthorize 逐接口校验（approve/reject 仅平台角色），不以前端隐藏为准。

## 5. 接口

| # | 方法与路径 | 权限 | 入参 | 出参 |
|---|---|---|---|---|
| 1 | GET /bidding/review-task/page | bidding:review:query | pageNo/pageSize/keyword(企业名或uscc)/bizType/status/beginTime/endTime | PageResult<ReviewTaskVO> |
| 2 | GET /bidding/review-task/get | bidding:review:query | id | ReviewTaskVO |
| 3 | GET /bidding/review-task/stats | bidding:review:query | 无 | { pending, todayNew, approved, rejected }（租户自动限定本企业） |
| 4 | POST /bidding/review-task/approve | bidding:review:approve | taskId/version | true（乐观锁，写接口 §0.7 静默处理） |
| 5 | POST /bidding/review-task/reject | bidding:review:reject | taskId/version/reason(必填) | true |

触发（后端在建档接口内自动完成，前端无单独创建入口）：
- 企业资质建档 POST /bidding/qualification/create 成功后 → 生成 biz_type=QUALIFICATION 任务；
- 证照建档 POST /bidding/certificate/create 成功后 → 生成 biz_type=CERTIFICATE 任务；
- 员工证书建档（如需超管审查；当前口径为租户自审，可不触发）。
