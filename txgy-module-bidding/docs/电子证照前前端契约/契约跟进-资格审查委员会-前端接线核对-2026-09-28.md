## 三、口径与验收

- 审查前置：国有资金项目（fund_source∈01/02/03）未组建委员会 → review 返回 1060115008，前端提示先组建（条例18条）；
- 组成校验：成员数须 5 人以上单数，技术/经济专家（TECH_EXPERT/ECON_EXPERT）≥ 2/3，不满足 1060115009；
- 委员会保存为整单覆盖（每次 save 用入参替换既有成员）；
- 项目登记资金来源下拉：有字典走字典（01 财政性资金 … 99 其他），无字典回退手填（不阻断存量自由文本）。

**验收清单**：
- [ ] 项目登记资金来源出现 fund_source 下拉（需后端已执行 SQL 下发字典）；
- [ ] 资格预审列表行操作出现「委员会」入口（bidding:prequal:committee 角色可见）；
- [ ] 打开委员会弹窗可添加成员（类别/角色/单位/职称/排序/备注）并保存（整单覆盖）；
- [ ] 国有资金项目未组建委员会点「通过/不通过」→ 提示先组建（1060115008）；
- [ ] 成员不足 5 人或专家不足 2/3 保存 → 提示组成不合规（1060115009）。
