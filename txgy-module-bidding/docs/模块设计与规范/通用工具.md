###  招标文件编制工具（招标人/代理机构专用）

- **文件编辑器**：制作资格预审文件、招标文件等，常内置标准化模板和智能编辑功能。
- **公告公示发布工具**：在线生成并发布招标公告、中标候选人公示等。
- **工程量清单/评标办法管理**：编制、管理工程量清单，并支持设置价格、技术等评分标准。

### 📦 投标文件编制工具（投标人专用）

- **响应文件编辑器**：投标人用来制作投标文件。
- **工程造价/资质核验**：辅助核验报价，并内置企业信息库以快速引用资质。
- **离线制作与加密**：支持离线制作投标文件并进行电子签章和加密。

### 🚀 开标工具（不见面开标辅助）

- **远程开标支持**：支持在线开标、解密、唱标等全流程。
- **智能辅助功能**：包括直播、语音唱标、开标一览表自动生成、开标结果回传等。
- **现场辅助设备**：常配套自助签到机、自助解密机等硬件。

### 📊 评标工具（专家/监督部门专用）

- **评审终端**：提供专家打分、投标文件比对等功能。
- **智能辅助评标**：自动分析投标文件、给出初步评审结果。
- **围串标分析**：分析投标文件相似度、识别异常规律。
- **远程异地评标**：支持跨地域专家在线评审。

### 🧩 其他通用工具与功能模块

- **电子档案管理系统**：自动归档招投标全流程文件。
- **数字见证系统**：对开评标过程进行音视频见证。
- **专家管理与抽取**：管理专家库并进行在线抽取。
- **排斥潜在投标人检查**：自动检测招标文件中可能存在的限制性条款。
- **数据统计分析**：进行交易数据统计、分析并生成报表。
- **CA数字证书/电子签章**：用于身份认证、文件加密、电子签章等。
