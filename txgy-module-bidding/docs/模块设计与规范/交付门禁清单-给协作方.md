## 二、架构门禁（`txgy-module-bidding-server/src/test/.../arch/`）

| 门禁 | 守什么 | 违反后的真实后果（都发生过） |
| --- | --- | --- |
| `BiddingArchitectureRulesTest` | 分层/命名/依赖方向等架构约束 | 破坏分层后越权访问、循环依赖 |
| `ErrorCodeFormatTest` | 错误码格式与唯一性 | 码值冲突，前端按码分支失效 |
| `AlertListEndpointGateTest` | 预警清单端点/4 个 VO/2 个服务方法必须存在 | 曾被整体删除：接口 404、页面打不开，而全量单测仍绿 |
| `NoHardcodedParamTest` | 阈值/口径必须走配置中心，禁止硬编码 | 业务阈值写死，运营改不动 |
| `RuleConfigAuditGateTest` | 规则配置读取必须留审计 | 判定点悄悄裸读，事后无法追溯 |
| `JobSafetyGateTest` | 调度任务安全性（默认关、dryRun 等） | 上线即误判，直接阻断投标 |
| `DeadServiceMethodGateTest` | 零调用者的服务方法必须登记理由 | 实现了但没有出口的假功能 |

> 以 `arch/` 目录实际文件为准；新增门禁请同步本表。

## 三、SQL 一键包不变式（`sql/tools/check-package-invariants.js`）

**构建期自动执行**（`build-credential-sync.js` 末尾调用），不通过即中止构建。

| # | 不变式 | 真实事故 |
| --- | --- | --- |
| ① | 建表语句的 id 必须 AUTO_INCREMENT | 应用不自生成主键 ⇒ 一切写操作失败 |
| ② | 列定义必须有行尾逗号 | 折叠 ALTER 丢逗号 ⇒ 包在第 184 行语法错误、整包中断 |
| ③ | 列定义不得含 AFTER/FIRST | 只在 ALTER 合法，折进 CREATE 报 near AFTER |
| ④ | 不得用 ADD COLUMN IF NOT EXISTS | MariaDB 专有语法，MySQL 不支持 |
| ⑤ | ALTER 的目标表必须由本包创建 | 跨域脚本混入 ⇒ 干净库必然失败 |
| ⑥ | 种子 INSERT 必须显式带 id | 该表主键非自增 ⇒ 报 no default value |

其余自检（`sql/tools/`，可用 `check-all.js` 串跑）：镜像完整性、权限码三处一致、字典覆盖、接口覆盖、
DO 列/表一致性、类型对等、内部术语、单位语义、前端影子字段等。

## 四、并发编辑约定（强烈建议）

1. **同一文件同一时间只由一方修改**；必须并行时先在本页登记"正在改 X"，改完释放；
2. **不要整文件覆盖**：本轮四次事故里三次是"整文件写成旧版本"导致的（整块端点消失）；
3. **改生成器要连带跑构建**：生成器里的修复逻辑有独立自检守着；
