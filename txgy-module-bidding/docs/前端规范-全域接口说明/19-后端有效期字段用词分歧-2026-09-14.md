# 契约 19：同一个 `validTo` 字段，后端 Schema 用词分叉（有效期至 / 有效期止）

- 提出方：前端（招投标前端）
- 日期：2026-09-14
- 影响面：资质台账、证照台账/表单/生命周期/材料核对、人员台账（**新装库/联调时用户看到的字段名**）
- 期望交付：后端（**前端不改后端**）

## 1. 现象（实测证据）

同一个"有效期到某日"的概念，后端 `@Schema(description)` / DDL 注释里两种写法并存：

| 写法 | 出现处（实测） |
|---|---|
| **有效期止** | `CertLifecycleApplyReqVO.newValidTo`（"续期后有效期止"）、`CertLifecycleRespVO.oldValidTo/newValidTo`、`QualificationPermitRespVO.validTo`、`PersonnelCertRespVO.validTo`/`idCardValidTo`/`certValidTo`、`NoticeExternalMeta.validTo`、`CertificateXxx` 生命周期系 VO |
| **有效期至** | `CertificateRespVO.validTo`（"有效期至（NULL=长期）"）、`QualificationRespVO.validTo`（"有效期至（null=长期）"）、`SafetyPermitRespVO.validTo`（"有效期至（3 年一延续）"）、`SubjectProfileVO.validTo`、`CertFileVersionRespVO.copyExpiringTime`（"复制件有效期至"） |

**关键点：同一个字段名 `validTo` 在不同 VO 里被写成两种词**（例如 `QualificationRespVO` 写"有效期至"、
而材料核对 VO 写"有效期止"）。前端此前**逐字段忠实照抄**，于是资质台账同一页里出现了
「有效期至」（主档列，源自 QualificationRespVO）与「有效期止」（材料核对列）**并存**——这不是前端自造的，是照抄的结果。

## 2. 前端本轮的处理（已改）

按"同一概念一个界面词"的原则，前端**统一为「有效期至」**（理由：中文日期区间习惯"有效期自 … 至 …"；
且台账/主档类 VO——`CertificateRespVO`/`QualificationRespVO`/`SafetyPermitRespVO`——用的都是"至"）：

| 文件 | 改前 | 改后 |
|---|---|---|
| qualification/index.vue | 有效期**止**（材料核对列，与同页主档列的"至"冲突） | 有效期**至** |
| certificate/modules/cert-form.vue | 表单 label "有效期止" | "有效期至" |
| certificate/modules/lifecycle-apply.vue | 台账字段名/校验提示/新有效期止（3 处） | 全部"有效期至" |
| certificate/modules/material-check.vue | 列名 "有效期止" | "有效期至"（注释同时标注后端两种写法） |
| certificate/index.vue | KPI 说明"无有效期止，不入到期扫描" | "无有效期至…" |
| personnel/index.vue | 表单 "有效期止" | "有效期至" |

**未改**：`certificate/modules/cert-files.vue` 的「加注有效期至」——它对应 `copyExpiringTime`（复制件/加注件的有效期），
与证书本身的 `validTo` 是**两个不同字段**，后端用词也不同，保留区分。

## 3. 请后端裁定（二选一）

① **统一为「有效期止」或「有效期至」其一**（推荐"有效期至"，与台账类 VO 现状一致），前端跟随；
   涉及 `@Schema(description)`、DDL `COMMENT`、以及一键包历史脚本里的字段说明。
② 若认为两种词**确有区分**（例如"止"用于生命周期回写、"至"用于台账展示），请在 04/08 号契约里写明分界，
   前端将按字段分别呈现（当前已按①统一，若②成立需要回退部分文案）。

## 4. 前端验收口径

后端统一后：`grep -rn "有效期止" txgy-ui-admin-vben/apps/web-antd/src` 应**为空**（当前仅剩注释里的后端用词说明）；
术语表（`17-前端术语表-2026-09-14.md`）中"有效期至"一行无需再附分歧说明。
