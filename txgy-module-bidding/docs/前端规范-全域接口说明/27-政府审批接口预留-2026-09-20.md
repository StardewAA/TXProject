# 27. 政府审批接口预留 —— 2026-09-20

## 1. 背景

招标全流程中四个环节需要政府/监管审批（项目立项、招标方案、终止、公告审核），**政府审批系统接口尚未建设**。
按用户裁定：**预留接口**，当前实现为 stub **直接返回通过**；接入真实政府审批/监管平台后替换实现，**调用方契约不变**。

## 2. 接口契约

| 项 | 值 |
|---|---|
| 端点 | POST /admin-api/bidding/flow/approval（网关 48080） |
| 权限 | bidding:flow:approval（菜单 sql/history/2026-09-20-flow-domain.sql 已登记） |
| 幂等 | @Idempotent |
| 说明 | 政府审批回调：对指定审批对象给出审批结论 |

## 3. 请求体（GovernmentApprovalReqVO）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| bizType | string | ✅ | 审批对象类型：PROJECT 项目立项 / TENDER_PROJECT 招标方案 / TERMINATION 终止审批 / ANNOUNCEMENT 公告审核 |
| bizId | string | ✅ | 审批对象业务标识（实体 id 或业务编号） |
| action | string | ✅ | APPROVE 通过 / REJECT 驳回 |
| operator | string | ❌ | 审批人（政府侧账号） |
| remark | string | ❌ | 审批意见 |

示例：

```json
{ "bizType": "PROJECT", "bizId": "2100016652328599554", "action": "APPROVE", "operator": "监管岗-张工", "remark": "同意" }
```

## 4. 响应体（GovernmentApprovalRespVO）

| 字段 | 类型 | 说明 |
|---|---|---|
| approved | boolean | true=审批通过 / false=驳回 |
| approvalNo | string | 审批文号（stub 生成 GOV-STUB-时间戳-类型-业务号；真实系统返回后回填） |
| approvedTime | datetime | 审批时间 |
| message | string | 审批意见/结果说明 |
| stub | boolean | true=当前为预留 stub 实现 |

## 5. stub 行为（当前）

- action=APPROVE → approved=true；action=REJECT → approved=false（驳回同样可用以测试驳回流程）。
- 直接返回审批结论，不落库、不推进实体状态（服务层动作方法接入后，由调用方在审批通过后自行推进状态）。
- 参数校验照常（bizType 非法 / bizId 空 / action 非法 → 错误码 1-060-111-001/002/003），避免脏调用。
- 实现类：GovernmentApprovalServiceImpl（service/flow），标注「预留 stub，接入真实审批系统后替换」。

## 6. 接入真实审批系统的替换说明

1. 替换 GovernmentApprovalServiceImpl.approval：内部调用政府审批/监管平台网关（HTTP/WebService/消息），映射为统一的 GovernmentApprovalRespVO 返回。
2. 若审批为异步（政府侧受理后回调）：预留转人工回调端点（可基于本契约扩展 POST /bidding/flow/approval/callback），stub 阶段可用本端点模拟回推。
3. 审批通过后需要联动推进实体状态的动作（如项目 APPROVING→ACTIVE），由调用方（流程服务）在 approved=true 后执行，动作方法遵循状态机校验（契约 26 §5）。
4. 测试模式（bidding.flow.mode=TEST）下仍走本 stub，保证前端/联调不依赖外部系统。

## 7. 测试模式调用场景

- 项目立项审批：bizType=PROJECT, bizId=<项目id>, action=APPROVE → 通过后推进 APPROVING→ACTIVE（待落地）。
- 招标方案审批：bizType=TENDER_PROJECT, bizId=<招标项目id>, action=APPROVE → 推进 APPROVING→PREPARING（待落地）。
- 终止审批：bizType=TERMINATION, bizId=..., action=APPROVE → 推进 →TERMINATED / 标段 FAILED（待落地）。
- 公告审核（实战模式）：bizType=ANNOUNCEMENT, bizId=<公告id>, action=APPROVE → 推进 REVIEWING→PUBLISHED（待落地）。
