# 页面指标重合度实测与结论（2026-09-14）

- 缘起：前端自查提出假设——"资质台账 / 证照台账 / 安全风险 / 人员台账 四页指标重合，功能划分不清"。
- 方法：只读测量。提取各页**界面文案标签**（title/label/a-statistic/正文短标签）、"天数"阈值、跨页 import 的组件，
  再做交集。脚本方式与"术语报告工具"一致（`sql/tools/report-terminology.js` 同族）。
- **结论：假设不成立**——四页的指标名重合度很低，跨页共用的标签绝大多数是"操作/状态/刷新/查询/重置"这类**工具按钮**，
  不是业务指标。**因此不合并页面**（依据见下）。

## 1. 实测数据

| 页面 | 界面标签数 | 跨页共用标签 |
|---|---|---|
| 资质台账 `qualification/index.vue` | 128 | 部分（多为工具按钮） |
| 人员台账 `personnel/index.vue` | 95 | 同上 |
| 证照台账 `certificate/index.vue` | 36 | 同上 |
| 证照生命周期 `certificate/lifecycle/index.vue` | 17 | 同上 |
| 安全风险 `safety-risk/index.vue` | 13 | 同上 |

跨页共用的 22 个标签里，**19 个是通用 UI 词**（操作/状态/刷新/查询/重置/来源/结论/编辑/详情/类型/备注…），
业务指标级重合仅 3 个（有效期/等级/风险），且均为不同实体的同名字段（资质等级 vs 人员等级；企业风险 vs 人员风险）。

**共同复用组件只有 1 个**：`certificate/modules/safety-risk.vue`，被"安全风险"页与"人员台账"页同时 import。

## 2. 那个唯一复用是**合理**的（已取证，不改）

- `safety-risk/index.vue` 头注释写明："① 安许 A/B/C 风险卡片——**直接复用**证照域组件"（有意复用，非重复实现）；
- 组件入参只有 `entId`（企业维度）；人员台账页在 `<SafetyRisk :ent-id="countEntId">` 上方**紧挨着企业选择器**
  与"统计可用持证人数"按钮，上下文清楚，不会被误读成人员维度；
- 因此**不做**"去重/迁页"，只在本报告登记：若将来人员页的该卡片要按人员维度展示，需后端补人员维度出参（现无）。

## 3. 本轮顺带发现并修掉的真矛盾

**同一个字段 `validTo` 在资质台账一页内出现两种列名**（「有效期至」与「有效期止」），
根因是**后端 VO 对该字段有"至/止"两种写法**而前端逐字段照抄（证据与处理见
`19-后端有效期字段用词分歧-2026-09-14.md`）。前端已统一为「有效期至」并提交契约 19 请后端对齐。

## 4. 复跑方式

本报告的数据由一次性脚本产出；若需复跑，按第 1 节口径重写脚本即可（提取"引号内中文短标签 + 天数阈值 + 跨页 import"）。
**不设门禁**：页面分工属业务判断，硬编码阈值会把"不同实体的同名字段"误判成重复（本次实测就是这个风险）。
