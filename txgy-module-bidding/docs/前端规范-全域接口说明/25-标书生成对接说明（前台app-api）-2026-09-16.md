# 标书生成对接说明（前台/门户 · app-api）

> 版本：2026-09-16 ｜ 归属：招投标模块 `bidagent` 子域 ｜ 面向：前台「标书制作」页开发同学
>
> 一句话：前台只调本模块的 app-api，不感知执行底座（Node bid-agent-service）与任何模型密钥；网关已具备 `/app-api/bidding/**` 路由，无需新增配置。

## 1. 鉴权与隔离

| 项 | 值 |
|---|---|
| 前缀 | `/app-api/bidding/bid-agent/task/**` |
| 鉴权 | 登录态（`isAuthenticated()`）；本期不额外要求权限码，若要细分可再加 `bidding:bid-agent:generate:*` |
| 租户 | 从登录态取租户；任务只返回本租户数据，跨租户按「不存在」处理 |
| 幂等 | 写接口均带 `@Idempotent`（1 秒同参窗口），前台无需传幂等头 |

## 2. 接口清单

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/task/generate` | 一键生成标书。body：`projectId`（必填）、`bidSectionCode`（必填）、`tenderMaterialId?`（空=按标段自动选唯一 TENDER 材料）、`templateMaterialId?`（空=跳过模板回填）、`force?`、`remark?`；返回任务 id |
| GET | `/task/get?id=` | 任务详情：`status`(PENDING/RUNNING/SUCCEEDED/FAILED/CANCELED)、`currentStep`(PARSE/OUTLINE/DRAFT/FILL)、`progress`、`openQuestionsJson`（待确认清单）、`artifactUrl`、`errorMessage` |
| GET | `/task/page` | 分页：`projectId?`、`status?`、`pageNo`、`pageSize` |
| POST | `/task/cancel?id=` | 取消（仅 PENDING/RUNNING） |
| POST | `/task/retry?id=` | 重试（仅 FAILED/CANCELED） |
| GET | `/task/outline?id=` | 章节树（`outlineJson`）与章节正文（`chapters[]`） |
| GET | `/task/artifact?id=` | 标书产物下载地址（docx；未生成时报错） |

```bash
curl -X POST 'http://127.0.0.1:48080/app-api/bidding/bid-agent/task/generate' \
  -H 'Content-Type: application/json' -H 'Authorization: Bearer <登录态>' -H 'tenant-id: 1' \
  -d '{"projectId":123,"bidSectionCode":"SEC-001","templateMaterialId":456}'
```

## 3. 状态与交互建议

| status | 前台表现 |
|---|---|
| PENDING/RUNNING | 进度条 + `currentStep` 文案（解析招标要点 / 生成章节大纲 / 撰写正文 / 回填模板）；建议 3~5 秒轮询 `task/get` |
| SUCCEEDED | 「下载标书」（`artifact`）与「查看章节」（`outline`）；`openQuestionsJson` 非空时醒目列出"待人工确认清单" |
| FAILED | 显示 `errorMessage` + 「重试」；同标段已有进行中任务时返回 `1_060_111_092` |
| CANCELED | 可「重试」 |

## 4. 前置条件（不满足时的表现）

1. 该标段需有**已入库**的招标文件材料（知识库管理 → 资料库，`indexStatus=1`）；否则 `1_060_111_094`。
2. 后台「智能体管理 → 云端模型」需**启用**一条配置；否则执行侧回退底座 `.env` 兜底模型，或报 `1_060_111_080`。
3. 执行底座（Node `bid-agent-service`，默认 `127.0.0.1:8199`）需在线；否则 `1_060_111_086`。
