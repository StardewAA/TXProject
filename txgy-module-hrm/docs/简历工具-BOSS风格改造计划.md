# HRM 简历工具改造计划

## 1. 已确认的产品要求

- 简历工具四张卡片严格使用图二文字：`AI简历 / 智能简历生成`、`在线编辑 / 匹配优质岗位`、`附件简历制作 / 打造HR的专业简历`、`附件上传 / 快速投递心仪职位`。
- AI 简历和附件简历制作点击后使用站内同标签页跳转，不打开新窗口，不跳转第三方域名。
- AI 页面参考 BOSS 直聘公开的简历工坊问答流程；附件页面参考 BOSS 直聘公开的模板选择、实时编辑和导出流程。
- AI 生成内容必须来自求职者输入和 HRM 已保存的求职资料，联系方式沿用个人资料，不交给模型编造。
- 附件简历支持模板切换、字段编辑、重复经历增删、实时预览、Word 下载和保存后投递。

## 2. 前端实施

### AI 简历页

1. 保留路由 `/portal/recruit/resume/ai`，使用站内同标签页跳转。
2. 不采用 BOSS 首页的对话式制作首屏；采用深色品牌导航和 AI 工作台。
3. 导航直接提供“简历模板、简历分析、我的简历、AI简历助手”四个入口，其中 AI 简历页聚焦结构化资料填写、生成和编辑。
4. 已填写的在线求职资料自动带入，用户可以继续编辑目标职位、城市、教育、经历、项目、技能和优势。
5. 调用 `POST /hrm/portal/recruit-agent/resume/generate`，查询任务结果后展示结构化草稿。
6. 草稿中的标题、简介、技能、工作经历、项目经历、教育经历均可编辑、添加、删除。
7. 确认后调用简历版本接口，保留版本号、来源和幂等键；模型失败时显示明确原因，不展示模拟内容。

### 附件简历页

1. 保留路由 `/portal/recruit/resume/attachment-builder`，使用站内同标签页跳转。
2. 采用深色品牌导航、蓝绿色工作区和左编辑右预览布局。
3. 提供模板分类、模板切换、基础资料、优势技能、工作经历、项目经历、教育经历编辑。
4. 编辑内容实时映射到预览；支持下载 Word，生成文件上传到 HRM 文件接口并登记为附件简历。
5. 保存后可在投递选择器中使用，上传文件只允许 HRM 招聘文件接口接收的类型和大小。

## 3. 后端与数据库

- 复用 HRM Agent 任务表和 `RESUME_GENERATE` 场景，服务端校验结构化结果，禁止虚构公司、时间、学历、证书、技能、数字成果和联系方式。
- 复用 `hrm_personal_resume`：`resume_type=1` 表示附件简历，`source_type=2` 表示制作生成，`file_url/file_name/content` 保存文件和可编辑快照。
- 复用 `hrm_personal_resume_version` 保存 AI 草稿确认后的不可变版本，按用户隔离并使用幂等键避免重复版本。
- 复用 HRM 本地文件接口 `/hrm/portal/recruit/file/upload` 和 `/hrm/portal/recruit/file/{fileName}`，不修改公共文件服务、登录注册、IM 或其它业务模块。
- 若部署环境未配置 AI 模型，接口返回失败原因；页面不得回退到假数据。

## 4. 验证与验收

- 前端：Vite 热更新下验证两个路由、同标签页跳转、桌面/移动端布局、浏览器控制台无本次新增错误。
- 交互：验证 AI 生成任务成功/失败、草稿编辑与版本保存、模板切换与实时预览、Word 下载、附件保存。
- 后端：运行 HRM 定向单元测试和结构化结果校验测试；确认用户归属、租户隔离、文件类型和大小校验。
- 数据：确认在线简历不被 AI 生成覆盖，附件简历和简历版本可在投递记录中读取。
