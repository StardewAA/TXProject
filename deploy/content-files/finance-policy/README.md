## 二、数据落库位置（导入后）

| 表 / 索引 | 说明 |
|---|---|
| `cms_document_review` | 政策审查记录（30 条） |
| `cms_knowledge_document` | 知识库文档（doc_category=FINANCE_POLICY，30 条） |
| `cms_knowledge_chunk` | 文档切片（默认 SEMANTIC / 800 字 / 重叠 80，111 条） |
| `cms_finance_policy_ext` | 金融政策结构化扩展：适用地区/行业/企业类型、支持方式、金额区间、支持比例、申报起止时间（30 条） |
| ES `txgy-cms-finance-policy-v1-000001` | 检索索引（111 个切片，含 dense_vector 字段） |

原件访问路径：`/files/finance-policy/<文件名>`（由前端 Nginx 映射 `deploy/content-files`）。

## 三、整库还原步骤

```bash
# 1) 建表
mysql -uroot -p ruoyi-vue-pro < sql/cms_finance_policy.sql
# 2) 恢复数据（含 30 份政策 + 111 切片 + 结构化扩展）
mysql -uroot -p ruoyi-vue-pro < sql/cms_202609203000.sql
# 3) 建 ES 索引模板
curl -X PUT "http://127.0.0.1:9200/_index_template/txgy-cms-finance-policy" \
     -H 'Content-Type: application/json' \
     --data-binary @deploy/elasticsearch/cms-finance-policy-index-template.json
# 4) 原件放到本目录（deploy/content-files/finance-policy/）
# 5) 后台「发布管理 → 重建检索索引」，或调 POST /admin-api/cms/knowledge/reindex
```

> 也可以不解压 SQL，直接用导入脚本重建：
> `python tools/import_finance_policy_pdfs.py --apply`（需先配好 MySQL / ES 连接）

## 四、ES 索引数据导出
