# 商城迁移待对接项

以下代码已保留商城侧适配入口，但未绑定正式项目的外部系统实现：

1. WMS：仅查询商品规格、销售价及现存库存，不允许商城直接锁定、出入库或写 WMS 表。
2. ERP：统一负责库存预占、释放、出库、退货入库；商城已提供持久化请求、独立测试模拟及默认关闭的回传契约，真实 ERP 发送器待对接。询报价、采购/销售单等仍按各自协议对接。
3. 物流：运单创建、轨迹查询、签名鉴权和回调。
4. 支付：正式/沙箱支付、退款、回调验签和幂等规则。
5. 通知：短信、邮件、企业微信等差异告警通道。

在对接方确认接口地址、字段、鉴权、错误码及幂等规则前，不执行正式数据库脚本，也不启用对应定时任务。

商城本地 ERP 请求/模拟账本的新增表不涉及正式 ERP/WMS 数据，实施与验证说明见
[WMS只读与ERP库存履约适配](../docs/mall-wms-readonly-erp-inventory-20260912.md)。
