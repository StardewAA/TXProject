## 1. 背景与目标

### 1.1 业务背景

防腐保温工程项目的销售流程为：**线索 → 客户 → 商机 → 报价 → 合同 → 回款**。

其中「报价」是承上启下的关键环节：销售人员在商机赢单后，需要向客户出具正式报价单，明确产品名称、规格、单价、数量、整单折扣与最终报价金额；报价经内部审批通过后，可直接转为合同，进入后续履约与回款环节。

### 1.2 业务目标

1. **规范化报价**：统一报价单模板与编号规则，避免线下 Excel 报价难以追溯。
2. **提效**：支持从商机/客户快速带出信息；支持「一键识别」把聊天记录、名片、报价图片自动解析成报价单。
3. **可控**：报价需经审批流审批，审批通过后才允许转为合同。
4. **可追溯**：完整记录审批状态、审批流程、关联合同，支持操作日志与数据权限隔离。

## 2. 名词术语

| 术语 | 说明 |
|---|---|
| 报价单 | 面向客户出具的报价凭证，含产品明细与金额 |
| 报价单号 | 系统自动生成的唯一编号，格式 `BJ + yyyyMMdd + 6位序号`（例：`BJ20260825000001`） |
| 产品总金额 | 明细行「报价价格 × 数量」的合计 |
| 整单折扣 | 对产品总金额的整体折扣百分比（0~100） |
| 折扣后金额 | 最终报价金额 = 产品总金额 − 产品总金额 × 整单折扣% |
| 赢单客户 | 存在 `endStatus = 1`（赢单）商机的客户，可作为报价对象 |
| 自填客户 | 客户名称不在赢单客户列表中时，手工输入，系统自动创建客户档案 |
| 一键识别 | 粘贴文本或上传图片，自动解析出客户/联系人/产品并填充报价单 |
| 场景 | 数据权限维度：我负责的 / 我参与的 / 下属负责的 |

### 5.4 新增报价单

入口：列表页「新增」按钮（权限 `crm:quotation:create`）。

**基础信息表单**：

| 字段 | 控件 | 必填 | 规则说明 |
|---|---|---|---|
| 报价单号 | 输入框 | — | 禁用，提示「保存时自动生成」 |
| 报价名称 | 输入框 | ✅ | 自由输入 |
| 负责人 | 下拉（用户列表） | ✅ | 默认当前登录用户；**编辑时禁用** |
| 客户名称 | 自动完成 | ✅ | 见 5.4.1 |
| 商机名称 | 下拉 | — | 见 5.4.2 |
| 报价日期 | 日期选择器 | ✅ | `YYYY-MM-DD`，毫秒时间戳提交 |
| 有效期至 | 日期选择器 | — | 同上 |
| 备注 | 多行文本 | — | 4 行 |

#### 5.4.1 客户名称（核心规则）

客户名称采用「**可选择 + 可自填**」的自动完成控件：

- **下拉选项**：系统内**赢单客户**（存在 `endStatus = 1` 商机的客户），选项 `value` 使用客户名称，保证选中后输入框展示客户名称。
- **点击下拉按钮**可展开选择赢单客户；无赢单客户时展示提示「暂无赢单客户，可直接输入新客户名称」。
- **自填**：可直接输入新客户名称。
- **提交处理**：
  - 名称能匹配到赢单客户 → 携带该客户编号 `customerId`；
  - 匹配不到 → 仅提交 `customerName`，**由后端自动创建客户档案**（客户名称 + 归属负责人）。
- 新增与修改**均支持**自填建客户。

> 实现要点（已知坑）：
> - 商机精简接口 `/crm/business/simple-all-list` **不返回 `endStatus`**，必须用分页接口 `/crm/business/page` 才能取到完整的赢单状态。
> - `AutoComplete` 为 combobox 模式，**选项为空且未设 `notFoundContent` 时 antd 会强制关闭下拉**，必须显式设置 `notFoundContent` 并开启 `showArrow`，否则下拉按钮点了没反应。

#### 5.4.2 商机名称（联动）

- 依赖项为客户名称。
- 仅当客户名称能解析出系统客户编号（即选中了赢单客户）时，商机下拉才**可用**；否则禁用并提示「请先选择赢单客户」。
- 选项为该客户名下的商机列表。

#### 5.4.3 产品清单

以可编辑表格形式录入明细行：

| 列 | 说明 |
|---|---|
| 产品名称 | 从产品库选择 |
| 产品单价 | 带出产品标准售价 |
| 报价价格 | 本次报价实际单价，可改 |
| 数量 | |
| 小计 | 报价价格 × 数量，自动计算 |

**校验规则**：
- 产品必须存在；
- 产品**不能为已禁用状态**（禁用产品不可用于报价）。

#### 5.4.4 金额

| 字段 | 规则 |
|---|---|
| 产品总金额 | 明细小计合计，`≥ 0`，保留 2 位小数 |
| 整单折扣（%） | `0 ~ 100`，保留 2 位小数 |
| 折扣后金额 | **自动计算且禁用**：`产品总金额 − 产品总金额 × 整单折扣 ÷ 100` |

### 5.5 编辑报价单

- 入口：列表行「编辑」（权限 `crm:quotation:update`）。
- **前端显示条件**：仅 `审批状态 = 未提交(0)` 显示编辑按钮。
- **后端校验**：仅「未提交(0)」「审批中(10)」允许更新，其余状态抛 `报价单更新失败：非草稿状态` 异常。
- 编辑时：
  - 报价单号不可改；
  - **负责人不可改**（负责人字段禁用，后端亦强制清空传入的负责人）；
  - 回显客户名称，且**缓存客户名称与编号映射**，避免把已关联客户误判为新客户。

### 5.6 一键识别（智能解析）

入口：新增/编辑表单中的「一键识别」按钮，弹出识别弹窗，含两个 Tab。

#### 5.6.1 粘贴文本（推荐，最准确）

粘贴微信聊天 / 名片 / 邮件文本，点击「智能解析并填充」。

支持识别的字段与规则：

| 字段 | 识别方式 |
|---|---|
| 客户名称 | `客户名称/客户/公司名称/公司名/公司/单位/甲方` 标签取值；或含「公司/集团/厂/中心/店/院/所」的词 |
| 联系人 | `联系人/姓名/名字` 标签；或含「经理/老师/先生/女士/总监/主任/总/工」的词 |
| 电话 | `联系电话/电话/手机号/手机/联系方式` 标签；或 11 位手机号 |
| 邮箱 | 邮箱格式 |
| QQ | `QQ` 标签 + 5 位以上数字 |
| 地址 | `地址/住址/地点/所在地/收货地址` 标签；或含「路/街/号/区/县/市/省/镇/村/栋/楼/室」的词 |
| 产品行 | 行格式「名称 数量 单价」或「名称 x数量 x单价」，支持行首序号（如 `1. 商品 20 350`） |

**文本归一化处理**（提升容错）：
- 统一换行符（CRLF → LF）；
- 全角字符转半角（含全角冒号、逗号、数字、字母）；
- 合并 OCR 在汉字之间插入的多余空格（仅合并行内空格，不吞换行）；
- `Q Q` → `QQ`。

**填充结果**：
- 报价名称：自动用「客户名 + 报价单」拼接；
- 报价日期：今天；
- 有效期至：今天 + 7 天；
- 备注：自动拼接触联系人/电话/邮箱/QQ/地址；
- 产品：按名称匹配系统产品，**仅匹配成功的产品进入清单**（未匹配的产品被过滤）。

#### 5.6.2 图片 OCR 识别

- 上传报价单/名片图片，使用 `tesseract.js`（`chi_sim + eng`）识别图中文字；
- 识别前做**图像预处理**：灰度化 + 放大至长边约 1600px，以提升中文识别率；
- 识别完成后自动填入文本框并**自动触发解析**；
- 识别失败提示「图片识别失败，请尝试粘贴文本」。

> ⚠️ 已知限制：浏览器端 OCR 对中文识别率有限，**AI 生成图片中的文字无法识别**（非真实字形）。建议使用清晰、正对拍摄的真实图片（截图效果最佳），或直接使用文本粘贴。

### 5.7 提交审批

- 入口：列表行「提交审批」（权限 `crm:quotation:update`），仅 `审批状态 = 未提交(0)` 显示。
- 提交后报价单进入 BPM 审批流，`auditStatus` 变更为「审批中(10)」，并记录 `processInstanceId`。
- 审批结果通过 BPM 回调（`CrmQuotationStatusListener`）写回：
  - 通过 → `审核通过(20)`
  - 拒绝 → `审核不通过(30)`

### 5.8 转为合同

- 入口：列表行「转为合同」（权限 `crm:quotation:update`）。
- **显示条件**：`审批状态 = 审核通过(20)` 且**尚未生成过合同**（`contractId` 为空）。
- 操作前二次确认：「确认将报价单【xxx】转为合同？」
- 成功后生成合同草稿，并**跳转到合同详情**；报价单记录 `contractId`。

### 5.9 查看审批

- 入口：列表行「查看审批」。
- **显示条件**：`审批状态 ≠ 未提交(0)` 且存在 `processInstanceId`。
- 跳转 BPM 流程实例详情页。

### 5.10 删除

- 入口：列表行「删除」（权限 `crm:quotation:delete`），二次确认后删除。

### 5.11 导出

- 入口：列表工具栏「导出」（权限 `crm:quotation:export`）。
- 导出当前搜索条件 + 当前场景下的数据，文件名 `报价单.xls`。

### 5.12 转移

- 接口 `PUT /crm/quotation/transfer` 已实现（权限 `crm:quotation:update`），用于变更报价单负责人。
- ⚠️ 列表页**暂无转移入口**，待补充。

### 5.13 报价单详情

独立详情页（路由 `CrmQuotationDetail`），展示：

- 基本信息：报价单号、报价名称、客户、商机、负责人、报价日期、有效期至、备注、审批状态；
- 产品明细列表；
- 金额汇总（产品总金额、整单折扣、折扣后金额）；
- 关联信息：关联合同、审批流程。

### 5.14 关联跳转

列表中以下字段可点击跳转对应详情：

- 报价名称 → 报价单详情
- 客户名称 → 客户详情
- 商机名称 → 商机详情（无商机时不跳转）

## 7. 业务规则

### 7.1 编号规则

- 保存时由 Redis 序号生成器自动生成；
- 格式：`BJ` + `yyyyMMdd` + 6 位流水号，例：`BJ20260825000001`；
- 前端报价单号输入框禁用，仅展示。

### 7.2 客户处理规则

1. 客户名称必填；
2. 优先从「赢单客户」下拉选择；
3. 自填名称且系统无匹配客户 → **自动创建客户**，归属负责人取报价单负责人（编辑时取原报价单负责人）；
4. 新增与修改均走同一逻辑（`resolveCustomerId`）。

### 7.3 金额计算规则

```
明细小计     = 报价价格 × 数量
产品总金额   = Σ 明细小计
折扣后金额   = 产品总金额 − (产品总金额 × 整单折扣 ÷ 100)
```

- 金额统一保留 2 位小数；
- 折扣后金额由系统计算，**前端禁用手工输入**。

### 7.4 审批状态机

| 值 | 名称 | 说明 |
|---|---|---|
| `0` | 未提交（草稿） | 可编辑、可提交审批 |
| `10` | 审批中 | 审批流处理中 |
| `20` | 审核通过 | 可转为合同 |
| `30` | 审核不通过 | 需修改后重新提交 |
| `40` | 已取消 | |

```
未提交(0) --提交审批--> 审批中(10)
审批中(10) --审批通过--> 审核通过(20) --转为合同--> 生成合同草稿
审批中(10) --审批拒绝--> 审核不通过(30)
```

### 7.5 操作权限约束

| 操作 | 前端显示条件 | 后端校验 |
|---|---|---|
| 编辑 | `auditStatus = 0` | 允许 `0` / `10` |
| 提交审批 | `auditStatus = 0` | — |
| 转为合同 | `auditStatus = 20` 且无 `contractId` | 需审批通过 |
| 查看审批 | `auditStatus ≠ 0` 且有 `processInstanceId` | — |
| 删除 | 始终显示 | — |

> ⚠️ 规则不一致：后端允许「审批中(10)」编辑，前端仅在「未提交(0)」显示编辑按钮。见第 10 节待办。

### 7.6 产品校验规则

- 产品必须存在；
- 产品不得为**禁用状态**；
- 报价价格、数量必填。

## 10. 非功能需求

| 类别 | 要求 |
|---|---|
| 数据权限 | 按场景（我负责的 / 我参与的 / 下属负责的）隔离 |
| 操作日志 | 记录报价单创建、更新（基于 `@LogRecord` 与 `LogRecordConstants`） |
| 金额精度 | BigDecimal，统一 2 位小数，避免浮点误差 |
| 并发安全 | 单号由 Redis 序号生成器保证唯一 |
| 兼容性 | 前端需兼容 CRLF / 全角字符 / OCR 噪声文本 |

## 11. 待办 / 已知问题

| # | 事项 | 说明 | 优先级 |
|---|---|---|---|
| 1 | 后端 `/parse-text` 接口未实现 | 一键识别当前为**前端正则解析**，未调用后端；后端接口已定义但未实现 | 高 |
| 2 | OCR 识别率有限 | 浏览器端 `tesseract.js` 对中文识别率一般，建议接入后端 OCR（腾讯云/百度通用文字识别） | 高 |
| 3 | 转移入口缺失 | `transfer` 接口已实现，列表页无操作入口 | 中 |
| 4 | 编辑状态规则不一致 | 后端允许「审批中(10)」编辑，前端仅「未提交(0)」显示编辑按钮，需统一 | 中 |
| 5 | 审批中编辑的产品校验 | 审批中编辑时若产品被禁用，需明确提示策略 | 低 |
| 6 | 一键识别未匹配产品提示 | 当前未匹配的产品被静默过滤，建议给出「N 项产品未匹配到系统产品」提示 | 中 |
| 7 | 报价单打印/导出 PDF | 当前仅支持 Excel 导出，无报价单打印模板 | 低 |
