## 测 ERP 采购入库 / MES 完工入库

1. 进入 **入库管理** http://localhost:5173/#/wms/receipt ，点击“模拟 ERP / MES 入库”。
2. 分别选择“ERP 采购入库（原料）”或“MES 完工入库（成品）”，选择对应仓库、上述专用 SKU，申请数量填 2，生成 WMS 草稿。商品选择弹窗现在按业务筛选：采购只显示原材料，完工只显示成品；商品信息及已选明细均显示中文“物料类型”。切换业务且已有选料时，确认才清空商品，取消保留原业务及选料。
3. 草稿生成后核对库存仍为 B，没有本单入库流水。
4. 在列表点这笔单的“修改”，在“本单验收”中录入 **实收 2、合格 1、不合格 1**。专用测试物料免检；其他需质检物料按页面要求上传本单质检图片。提交 BPM 审批，并确认提示。
5. 审批中核对库存仍为 B。用角色已勾选“入库单仓库审批”的账号进入 **工作流程 → 审批中心 → 待办任务**，打开这笔 WMS 入库审批，填写意见并点击“通过”。
6. 回到单据/流程详情，点击“刷新执行结果”。应显示“审批已通过、执行已入库”，已入库合格数量 1；库存为 **B+1**，本单入库流水 **1 条，变更 +1**。

ERP、MES 两种类型各做一次。不合格数量不会增加库存。

## 测 ERP 销售出库 / MES 领料出库

1. 进入 **出库管理** http://localhost:5173/#/wms/shipment ，点击“模拟 ERP / MES 出库”。
2. 分别选择“ERP 销售出库（成品）”或“MES 领料出库（原料）”。销售业务的仓库下拉仅列成品仓，领料业务仅列原料仓；按实际 warehouseType 筛选，不按名称猜测。
3. 选好业务仓库后点击“选择出库库存”，列表仅查询所选仓库中账面库存大于 0 的 SKU，并显示仓库及账面数量。选专用测试 SKU，出库数量填 1（先确认 B≥1），生成草稿。已有选料时切换出库业务或仓库，会提示清空；取消应保留原选择，确认才清空。无库存的商品不能从此出库列表选入，入库仍可选首次入库的 SKU。
4. 草稿及审批中均应保持库存 B，本单无出库流水。
5. 在出库列表点该单“修改”，检查来源、仓库、SKU、数量，点击“提交审批”并确认。来源申请的关键字段锁定，不能借确认页改成另一笔来源申请。
6. 用角色已勾选“出库单仓库审批”的账号从待办任务打开这笔 WMS 出库审批，填写意见并通过。
7. 刷新执行结果，应显示“出库成功”，已出库数量 1；库存为 **B-1**，本单出库流水 **1 条，变更 -1**。

这里“库存”是账面现存量，没有实现预留量和可用量计算。审批通过前没有预扣库存，最终执行时再次校验余额。

## 测异常和重复保护

| 场景 | 操作 | 应看到的结果 |
|---|---|---|
| 库存不足 | 专用出库单申请数量填 B+100，再提交仓库人工审批 | 可能在提交校验时被拦截；若进入审批并通过，执行结果必须失败并说明库存不足；库存 B 不变、本单流水 0、不能为负库存 |
| 仓库拒绝 | 新建专用单，提交后在待办点击“拒绝”，填写理由 | 结果为审批拒绝，库存不变、无本单流水 |
| 重复申请 | 再用同一个模拟来源单号、同一业务类型、仓库、SKU 和数量提交 | 返回原 WMS 单，不新建另一张，不新增流水；改单号属于新申请，不能用来测试重复 |
| 已完成单重复操作 | 刷新执行结果、多次查看单据 | 数量和流水不再增加；已完成单不能再次提交审批 |
| 真正的重复审批回调 | 开发人员按接口测试重放同一流程 ID、业务单 ID、审批结果 | 本轮已用实际内部回调验证两类出库及入库，不重复增减库存；普通自测不需要手工调用内部 RPC |

短信报错不会回滚 WMS 入库/出库审批结果，但短信送达仍受共享短信服务现有问题影响。若看到执行失败，不要把“BPM 已通过”当成“库存已成功”。出库失败重复回调不会自动重扣；当前不提供通用库存执行重试入口，需要核对原因后按受控业务方案处理。

## 测按角色参与审批

1. 打开 **系统管理 → 角色管理 → 对应角色 → 更多 → 菜单权限**。入库管理下勾选“入库单仓库审批”，出库管理下勾选“出库单仓库审批”，按该角色职责分别授权。角色名称不限，不必指定角色60096。
2. “入库单提交审批”“出库单提交审批”用于发起审批，单独勾选不会成为审批人。审批账号还需相应单据查询、BPM 待办页面及处理权限；账号、角色和租户套餐必须启用。
3. 在用户管理把该角色赋给测试账号，保存后重新登录测试账号。**授权后再提交一笔新的审批**，检查该账号待办。当前宋凯80168的仓库管理员角色已具备两类仓库审批权限，可直接自测。
4. 当前采用“或签”：任意一个有效候选人通过即可，其他成员该节点待办结束；拒绝则流程拒绝。不是所有成员都必须逐个通过。
5. 取消某角色的入库审批权限后，用新的入库单验证该角色用户不再得到待办（须确认其其他角色也未获得该权限）。已有任务不会自动撤销、转派；没有启用候选人时流程拒绝，不会自动通过。

旧“出库单上层决策审批”权限保留，但当前 WMS 单层仓库审批不使用它。详细权限键、实际验证单和限制见 [审批权限说明](wms-approval-permissions-20260912.md)。

ERP 采购人员/销售人员的角色和审批请由 ERP 小组在 ERP 内验证。WMS 仅验证收到已审批来源申请之后的仓库流程。

## 接口自测与交接

仓库、SKU、库存、流水只读入口分别是 `/admin-api/wms/external-read/warehouses`、`/skus`、`/inventory`、`/history`，均 GET，携带现有访问令牌及 tenant-id，支持 pageNo/pageSize。可按上述物料编码筛选库存，按单据的 SIM- 来源业务单号筛选流水。

请求字段、返回状态、权限、幂等、错误码、ERP 成功回调及 MES 轮询/建议回调约定见 [接口交接文档](wms-erp-mes-interface-handoff-20260912.md)。实际来源系统尚未完成联调；这份自测验证的是模拟来源、真实本机 WMS/BPM 执行。
