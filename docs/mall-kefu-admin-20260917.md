## 安全边界

- 默认 `scoped-enabled=false` 时只显示“尚未开通”，不读取队列或名单，不回退到旧客服接口。
- 平台固定 `shopId=0`，店铺要求正整数编号；租户与操作者取认证上下文，界面没有 tenantId/操作者身份覆盖字段。
- MEMBER=1 与 ADMIN=2 分开；后台 receive 菜单权限不替代独立坐席授权，也不会自动把供应商变为坐席。
- 账号/租户/权限/范围变化或离开页面时取消请求并丢弃迟到响应，清空会话与草稿，不把消息写入浏览器持久存储。
- 顾客先转人工后才能读取正文或领取；发送必须为当前 ADMIN 坐席名下 ACTIVE 会话，前后端各自校验。
- 授权、领取与结束携带服务端版本。撤权记录原因；冲突不强制覆盖最新版本。
- 发送超时保留原 UUID、版本、文本并锁定草稿，只允许重试原消息或明确放弃本地重试；不自动生成第二条消息。
- 服务端已鉴权的商品/订单卡片只作为纯文本快照展示，不将状态码猜成物流状态，不请求远程图片、不自动打开链接，不增加后台订单读取权限。
- 在线由明确“上线接待”启动服务器租约，不假装默认在线；隐藏时请求下线，不再续约。切换身份或范围后不在新上下文发送旧范围下线请求，旧租约最迟 90 秒失效。
- 已读仅在点击“标记当前可见消息已读”后上报，不将打开队列当作阅读全部会话。
- FAQ 保存不等于发布；限制 30 项、唯一标识、问题/答案/关键词长度，发布需原因及当前版本。未实现真实 AI 或附件。
