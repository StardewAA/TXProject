# MES 环保污染监控模块 · 需求文档

| 项 | 内容 |
| --- | --- |
| 模块 | txgy-module-mes（生产制造执行）新增环保监控子模块 |
| 定位 | 面向生产制造企业角色，对生产线物品去向做污染监控与合规管控 |
| 版本 | v0.1（初稿，评审后修订） |
| 日期 | 2026-09-03 |
| 状态 | 待评审 |

---

## 1. 背景与目标

### 1.1 背景
现行 MES 主流程已覆盖：基础数据建档 → 工艺准备 → 物料备料 → **IQC 来料检验** → **采购入库** → 生产工单与排产 → 生产执行 → IPQC / 工序流转 → OQC → **产品入库** → 销售出库。该流程对**质量**做了完整管控，但缺少对**环保污染**的识别与去向管控：

- 入厂材料是否含污染、应如何存储，无判定；
- 生产各环节产生的废弃物/半成品去向无监控；
- 成品的污染属性（达标但有污染 / 不达标有害无害）不区分，一律按质量放行或报废。

### 1.2 目标
在现有主流程基础上，以 **AI 初筛 + 人工复核** 双阶段判定，在 4 个环节插桩环保判定，实现：
1. 入厂、领用、过程中间物、成品 全链污染分类；
2. 每类污染物的**存储方法与去向**受控、可登记、可追溯（批次反查）；
3. 污染判定独立于质量判定，不破坏现有 IQC / OQC / 退货逻辑。

### 1.3 非目标（本期不做）
- 不改变 IQC/OQC 的质量合格判定与采购退货规则；
- 不做排放口在线监测设备对接（排放合规流水先做人工登记）；
- 不接政府环保申报接口。

## 2. 术语
| 术语 | 含义 |
| --- | --- |
| 批次 | 物料/产品入库或生产形成的追溯单位（沿用现 MES 批次号） |
| AI 初筛 | 系统/AI 依据成分、MSDS、质检数据给出的预分类与存储建议 |
| 人工复核 | 质检/仓库/车间人员对 AI 结果的最终确认 |
| 废弃物（中间物） | 工序产出的非正常半成品：边角料、副产物、报废中间品等 |
| 危废/污染暂存区 | 存放有污染物料的受控环境（按存储方法隔离） |
| 存储方法 | 某类污染应存放的环境要求（普通/隔离/防渗/温控/密闭等） |
| 回用 | 无污染中间物移入下一工序/回库再使用 |
| 排放 | 无污染中间物排出产线、排放处置（需记合规流水） |
| 标记 | 对有污染或不达标成品加注标识，禁止按正常品流转/出库 |

## 3. 总体判定规则（贯穿四段，一条不破）

| 编号 | 规则 |
| --- | --- |
| R1 | AI 初筛只输出**三值预分类**：无污染 / 有污染 / 不确定；并给出分类依据、置信度、推荐存储方法 |
| R2 | **最终分类一律以人工复核二值为准：无污染 / 有污染**（采购、中间废弃物、成品三处同一规则）。AI 判"不确定"也必须由人工复核收口为二值之一，不允许"不确定"留存为终态 |
| R3 | **环保判定独立于质量判定**：污染状态只影响"存储/去向/出库"，不触发采购退货、不改变质量合格口径 |
| R4 | 判为"有污染"的物料一律按（AI 推荐、人工确认的）**存储方法存入对应受控环境**并登记 |
| R5 | 每条判定以 `环节 + 关联单号 + 批次 + 物料` 为唯一约束，一条记录贯穿 AI 初筛 → 人工复核 → 处置去向（可追溯、可反查） |
| R6 | 所有排出/处置都登记**去向**；排放类的记录合规流水（本期人工登记） |

## 4. 分环节需求

### 4.1 环节一：采购入库（环保初筛）
**触发时机**：IQC 检验合格、执行采购入库前（环保判定是"入库"新增子步骤，质量退货逻辑不变）。

1. **AI 初筛**（系统对整批原料/来料批次）：
   - 输入：物料品类、成分/MSDS 关键词、供应商、IQC 质检项与实测值、批次。
   - 输出三值预分类 **无污染 / 有污染 / 不确定** + 依据 + 置信度 + **每类对应的推荐存储方法**。
2. **人工最终确认**（质检/仓库复核人）：只允许给出 **无污染 / 有污染**。
   - AI 为"不确定"的，强制进入人工复核并必须裁决为二值之一。
   - **无污染** → 入**普通原料仓**，正常入库登记，判定记录归档。
   - **有污染** → 按其**存储方法**存入对应**污染管控环境**（隔离/防渗/温控…），登记判定记录 + 污染暂存台账。
3. 说明：判"有污染"不等于拒收、不退货——该原料可能质量合格，只是需环保受控存储；退货仍只由 IQC 质量判定驱动（R3）。

### 4.2 环节二：生产领用（领出前复核）
**触发时机**：从仓库调出原料投入生产前，对**被领批次**做污染状态复核。

1. **AI 记录**：结合入库判定记录 + 存储环境，生成该批次的污染状态快照与放行建议（允许领用 / 拒绝领用）。
2. **人工确定**：仓库管理员复核放行。
   - 两步均通过（状态为无污染或已受控）→ **允许领用**，进入产线。
   - 复核判为有污染 / 拒绝 → **拒绝领用**，原料转污染暂存或隔离处理，不进入产线。
3. 目的：防止污染料混入产线（源头隔离）。

### 4.3 环节三：生产过程（中间物/废弃物）
**触发时机**：生产执行到每道工序，对该工序产出判断归属。

1. **是否废弃物判定**：
   - 工序正常产出**半成品** → 不是废弃物，沿工序流转至下一道（继续重复本环节判断），直至成品环节。
   - 工序产出**废弃物**（边角料/副产物/报废中间品，由车间操作员在报工时标记）→ 进入 2。
2. **废弃物环保判定**：
   - **AI 初筛**三值（无污染 / 有污染 / 不确定）。
   - **人工复核**（车间/质检）二值收口：
     - **无污染** → **直接排出**，去向登记二选：**回用**（进下一工序/回库）或 **排放**（排放需按标准并记合规流水）。
     - **有污染** → **保存处理**：按存储方法存入污染/危废暂存区，登记暂存台账。

### 4.4 环节四：成品（达标与不达标）
**触发时机**：加工到最后一步成品，先确定质量达标与否。

**分支 A —— 成品达标：**
1. **AI 初筛**三值（无污染 / 有污染 / 不确定）。
2. **人工二次检测**二值收口：
   - **无污染** → **直接存储**入成品合格仓，登记。
   - **有污染** → **AI 生成该成品的存储建议并加标记**：隔离存储于受控环境，**不按正常品出库**，登记判定记录 + 污染台账。

**分支 B —— 成品不达标：**
1. **全部不出库**（整批锁定，沿用"整批锁定 禁止出库"规则）。
2. 下一步判定**是否有害**（AI 辅助 + 人工确认，沿用 R1/R2）：
   - **有害** → 系统**提供其存储方法**，按危废/有害物受控存储并登记。
   - **无害** → **直接存储并加标记**（次品/降级待处理，不进入正常销售流转）。

**成品状态 × 处置矩阵：**

| 质量 | 环保判定 | 处置/去向 | 登记 |
| --- | --- | --- | --- |
| 达标 | 无污染 | 入成品合格仓 | 判定记录 |
| 达标 | 有污染 | AI 存储建议 → 隔离存储 + 标记（不出库） | 判定记录 + 污染台账 |
| 不达标 | 有害 | 按存储方法危废/有害受控存储 | 污染台账 + 锁定 |
| 不达标 | 无害 | 直接存储 + 标记 | 台账/标记 |

## 5. 功能需求

### 5.1 AI 初筛服务
- `AI 初筛`：入参 = 环节、物料/产品、批次、成分/MSDS、质检项实测值、存储环境；出参 = `{ 类别: 无污染|有污染|不确定, 置信度, 依据明细[], 推荐存储方法 }`。
- 存储方法含字段：环境类型（普通/隔离/防渗/温控/密闭/危废标识等）、温湿度要求、包装/容器要求、备注。
- **开发期**：先按规则引擎 mock（物料污染词典 + 质检指标阈值）跑通闭环，预留 `txgy-module-ai` 大模型接口，二期替换为真实模型调用；AI 仅作建议，分类终态永远在人工（R2）。

### 5.2 人工复核
- 待复核队列：所有 AI 初筛完成、待人工确认的记录进队列（按环节分页）。
- 复核页展示：AI 预分类、依据、置信度、推荐存储方法，人工点选 **无污染 / 有污染**（只此二值）。
- 复核必须填写复核人与时间；允许补充备注。
- 审计要求：AI 结果与人工结果都留痕，支持按批次反查全链判定。

### 5.3 判定记录与台账
- 全链判定记录（唯一约束 R5），支持查询：按批次 / 物料 / 环节 / 分类 / 时间 / 复核人。
- 台账：污染/危废暂存台账、排放合规流水、被标记成品/次品清单。
- **批次反查**：输入批次号 → 展示该批次从采购判定 → 领用 → 中间物 → 成品的完整去向链（呼应原流程图"批次追溯"）。

### 5.4 受控存储
- 有污染物料/成品入库到受控环境（库位需有"污染管控/危废"属性标识）。
- 普通仓与受控仓隔离，防混放；标记品禁止流转到正常出库/销售。

### 5.5 前端页面清单（vben，MES 菜单下新增"环保监控"分组）
1. 采购入库-环保判定（AI 初筛结果 + 人工复核 + 存储方法）
2. 生产领用-放行复核
3. 工序废弃物登记与环保判定
4. 成品环保判定（达标分支）
5. 不达标成品处置（有害/无害 + 存储）—— 可与 4 合并
6. 环保判定记录查询 / 待复核队列
7. 污染/危废暂存台账、排放合规流水、被标记品清单
8. 批次全链环保追溯

### 5.6 角色权限
| 角色 | 权限 |
| --- | --- |
| IQC/质检员 | 采购入库、中间废弃物、成品的 AI 初筛查看与人工复核 |
| 车间操作员 | 报工时标记废弃物、登记中间物去向 |
| 仓库管理员 | 领用放行复核、污染品入受控环境登记 |
| 环保专员（新增） | 台账审核、排放合规流水登记、标记品管理（终审） |
| 系统管理员 | 存储方法字典、污染词典、参数配置 |

## 6. 数据模型（建议表）
| 表 | 说明 |
| --- | --- |
| `mes_pollution_storage` | 存储方法字典：环境类型、温湿度、包装要求 |
| `mes_pollution_material` | 物料/产品环保属性词典（成分关键词/MSDS 摘要/默认阈值），AI mock 输入 |
| `mes_pollution_check` | 污染判定记录（核心）：环节、关联单号、批次、物料、AI 类别+置信度+依据、人工类别、复核人/时间、推荐存储方法、最终处置、去向/库位、标记 |
| `mes_pollution_ledger` | 污染/危废暂存台账：来源（判定记录 ID）、存储环境、当前状态（暂存/处置中/已回用/已排放/已处置）、操作人 |
| `mes_pollution_discharge` | 排放合规流水（本期人工登记）：去向、排放标准、登记人 |

核心唯一键：`环节 + 关联单号 + 批次 + 物料`；`mes_pollution_ledger` 挂 `mes_pollution_check.id` 实现可追溯。

## 7. 后端接口（草案）
- `POST /mes/pollution/ai-prescreen` AI 初筛（mock/真实可切换）
- `POST /mes/pollution/review` 人工复核（收口二值）
- `POST /mes/pollution/pull-review` 生产领用放行/拒绝
- `POST /mes/pollution/waste-register` 废弃物登记 + 去向（回用/排放）
- `POST /mes/pollution/final-review` 成品环保判定（达标分支）
- `POST /mes/pollution/reject-dispose` 不达标成品 有害/无害 处置
- `GET  /mes/pollution/page` 判定记录分页（环节/状态过滤）
- `GET  /mes/pollution/todo` 待复核队列
- `GET  /mes/pollution/trace?batchNo=` 批次全链环保追溯
- `GET  /mes/pollution/ledger/page` 污染/危废台账
- `GET  /mes/pollution/storage-list` 存储方法字典

## 8. 状态与闭环
判定记录状态机：
`AI 初筛完成(待复核) → 人工已复核(无污染|有污染) → 处置/去向已登记 → 闭环`
不变量：不存在"终态 = 不确定"的判定（R2）；同一批次同一环节不允许出现两条不同终态判定（R5）。

---

## 9. 非功能与合规
- 留痕：AI 结果、人工结果、复核人、时间均不可改（仅可新增纠错记录）。
- 审计：环保判定表支持导出，供环保检查/追溯。
- 性能：判定记录按批次索引，全链追溯 < 2s。
- 权限：环保台账按角色只读/可写控制。

## 10. 分期计划
- **P1（闭环先行，AI mock）**：5.1 mock 规则 + 判定记录/台账表 + 4 环节复核 UI + 批次追溯 + 权限。可演示全链。
- **P2（真实 AI 接入）**：接 `txgy-module-ai` 大模型初筛，存储建议由模型生成；排放合规流水完善。
- **P3（可选）**：环保报表、供应商环保档案、排放监测设备对接。

## 11. 验收标准（抽查用例）
1. 一批含污染标识原料：IQC 合格 → AI 初筛"有污染" → 人工复核"有污染" → 进入受控环境存储并登记，**不触发退货**；能按批次反查。
2. 一批 AI 判"不确定"的原料：必须由人工复核裁决为二值之一，系统不允许以"不确定"结束。
3. 生产某工序报工标记边角料为废弃物：AI 初筛 + 人工复核 → 无污染"回用/排放"有去向记录；有污染入暂存台账。
4. 达标但判"有污染"的成品：隔离存储 + AI 存储建议 + 标记，无法从正常成品仓出库。
5. 不达标成品：整批锁定不出库；有害→给存储方法受控存储；无害→直接存储并标记。

---

## 12. 评审遗留
- 采购入库环节 AI 初筛"有污染"的原料，是否允许 **经过人工复核后仍被同一批次再次领用**（默认：不允许，须先在暂存区完成处理/净化）——建议 P1 默认拒绝，评审确认。
