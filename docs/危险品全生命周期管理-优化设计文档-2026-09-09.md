## 0. 天信管业真实场景锚（v0.3 一切设计的基准）

| 类别 | 真实清单 | 特性要点 |
| --- | --- | --- |
| **危化品** | ① 异氰酸酯（黑料 / MDI·TDI 类）② 环氧粉末 ③ 稀释剂 | ① 剧毒·强放热反应，湿敏，需 N₂ 保护储存；② 静电粉尘易爆；③ 易燃有机溶剂 |
| **危废（产生源）** | ① 废包装桶 HW49 ② 废有机溶剂 HW06 ③ 漆渣 HW12 ④ 废活性炭 HW49 ⑤ 废机油 HW08 | 来自喷涂/环氧/设备维保；活性炭自身是治理设施耗材 → 换炭即产 HW49 |

**产线映射**：喷涂 VOCs 治理=活性炭吸附+催化燃烧（换炭→废活性炭 HW49）；抛丸/打磨=布袋除尘（收尘灰入危废判定）。中间废弃物环节的判定对象就从这套真实物上来。

## 3. 维度契约与一物一码（沿用 v0.2 §3，精炼）

- 三轴：污染态(CLEAN/POLLUTED 门禁) × 风险类型(CHEMICAL/POLLUTED/HAZ_WASTE/NORMAL 定规则) × 危险等级(A-D+HW码+特性 定深度)。type 不取代 pollution_status。
- 一物一码：批次码 + 容器码(`mes_dg_container` 一桶一码)。危废桶号即容器码，追溯链 `trace_code` 串联。
- 判废依据落到 §0 清单：如名称含"异氰酸酯/MDI/TDI"→ CHEMICAL+剧毒+遇湿反应；"漆渣/废溶剂/废活性炭"→ HAZ_WASTE + 对应 HW 码。

## 4. 修复 A：入库待检冻结 + 判定状态机（沿用 v0.2 §4，精炼）

到货登记→待检区冻结(`material_stock.frozen`，QC `MesQcPendingInspect` 同款)→AI/人工复核→{NORMAL 解冻合格区 / CHEMICAL·POLLUTED 隔离区·危化品专区 / 退货}。
判定状态 PENDING→{CLEAN/POLLUTED/CANCELLED}；CANCELLED 留痕不物理删；复核 CLEAN 解冻只限本判定来源；写透同时置 `material_stock.frozen` 与 `batch` 戳（修 frozen 空转 Bug-3）。

## 5. 修复 B：重量 + 物料衡算（v0.3 强化：称重防篡改）

### 5.1 全链重量（沿用 v0.2 §5.1）
判定/台账/容器补 quantity+毛/净/皮重。危废产生/转移/处置**每个动作称重**，双人称重签字。

### 5.2 称重防篡改（对标新增）
- 企业实际用**电子秤/地磅/汽车衡**，系统要对接**自动采集**，不是手填重量。
- 方案：`mes_dg_weighbridge`（衡器档案：类型电子秤/地磅/汽车衡、量程、检定有效期）+ `mes_dg_weigh_record`（衡器号/自动读数/时间/操作人）。
- 重量**优先取衡器接口读数**（预留串口/协议，现场先"衡器读数→人工确认"）；**禁止纯手填为唯一来源**——手填必须留痕并标 `source=AUTO|MANUAL`，AUTO 的读数不可改，防"称重造假"。

### 5.3 物料衡算（沿用 v0.2 §5.2）
`mes_pollution_mass_balance`：投入≈合格品+危废+排放+损耗，允差预警。危废必须可由源头工单反推投料批，否则报"无源"。排放回填自 §9 在线数据。

- 成品 FINISHED_PRODUCT 三态：达标有污染→隔离不出库 / 不达标→返工或报废转危废建档 / 正常。

## 7. 危化品管控（v0.3 落到天信：异氰酸酯级）

### 7.1 五双管理（沿用）
双人收发/保管/双锁/领料/运输，PDA 双账号各签一次。

### 7.2 按物料特性分级储存（对标：异氰酸酯）
| 物料 | 储存要求（天信实况） | 系统管控 |
| --- | --- | --- |
| 异氰酸酯(黑料) | 专用危化品库+**N₂ 保护/防潮**、远离水醇胺（放热剧反应）、阴凉通风 | 库位绑定禁配(水/醇/胺)；温湿度监控超限报警；MSDS 必挂 |
| 环氧粉末 | 防静电、防火花、防爆区 | 静电接地记录；禁火作业票联动 |
| 稀释剂 | 易燃液体专柜、限量储存、通风防爆 | 储量上限预警；双人领用 |

- 效期 FIFO + 过期冻结：启用 `batch.expireDate/produceDate`（v0.2 §7，字段闲置实测确认）；定时任务扫过期→冻结→转危废/报废（调度底座 §2 待建）。

## 8. 危废链（v0.3：对齐国家固废系统 + 标签合规 + 治理设施）

### 8.1 委外六步真实节点序（沿用 v0.2 §8，对齐国标）
年度备案→申报→资质核验（供应商主数据维护）→电子联单（产生申报→运输确认→接收确认）→装车转移（逐桶称重·四方会签）→回执归档 5 年。

### 8.2 对接国家固废管理系统（对标新增）
- 电子转移联单 = **国家固废管理信息系统统一运行**，企业流程必须对齐其**五方角色 + 申报时限**（产生/运输/接收/贮存/处置），不是内部自造单号。
- 方案：`mes_dg_manifest` 存联单号+五方节点状态+申报时限；系统按国家平台时限**倒排提醒**（如申报后 N 日未确认即预警）；**预留对接接口，当前以"格式合规导出/导入 + 手工填报确认"落地**（无政务网络时先能出示标准格式），接入国家 API 为 P4 可选。

### 8.3 危废标签 HJ 1276-2022 合规（对标新增）
- 危废标签不是随便打印贴：须按 **HJ 1276-2022《危险废物识别标志设置技术规范》**：标签样式/危险特性图形/危废类别/产生单位/批次/重量/日期/二维码。
- 方案：标签**由系统按 HJ1276 模板生成**（含唯一二维码=容器码），打印后贴桶；扫描二维码即查该桶全程。标签补印/损坏走换签留痕。
- 贮存间设置标志牌、包装容器标签尺寸规范，纳入巡检项。

### 8.4 治理设施与危废产生联动（对标新增）
- 产线治理设施台账 `mes_dg_facility`：活性炭吸附/催化燃烧/布袋除尘；关联排放口。
- **活性炭定期更换**：到期提醒→更换工单→**换下即登记为废活性炭 HW49 入危废桶**（一桶一码）——"耗材→危废"自动转化，杜绝换炭不记危废。
- 设施**停运申报**：停运≠随意停，须申报+审批（否则影响达标排放，联动排污许可）；停运期间在线监测超标的应急流程见 §9。

## 9. 排污合规主线（v0.3 新增——把 permit/outlet/env 串起来）

> 企业"按证排污"：**排放限值取自排污许可证、超许可总量=违法红线、执行报告定期上报**。

### 9.1 模块落地顺序
permit/env/outlet/carbon 表已存在 → **先补 DO/Service/菜单/页面**（评审当前是否按现状建，或按天信口径扩列）。

### 9.2 联动设计
```
排污许可证 permit(permit_no/期限/annual_limits)
   └─ 排放口 outlet(挂 permit_no/permit_limits/pollutant_codes/is_key_outlet)
        └─ 在线监测 reading(实测浓度/流量) → 比对 permit_limits
             ├─ 超许可限值 → 报警 + 整改单(异常闭环)
             ├─ 超许可总量(annual 累计) → 违法红线告警 + 应急(停排/减产) + 上报留痕
             └─ 排放量回填 mass_balance.output_emission(衡算闭环)
执行报告 env_report(按月/季/年, 定期上报备案, 数据取自监测/台账自动汇总)
```

### 9.3 与危险品链的接口
- 中间废弃物环节"排放/回用"判定 = 是否进入治理设施 → 关联 outlet + 是否需 permit 校验。
- 治理设施停运申报、超总量处置、应急响应统一进 `mes_dg_exception` 审批链。
