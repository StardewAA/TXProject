# 07 主体域前端交付——业务口径说明（A 方案：企业主体 + 多经办人）

> 读者：前端同学（业务背景说明，避免按直觉把“档案”做成人员粒度）。
> 配套接口见 06-bidding前端契约接口完全对照.md §4（subject）；字段/枚举以本目录契约文件为准。

## 1. 一句话结论

**主档案与投标/招标资格 = 企业（法人/其他组织）粒度；人员只是“企业内的经办自然人”，通过绑定出现在企业下，不是独立的主体。**

系统里“主体档案”（bidding_subject_profile）填的是一家公司；一个公司下可绑定多个自然人账号（经办人 OPERATOR / 联系人 CONTACT）；
而“关注/意向/投标流程跟踪”按登录的自然人账号（user_id）各自维护。

## 2. 为什么是“企业粒度”，原因逐条（业务依据）

1. **法规层面**：《招标投标法》第 25 条——投标人应当是法人或者其他组织；只有依法必须招标的项目中的科研项目等特殊情形允许个人投标。
   资格审查的法定对象是“企业”：营业执照、统一社会信用代码、企业资质等。个人不是法定投标主体。
2. **全流程署名主体是企业**：招标公告/中标公示/中标通知书/合同签署主体，写的是企业名称与统一社会信用代码，不是个人。
   若把档案做成人员粒度，公告主体、合同主体、后续追责都会对不上。
3. **统一社会信用代码是唯一键**（GB 32100，18 位）：企业档案以 uscc 唯一去重、跨年复用；个人没有 uscc，无法承担这个主键角色。
4. **行业惯例一致**：公共资源交易/招投标平台普遍是“企业主体库 + 单位经办人”两层；经办人负责操作，资格挂在企业。
5. **我们的 A 场景**：同一家企业里多名业务员共用一套投标资格（报备/报名/传标书），每人用自己的账号跟踪自己的意向——
   所以“资格归企业、操作与跟踪归个人”正好满足，不需要给每个人另建一套资格档案。

## 3. 数据模型对应（前端按此理解）

| 概念 | 表/接口 | 粒度 | 前端呈现 |
| --- | --- | --- | --- |
| 主体档案 | bidding_subject_profile / /bidding/subject/profile/* | 企业 | 企业信息卡：企业名称、uscc、法人、注册资本、行业/地区、联系人、营业执照文件 |
| 平台授权 | bidding_subject_auth / /bidding/subject-auth/* | 企业 | 授权列表/状态（ENABLED/DISABLED…）+ 资格状态展示 |
| 经办人绑定 | bidding_subject_user / /bidding/subject-auth/user/* | 自然人（绑定在企业下） | 企业详情里的“经办人列表”，含昵称与角色 |
| 关注/意向/跟踪 | bidding_follow_item(+event) / /bidding/notice-follow/* | 自然人账号 user_id | “我的关注/我的投标流程”，默认只显示当前登录人自己的数据 |

## 4. 前端页面应有的样子（建议，避免业务歧义）

- 主体档案页：对象是企业，不要提供“以个人名义建档”入口（个人投标通道 INDIVIDUAL 本期未开放，后续开放再上）。
- 经办人：企业主体下的从属列表；新增经办人=选择系统用户+角色(经办/联系人)，绑定关系唯一(企业+类型+人)。
- 跟踪/关注列表：默认按“我”（当前登录人）过滤，标题用“我的…”；不要在企业维度把所有业务员的关注合并展示。
- 措辞模板（可直接用于页面文案/空态/报错）：
  - 主体选择：请先完善并授权【企业主体档案】；只有完成授权的企业才能参加投标/发布。
  - 经办人添加：请选择本企业名下要授权的经办账号（人员不单独构成投标主体）。
  - 资格提示：贵司主体已授权但档案未完善/已停用，请联系平台完成核验。
  - 关注说明：关注与意向按账号独立保存，团队成员各自维护自己的关注即可。

## 5. 前端易错点清单（对照测试/评审用）

- [ ] 不得出现“个人档案/个人主体”入口与个人投标资格路径（本期无 INDIVIDUAL）。
- [ ] uscc 用 18 位校验，非法格式应拦截（GB 32100）。
- [ ] 授权状态与档案完善度区分展示：授权≠档案完善，资格门=授权且档案完善。
- [ ] 经办人绑定/解绑不删除企业档案与历史（解绑=停用留痕，接口语义见契约）。
- [ ] “我的关注/流程跟踪”必须按当前登录人过滤；若将来需要企业级共享视图，属于新增需求（需企业维度授权后另行设计）。
- [ ] 主体类型 BIDDER(投标人)/TENDERER(招标人) 是“企业扮演的角色”，同一家企业可同时是投标人和招标人，别在界面上固化成二选一档案。

## 6. 业务口径 FAQ（前端可直接粘贴给业务确认话术）

- Q：为什么一个企业要绑这么多账号，不直接让个人注册投标？
  A：投标主体是公司（法规 25 条），个人是经办操作人；公司对其投标行为负责。
- Q：我们业务员离职了怎么办？
  A：解绑该经办人（保留历史留痕），其关注/意向归属个人账号，新经办人重新建立关注即可（如需转移另做需求）。
- Q：一个账号能同时是多家企业的经办人吗？
  A：技术上可绑定多家企业（每家企业下各一条绑定）；前端列表按企业展示，不做全局合并。
