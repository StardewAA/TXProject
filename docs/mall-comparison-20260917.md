# 跨店商品比较与结算预估（2026-09-17）

## 本批交付

- PC `/compare`、H5 `/pages/goods/compare`：从商品详情明确选 SKU，最多 4 项，原始规格差异对照、不可用项移除、采购份数/偏好、重新核验并加购。
- 访客清单按租户隔离；登录后显式合并，不自动覆盖。会员清单由后端持久化，PC/H5 共用，版本冲突要求刷新。清单只存 SKU 编号及选择，不存商品/订单快照。
- 后端共用公开比较结果。标价、规格、店铺只来自当前租户可售商品；无权限商品仅返回不可用占位。
- 本人地址结算预估复用现有计价，逐 SKU 独立估算，不创建订单、锁库存、扣积分或消费优惠券。缺地址/运费模板/计重信息时不把未知费用当 0。
- 数量或偏好修改后，旧结果、旧报价及加购按钮不能作为新输入结果继续使用；账号变化和迟到请求隔离。Vue 官方 watcher 清理说明用于复核异步结果归属。

## 尚未完成 / 不夸大范围

当前真实数据缺统一商品族、包装和计量基准，部分 SKU 缺单位。此批不是“完整智能推荐”：不按相似名称认定同款，不做物理单位换算，不生成最低价排名，`recommendedSkuId` 为 null，并给出资料不足原因。后续须补可信规格映射及维护入口，再完成硬规格过滤、可解释排序与至少三店同商品族验收。交付份数是 SKU 的销售数量，不代表不同 SKU 相同 kg/L/面积。

## 接口

- `GET/PUT /app-api/product/comparison/list`：会员隔离、CAS 版本更新。
- `POST /app-api/product/comparison/calculate`：公开 SKU 对比，1—4 项、数量 1—999。
- `POST /app-api/trade/product-comparison/quote`：本人地址与会员上下文，费用单位分；所有金额完整且核验通过才展示总价。

不变：ERP 统一库存变更；WMS 只读；审核可售门槛；租户 1 入口；新公共租户未启用。
