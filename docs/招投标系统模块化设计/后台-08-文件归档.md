# 后台-08 文件归档（企业后台管理系统）

## 定位
全过程文件与日志打包归档，归档后只读，保存期管理与调阅审计。

## 依据
- 《档案法》（2020 修订）；《政府采购法》第 42 条（政采≥15 年）。
- 《电子招标投标办法》存档要求。
- 数据规范 V2.0 表28/29 附件集结构，作为归档清单来源。

## 功能

| 功能 | 说明 |
|---|---|
| 归档清单 | 自动生成全过程文件清单并核验齐全性 |
| 打包归档 | 文件+数据+审计日志打包，计算哈希 |
| 只读锁定 | 归档后只读，仅允许补充归档 |
| 保存期管理 | 按项目类型配置期限，到期提醒 |
| 调阅审计 | 调阅一律留痕 |

## 视图

功能视图：招标人/代理=发起归档/补充/调阅；监管=接口调阅抽查；运营=到期处置。
流程视图：交易结束 → 清单核验 → 打包哈希 → 只读锁定 → 保存期倒计时 → 到期双人审批处置。

## 接口

- REST：POST /admin-api/bidding/archive/create；GET /archive/page；POST /archive/access。
- 跨模块 API：ArchiveApi.getStatus(projectCode)；ArchiveApi.getList(projectCode)。


## 涉及的数据对象（VO 完整字段表）

> 下表逐字照录《VO数据对象规范（国家V2.0模版·陕西适配全量版）.md》对应数据集的全量字段（8 列，含公开范围）。
> 该规范为国家级 V2.0（发改办法规〔2018〕1156号）与陕西省 V2.0 的合并速查版：同名数据集以陕西为准，「英文名称」照录原文（含拼写瑕疵，勿改）；只列字段清单，不含建表 DDL，也不绑定 Java record。

> 文件归档沿用各业务 VO 已定义的「附件关联标识号 ATTACHMENT_CODE（C..ul）」与附件集字段（国家 20 号令 A.1 附件集），规范未单列独立的归档 VO；归档清单即上述 VO 附件字段的集合，无需重复建表。

## 技术复用

依赖 web、security、mybatis、biz-tenant、job；档案包整体哈希防篡改；保存期限配置字典（政采 15 年、工程按制度）；归档只读由本模块统一控制。
