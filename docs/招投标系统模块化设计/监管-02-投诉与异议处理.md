# 监管-02 投诉与异议处理（监管系统）

## 定位
受理与办理投诉：3 个工作日内决定受理，受理后 30 个工作日内作出处理决定。

## 依据
- 《招标投标法实施条例》第 60~62 条：投诉时限与处理程序。
- 《陕西省实施〈招标投标法〉办法》：省内投诉程序。
- 数据规范 V2.0 表122 投诉信息数据集。

## 功能

| 功能 | 说明 |
|---|---|
| 投诉登记 | 接收大厅入口与企业后台异议升级转来的投诉 |
| 受理决定 | 3 个工作日内受理/不予受理并说明理由 |
| 办理转办 | 承办、转办、办理过程留痕 |
| 处理决定 | 30 个工作日内出处理决定，签署锁定 |

## 视图

功能视图：监督人员=受理/转办/决定；投诉人=提交/查进度；被投诉主体=收通知/答辩。
流程视图：提交 → 登记 → 3 个工作日受理决定 → 办理（可转办）→ 30 个工作日处理决定 → 回传各方 → 归档。

## 接口

- REST：POST /admin-api/bidding/sup/complaint/accept（受理）、/decision（决定）；大厅调用提交接口见 05 文件 2.3。
- 跨模块 API：ComplaintApi.submit(ComplaintSaveReqVO)；ComplaintApi.getProgress(code)。
