# 监管-04 信用监管（监管系统）

## 定位
违法违规、黑名单、奖励、履约等信用信息登记，按公开级别输出给企业后台与大厅。

## 依据
- 《招标投标法实施条例》信用公示要求；《公共资源交易平台管理暂行办法》。
- 《陕西省公共资源交易平台管理办法》。
- 数据规范 V2.0 表128~140 信用信息数据集及代码集。

## 功能

| 功能 | 说明 |
|---|---|
| 违法违规登记 | 主体、行为、依据、处罚结果 |
| 黑名单管理 | 列入/撤销、限制行为、期限 |
| 奖励与履约 | 奖励记录、履约评价汇聚 |
| 分级输出 | 社会公开字段送 ES/大厅，政务公开字段送企业后台 |

## 视图

功能视图：监督人员=录入/审核/列入/撤销；企业后台=查本人信用；公众=经大厅查社会公开部分。
流程视图：来源（投诉/检查/处罚）→ 登记 → 审核 → 生效 → 分级推送 → 撤销留档。

## 接口

- REST：POST /admin-api/bidding/sup/credit/create（登记）、/revoke（撤销）。
- 跨模块 API：CreditApi.write(CreditSaveReqVO)；CreditApi.checkStatus(subjectCode)；CreditPublicApi.syncToEs(doc)（对接 ES 同步服务）。

## 技术复用

依赖 web、security、mybatis、mq（信用公开异步同步 ES）；记录只追加，撤销用状态+撤销表；公开级别在 Api 层裁剪。
