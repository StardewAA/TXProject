# 监管-03 监督检查（监管系统）

## 定位
检查计划、检查记录、整改跟踪与报警处置的日常监督工具。

## 依据
- 《电子招标投标办法》第 3 条；《公共资源交易平台管理暂行办法》。
- 《陕西省公共资源交易平台管理办法》。
- 数据规范 V2.0 表120 行政监管事项、表121 项目报警信息、表127 报警等级。

## 功能

| 功能 | 说明 |
|---|---|
| 检查计划 | 年度/专项计划，关联项目或主体 |
| 检查记录 | 线上/现场检查发现与证据附件 |
| 整改跟踪 | 下达整改、跟踪状态、复核 |
| 报警处置 | 接收数据归集推送的报警并登记处置 |

## 视图

功能视图：监督人员=计划/检查/整改/复核；被检查对象=看整改要求、交材料；公众=不可见。
流程视图：计划 → 检查 → 记录 →（问题）整改 → 复核 → 归档；报警：归集推送 → 登记 → 处置。

## 接口

- REST：POST /admin-api/bidding/sup/check/rectify（下发整改）；GET /check/page。
- 跨模块 API：CheckApi.sendRectify(RectifyVO)；AlertReceiveApi.receive(表121 VO)。

依赖 web、security、mybatis、biz-data-permission；报警只登记不定性，定性由人完成；证据附件存文件服务并记哈希。
