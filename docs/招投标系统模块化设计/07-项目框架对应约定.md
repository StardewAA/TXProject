# 07 项目框架对应约定（模块设计遵循 yudao 框架）

> 本文件定义：19 个模块落地到本项目框架（RuoYi-Vue-Pro / yudao）时的统一对应规则。模块文件中的"项目框架落点"一节均按本约定书写；无程序代码，只约定命名与结构。

## 一、模块包结构（全部在新模块组 cn.iocoder.yudao.module.bidding 下）

每个业务模块（如投标递交）统一按既有业务模块（如 yudao-module-system）的目录规范组织：

cn.iocoder.yudao.module.bidding.{系统}.{业务}
├── controller/admin/      管理端接口（URL /admin-api/bidding/...，匹配框架 WebProperties.adminApi 规则）
│   └── {业务}/vo/         请求/响应 VO（XxxSaveReqVO、XxxRespVO、XxxPageReqVO）
├── controller/app/        C 端接口（/app-api/bidding/...，大厅公众接口除外——公众接口放 hall 且标 @PermitAll）
├── service/               业务接口 + ServiceImpl
├── dal/dataobject/        XxxDO（继承 BaseDO 或 TenantBaseDO）
├── dal/mysql/             XxxMapper（继承 BaseMapperX）
├── dal/redis/             缓存 Key 常量与缓存 DO（按需）
├── convert/               MapStruct 转换器（DO ↔ VO ↔ 交换 VO）
├── api/                   跨模块接口 XxxApi + XxxApiImpl（供其他模块进程内调用）
├── enums/                 枚举 + ErrorCodeConstants（错误码段 1_100_xxx_xxx，与既有模块段不冲突）
├── framework/             该模块自身的配置、监听、处理器
├── job/                   定时任务（如保存期提醒、ES 同步重试）
└── mq/                    消息生产者/消费者（如公开同步、备案推送）

## 二、类命名与框架基类对应

| 设计元素 | 框架对应 | 说明 |
|---|---|---|
| 数据表 | dal/dataobject 的 XxxDO，@TableName 与 03 文件表名一致 | 企业后台 DO 继承 TenantBaseDO（tenant_id），监管/大厅 DO 继承 BaseDO |
| 增删改查 | XxxService / XxxServiceImpl | 事务、缓存、操作日志注解沿用框架惯例 |
| 数据访问 | XxxMapper extends BaseMapperX<XxxDO> | 分页入参 PageParam/PageReqVO，返回 PageResult |
| 跨模块调用 | api 包 XxxApi + XxxApiImpl | 接口即 05 文件的模块接口；实现类注入 Service |
| REST 接口 | Controller + CommonResult 返回 | 管理端 @PreAuthorize("@ss.hasPermission('bidding:xxx:yyy')")；公开接口 @PermitAll |
| 权限码 | 菜单权限码前缀 bidding:（如 bidding:ent:notice:create） | 权限码注册在菜单表，按钮级控制复用 v-hasPermi |
| 错误码 | ErrorCodeConstants，new ErrorCode(1_100_xxx_xxx, "中文提示") | 按模块分段，错误码表见 05 文件 |
| 时间字段 | 业务时间 varchar(14)（yyyyMMddHHmmss），审计字段用 BaseDO 自带 | 与 V2.0 数据时间戳一致 |
| 文件/附件 | 复用文件服务（上传/下载/删除，哈希留存），表里存路径+哈希 | 不新写文件能力 |

## 三、框架 starter 复用（只依赖不改动）

| 能力 | 复用 | 用在哪 |
|---|---|---|
| Web/Security | yudao-spring-boot-starter-web / -security | 全部 Controller、登录态、@ss.hasPermission |
| 缓存 | yudao-spring-boot-starter-redis | 字典、时限、幂等缓存 |
| 多租户 | yudao-spring-boot-starter-biz-tenant | 企业后台租户隔离（TenantBaseDO + 租户拦截器） |
| 定时任务 | yudao-spring-boot-starter-job | 保存期提醒、ES 同步重试、公示到期 |
| 消息 | yudao-spring-boot-starter-mq | 公开同步、备案推送、订阅通知（异步解耦） |
| 数据权限 | yudao-spring-boot-starter-biz-data-permission | 监管系统按 region_code 的辖区数据权限 |
| 校验/测试 | yudao-spring-boot-starter-test、validation | 单元与接口校验 |

## 四、ES 落点（框架内自包含）

现有框架无 ES starter（仅 AI 模块私有使用），因此 ES 能力全部收敛在 yudao-module-bidding-es 新模块内：引入 ES 客户端依赖、实现 04 文件的同步服务与索引管理，对外只暴露"公开同步接口"给大厅检索模块。除该新模块外，任何模块不直接依赖 ES。
