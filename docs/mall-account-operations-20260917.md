## 实现

1. PC 私有路由增加 AccountPage 边界。登录代次变化时移除旧页面及表单、关闭确认弹窗，显示重新加载提示。重新加载经过原有服务端身份核验，不自动把旧表单带入新账号。认证页不包在边界内，避免注册/登录过程被自身状态变化中断。
2. useAccountOperation 将异步工作绑定页面存活状态和登录代次。正常同标签页令牌刷新不改变代次；跨标签页令牌存储变化按保守策略提示重载，不尝试猜测是否同一用户。
3. 13 个业务页面/组件的确认弹窗使用同一保护，包括商品审核、上下架、库存调整、销售发货/售后、账单确认、询价关闭/导入、地址、购物车、买家订单及售后。等待确认期间换号或页面卸载，后续命令不得继续发出。取消确认不产生未处理异常。
4. 商品主图、SKU 图、询价图片、店铺 Logo 在图片解码后、上传前及响应后检查原页面身份；营业执照 FileReader 晚回调不更新旧表单。会员头像与保存后的连续读取也增加存活检查。
5. 询价模板下载必须传入页面当前性检查，离开页面或换号后不创建下载链接；询价保存后继续提交前再次核验原操作。Blob JSON 异步解析完成后复核身份，旧下载错误不得触发新账号刷新或返回旧数据。
6. 上一轮 PC 实际 href、H5 导航/返回/分享的租户标识一起上线；没有启用新的租户名单或公共租户。

## 资源盘点及边界

| 资源 | 当前处理 | 保留的边界 / 待办 |
| --- | --- | --- |
| PC 私有 JSON / FormData | 统一 request，服务端会话证明、登录代次检查 | 后端仍必须鉴权；前端边界不是权限替代 |
| PC Excel 模板 | requestBlob + 页面当前性检查 | 只覆盖现有模板下载，不宣称新增导出已实现 |
| PC 图片上传 | 统一请求 + 解码/回调原身份检查 | 已发送的上传不能撤回；公共图片地址不是私有附件 |
| PC 企业执照 | 本地文件读取后受页面身份保护，走现有申请接口 | 不改动营业执照存储/审核权限契约 |
| PC 经营表单与弹窗 | 换号移除表单；等待中的确认不得续发命令 | 已发送的业务操作不会因离开页面自动撤销，仍以服务端状态为准 |
| H5 上传及企业资料 | 既有 prepareTenantUpload / tenantSnapshot 保护，本轮导航回归通过 | 需继续核对所有 H5 文件选择回调、页面缓存、失败处理；现有 file.js 的 JSON 解析异常及错误分支完成性应专项补测 |
| 客服消息 / 附件 | 后续独立盘点现有交付与契约 | 不把 HTTP/页面保护当成 WebSocket、坐席、私有附件隔离完成 |
| 第三方支付 / 物流 / 地图 | 保持原有预留 | 需真实配置、授权与专项验收；本轮未开通 |

T-13 仍是部分完成，不勾选全资源隔离或真实双租户交易整项。公共租户、自营企业与公开/注册名单尚待确认；现有租户 1、功能开关及账号归属不变。不创建 3000/9001 等真实测试租户。
