## 一、质变主张（为什么这是一次"质的优化"）

| 维度 | 现状（记录型） | 优化后（合规型） |
| --- | --- | --- |
| 对象 | 以"污染判定单/台账行"为中心 | 以**实物码（批次码+容器码）**为中心，一物到底 |
| 生命周期 | 4 环节判点，判完即止 | 危化品→产废→转移→处置→排放 全链可追（追溯链） |
| 门禁 | 仅领用/出库 2 处拦截，待检不冻结 | 入库冻结→复核→定区 4 步；按固有危害×污染戳两维拦截 |
| 记录 | 手填，可造假 | 电子秤/地磅**自动采集净重禁手改** + 双人签字 + 拍照 + AI 快照留痕 |
| 闭环 | 拦截无后续 | 每处拦截给后续处置/整改/升级审批，异常必有去向 |
| 合规锚 | 无 | **按证排污**（限值/总量红线/执行报告）+ **国家固废联单硬放行** + HJ1276 标签 + 应急备案 |
| 治理设施 | 无 | **同开同停**联锁；活性炭更换→废活性炭 HW49 闭环；停运申报 |
| 数据 | 各表孤岛 | **重量三平衡** + 物料总衡算，投入≈产物+危废+排放+损耗 |

> 一句话：把"环保台账"重构成"**实物码为主键、排污许可证为基准源、电子联单为法定出口**的合规链"。

## 三、总体架构与角色

### 3.1 风险管控两维（不可混用，比"三轴"更严谨）

- **维度一：物料固有危害等级 `hazard_level`**——建档时定，终身不变：NORMAL（钢材/PE料/成品管）｜CHEMICAL（黑料/白料/稀释剂/环氧粉末）。
- **维度二：批次污染状态戳 `pollution_flag`**——流转中判定、可变化：CLEAN 合格｜UNCERTAIN 待复核（冻结）｜POLLUTED 异常（隔离，走异常处置）。
- **危废不是物料维度，而是产废环节"新产生的一类对象"**（危废桶/台账），与原料批次经追溯链父子关联——不进入物料分级。

### 3.2 角色矩阵

| 角色 | 职责 | 权限 |
| --- | --- | --- |
| 库管员 | 收货/上架/发料/危废入库/巡检 | 操作单 |
| 司磅员 | 地磅/汽车衡监督、称重异常上报 | 称重监控、双签 |
| 环保员 | MSDS核对/危废类别确认/联单申报/回执/执行报告编制 | 环保操作+发起审批 |
| 设备管理员 | 治污设施运行/活性炭更换/停运申报 | 设施操作 |
| 班组长 | 投料复核/异常上报/泄漏先期处置 | 复核签字 |
| 环保主管 | 放行/处置计划/停运/月对账 | 一级审批 |
| 环保负责人 | 资质确认/联单/归档/年度备案/报告签发/应急指挥 | 二级审批 |
| 门卫 | **凭国家联单生效状态放行** | 出厂扫码核对 |
| 运输/处置单位（外部） | 国家固废系统联单确认/签收/回执 | 联单接口 |

### 3.3 全程链路总览

```
前置：资质准入 + 年度危废管理计划备案 + 排污许可台账 + 应急预预案备案
送货(黑料/白料/稀释剂/环氧粉末)
 ▼ ①收货→待检区【冻结】(AI初筛+MSDS核对)→人工复核 → CLEAN合格区/POLLUTED隔离退货/资质不符拒收
 ▼ ②在库：黑料恒温干燥专库(与白料分间)/稀释剂防爆/五双/FEFO/每日双签巡检/超量超期预警
 ▼ ③领用：扫码→放行复核(污染批无放行单拦截)→危化双人发料
 ▼ ④投料/产废：扫码投料定额核销→治污设施同开同停→电子秤自动称重→HJ1276贴签入桶
     └ 排放：在线监测实时比对【排污许可限值】→超浓度报警/总量80%黄警/100%红线锁产线
 ▼ ⑤成品判定：达标出厂/局部缺陷返工(为主)/整体报废(钢管回收,剥层经鉴别才转危废)
 ▼ ⑥危废暂存：一桶一码入暂存间(计时≤1年)+HJ1276警示标志 → 月度双签对账
 ▼ ⑦委外：处置计划→资质核验→MES联单草稿→【国家固废系统申报】→运输/接收在线确认→联单生效
     → 地磅自动称重(与桶码±2%比对)→四方会签→门卫凭生效联单放行→签收→回执归档(≥5年)
 ▼ ⑧按证排污：监测+台账+设施+应急 → envreport自动汇总→签发→按期上报
 ▼ ⑨应急联动：泄漏/超标/故障→一键应急→按MSDS分物料SOP→应急废物称重入危废→事件进报告
 ▼ ⑩追溯：扫码正向跟去向/反向查来源 → 导出报告(时间轴+衡算表+签字+联单回执)
```

## 四、详细流程（六要素：操作→校验→分支→异常→签字→结果）

### 环节0｜前置（资质准入 + 三大备案）

- 供应商危化品资质 + **黑料/白料/稀释剂 MSDS 提前上传**；处置单位经营许可证（核准类别须覆盖 HW49/HW06/HW12/HW08）、运输单位道路运输许可证。
- 年度危废管理计划填报备案（五类危废种类数量流向）；排污许可台账录入；应急预案备案（§八）。
- 校验：无 MSDS 的危化品不下采购单；许可证/资质到期前 30 天预警，过期移出可选名单；年度计划未备案→处置流程不可发起。
- 签字：环保员录入 → 环保负责人审核。

### 环节1｜采购到货 → 待检 → 入库（分两步，修"一步到位无复核"漏洞）

1. **收货**（库管员）：扫送货单核采购订单；逐批扫码、填实收、拍照；危化品核运输资质；**黑料桶受潮变形/稀释剂桶渗漏**重点检查；短缺/破损填差异。
2. **入待检区冻结**：绑定待检库位，生成批次码/追溯码，状态=待检（冻结，写 `material_stock.frozen`）。触发 AI 初筛：CLEAN 且非危化→待确认转合格区；POLLUTED/UNCERTAIN→保持冻结推环保员。危化品 PDA 强制核对 MSDS。
3. **人工复核**（环保员）：
   | 结果 | 去向 | 后续 |
   | --- | --- | --- |
   | CLEAN | 合格区上架（危化品按专库库位） | 批次戳=CLEAN |
   | POLLUTED | 隔离区 | 挂红牌，等处置决策（退货/降级/无害化/转危废） |
   | 资质不符 | 拒收退货 | 退货单；危化退货车同样核危货资质 |
   | 破损/渗漏/争议 | 让步接收（环保主管签）或索赔 | 渗漏物按应急收集 |
4. 签字三方：送货人+库管员+环保员。结果一个事务：待检单→入库/退货单 + 污染判定① + **追溯链节点①** + 打印批次二维码。

### 环节2｜在库日常

- 上架校验库位（**黑料与白料禁同区、稀释剂必进防爆区、污染品进隔离区**）；每日巡检双签打卡（温湿度/异味/泄漏/标签破损拍照上报）；危化品存取双人双锁留痕；月度盘点。
- **危废月度硬平衡：期初结存 + 本期产废净重 − 本期转移净重 = 期末结存（在桶秤采），差>±2% 冻结月结**。
- 效期 FEFO 出库，过期自动冻结禁止领用。

### 环节3｜生产领用（判定②放行复核）

- 领用/发料：扫码工单+批次，按 BOM 定额发料，超领说明；余料退库（黑料余料确认未受潮）。
- 校验：待检/冻结→拦截；**POLLUTED 且无放行单→硬拦截**（放行审批：环保员申请→环保主管批，降级限定工单范围）；危化超定额预警+主管签；退料被污染→转隔离区。
- 签字：领用人+发料库管员（双人）+环保主管（污染批）。追溯链②。

### 环节4｜投料 / 产废（判定③，重量从这开始"真"）

- **4-1 危化投料**：扫码投料（PDA 显示 MSDS 防护要点）→登记实际量关联工单→班组长复核。作业前校验对应治污设施在运行（见 §七）。
- **4-2 治污设施同步**：生产时段内设施必须有运行信号；故障停机→生产停机+报警。
- **4-3 产废六类触发入口 + 场景锁 HW**（**统一出口=电子秤称重建档，入口分布在业务动作**，不登记则动作不得闭环）：
  | 危废 | 触发场景 | 登记入口 | HW |
  | --- | --- | --- | --- |
  | 废包装桶 | 危化投料领用、桶内物料用尽当班 | 领用/投料单确认"空桶产生" | HW49 900-041-49 |
  | 废有机溶剂 | 喷枪/调漆设备清洗完成 | 清洗作业记录 | HW06 900-402-06 |
  | 漆渣(含废漆雾过滤棉) | 捞渣/过滤棉更换 | 记录→称重建档 | HW12 900-252-12 |
  | 废机油 | 设备维保换油完成 | 维修单联动（不登记不能完工） | HW08 900-249-08 |
  | 废活性炭 | 设施换炭作业票完成 | 换炭单联动 | HW49 900-039-49 |
  | 应急废物 | 泄漏应急处置收集完成 | 应急事件单联动 | 按场景 HW49/HW06/HW08 |
  | 过期/变质危化品 | 效期冻结/巡检失效 | 冻结单→主管批准转危废 | 按原 HW |
  - 空桶当班收集至危废暂存间/专用区（加盖防托盘围堰），交接双签。废包装桶由原供应商回收用于原始用途且台账完整的，按豁免清单管理（留存协议与转运凭证），否则一律 HW49 委外。
- **4-4 称重防篡改**（防造假核心）：
  - **产废电子秤直连 PDA**：防爆电子秤/台秤蓝牙直读毛重皮重，**净重系统计算写入，手工录入入口关闭**；记录含设备编号、时间戳；离线缓存恢复上传；液态废称桶扣容器档案皮重，逐次累加。
  - 人工改类需环保员授权+理由。
- **4-5 排放联动**：在线监测实时比对许可限值（§六）。
- **4-6 HJ1276 标签**：容器标签系统按规范生成——**二维码即桶码**（扫码调台账/MSDS）+ 危险特性警示图形 + 名称/类别/代码/形态/包装/产生日期/重量/产生单位/联系人；标签破损扫码补打留痕；**无标签禁止移位、禁止出厂**。
- **物料衡算（两级）**：
  - 第一级**危废重量硬平衡**（可逐斤核对，见环节2）+ **产废-投料系数平衡**（稀释剂领用≈VOCs折算+HW06+HW12夹带+残液；活性炭装填量×更换次数≈废活性炭量；换油量≈废机油量；投料桶数×皮重/残液系数≈空桶数）。
  - 第二级**物料总衡算（趋势核查）**：黑料+白料绝大比例进成品发泡层；稀释剂约X%挥发VOCs+Y%成HW06/HW12；环氧粉末=上粉进涂层+回收粉回用+除尘灰(一般固废)。废气年排放量=Σ(监测浓度×标干风量×运行h)×10⁻⁹吨；超阈值预警核查（不直接判违规，书面说明）。
- 结果一个事务：危化库存扣减+台账=已产生待入库（秤采净重）+容器码/HJ标签+追溯链③（原料批→产线→危废桶父子，废活性炭可溯到换炭单）+衡算异常单。

### 环节5｜成品达标（判定④）

| 结果 | 流向 |
| --- | --- |
| 达标 | 成品库入库出厂，批次戳=CLEAN |
| 局部缺陷（检漏点/厚度不足/碰伤） | **返工为主**：返修补口/重新发泡，返工回路入追溯链，返工后复检；返工废涂层/废泡沫按鉴别分类 |
| 整体报废（管体废） | 钢管**回收利用**（返切/回炉/降级）；剥离的废防腐层/废泡沫**经鉴别具危险特性才转危废**，不默认危废 |
| 待复检 | 冻结待复检 |

签字：检测人+质检/环保员复核；报废判定→环保主管审批（附鉴别依据）。追溯链 FINISHED_PRODUCT（含返工回路）。

### 环节6｜危废入暂存

- 扫桶码+暂存库位绑定；确认分区（**液态 HW06/HW08 进围堰托盘区，固态 HW49/HW12 分垛**）；入库计时（≤1年，延期须报批，系统给申请入口）；月末盘点对账双签。
- 校验：混放报警；入库桶净重汇总自动与车间产废秤采核对。
- 暂存间按 GB18597-2023 "四防"（防风防雨防晒防渗漏），警示标志+信息公开栏。

### 环节7｜委外处置（内部五步 + 国家联单硬对齐）

1. **处置计划**（内部）：扫码勾桶填处置方式与数量 → 环保员申报 → 环保主管批准（未批准不得联系外单位）。
2. **资质核验**：自动校验许可证有效 + **核准类别逐项覆盖本次废物**（仅持 HW08 资质不可收 HW06→拦截）→ 环保负责人确认。
3. **国家固废系统电子联单**（法定流程，内部审批是申报前置）：
   ```
   ① MES 按勾选桶码自动生成联单草稿(名称/HW/重量=秤采净重汇总/形态/包装/运输/接收/车辆)
   ② 环保员登录【全国/省固废系统】创建电子联单，数据与草稿逐项一致（具备接口条件时 MES 直推）
   ③ 将国家系统联单号回填 MES，与内部处置单、桶码绑定
   ④ 运输单位在线确认 → ⑤ 接收单位在线确认 → 三方齐 = 联单【已生效】，才可启运
   ※ 时限硬控：未申报/未生效联单不得出厂；批准后超期未申报自动催办
   ```
4. **启运出厂（防作弊称重 + 四方会签 + 门卫硬放行）**：逐桶扫码核对桶码↔联单明细（少/多/错桶报警）；**汽车衡自动称重**：车牌识别+视频抓拍+红外防作弊，毛重皮重自动采集净重自动回写，**地磅属强制检定器具须定期检定存档**，司磅员+押运司机双签，手改入口关闭（异常补录需主管授权留痕）；**地磅净重 ≈ Σ桶码废物净重+Σ容器自重，偏差>±2% 拦截核查**；**门卫扫车牌/联单码硬校验：联单号存在+已生效+四方签字齐，缺一不放行**；四方电子签字=移交环保员+押运司机+接收经手人+门卫。追溯链④（国家联单号/车牌/地磅净重/去向/四方签字）。
5. **到达签收与回执**：接收单位国家系统核对签收（不符按规定时限异议，MES 预警）；处置完成回传盖章回执，与联单自动比对（重量/方式不符退回）；环保负责人归档。台账=已闭环，追溯链⑤，档案归档≥5年。

### 环节8｜执行报告与追溯

- **执行报告**：按许可证载频次自动建季报/年报任务（提前15天催办），自动取数（在线监测小时日均值+超标时段、危废台账+国家联单、设施运行/停运/换炭、应急事件）→ 环保员核对 → 负责人签发 → 上报回执归档；逾期未报升级并锁定相关审批。
- **追溯查询**：正向跟去向（原料批→库区→工单→投料→成品/危废桶→联单号→处置单位→回执）、反向查来源（危废桶→产线→原料批→供应商；废活性炭桶→治理设施换炭单）；节点含签字人/时间/单据/状态；报告含时间轴+衡算表+签字+整改+应急。

## 六、按证排污（排污合规主线）

> 排污许可证 = 全厂环保数据**基准源**：限值取自证、监测对着证、总量卡在证、报告照着证。

1. **许可主数据**【空壳表落地】：证号/管理类别（重点=季报+年报，简化=年报）/有效期5年届满60天预警；逐排放口维护废气（**DA001 涂装：非甲烷总烃 VOCs、颗粒物；DA002 抛丸：颗粒物**）许可浓度限值与年排放总量；试压废水循环回用零外排、生活污水纳管登记 COD/氨氮；厂界噪声。证载变更先办变更留档；逾期未延续锁定作业。
2. **监测按限值比对**【空壳表落地 + 新建采集】：数据入库自动匹配该口许可限值 → 浓度超标实时报警推应急、关联工单与设施运行（可追溯产线/批次/当时设施是否运行）、严重时限产停线；**年累计达许可总量 80% 黄警**（口径=自然年Σ监测浓度×标干风量×时长，次年1/1重置）、**达 100% 红线锁定新增作业**，负责人决策停限产或申请总量变更。
3. **执行报告自动汇总**【空壳表落地】：到期自动建任务，草稿自动取数汇总，签发上报回执归档；逾期升级锁定审批。
4. **自行监测与信息公开**：按 HJ819 制定方案（在线+委托第三方定期手工：有组织 VOCs/颗粒物、厂界无组织、废水、噪声），报告传 envreport，超标自动入异常；排放口设采样平台/标志牌与证号一致；废水三级沉淀循环回用、生活污水化粪池纳管；噪声减振消声隔声、GB12348 监测；信息按证载平台公开；台账按证载年限保存（危废≥5年）。

## 七、治污设施运行管控（同开同停）

1. **台账**（挂 `mes_dv_machinery` 扩展，✅设备模块真可复用）：VOCs 治理=干式过滤+活性炭吸附脱附+催化燃烧(CO/RCO)，关联涂装线；布袋除尘器关联抛丸机；登记活性炭装填量/更换周期（运行时长+压差双条件）、滤袋规格数量；绑定排放口 DA001/DA002。
2. **同开同停**：生产设备开机信号先于/同步设施，设施未运行→对应工单禁止开工（PDA 扫码即校验）；运行监控按时间轴比对（作业时段内须有设施运行信号，停机累计超10分钟且无批准停运单→立即报警按异常排放处理，该时段产量/监测自动入执行报告）。
3. **停运申报**：检修/换耗材需停运→设备管理员提前申报（原因/起止/期间生产安排）→环保主管批；突发故障→1小时内补报+生产同步停机。记录自动入报告。
4. **活性炭更换闭环**（废活性炭=HW49 900-039-49）：按运行时长+压差预警 → 换炭作业票（停运申报联动）→ 旧炭卸出**电子秤自动称重双人** → 系统直接生成危废桶码+锁 HW49+打 HJ1276 标签入暂存 → 新炭装填（批号/装填量/碘值）。**技术指标：颗粒活性炭碘值≥800mg/g（HJ2026，新炭附检测报告）、吸附段<40℃、前置干式过滤防穿透、更换周期原则上≤3个月双条件预警**；CO 催化床温度异常报警，贵金属催化剂到期原厂回收再生（留凭证）；滤袋更换/燃料电耗登记；更换/停运/运行时长自动进报告取数。

## 八、应急管理

1. **预案备案**：综合+专项+现场处置方案编制发布后按规定时限（发布20工作日内）报生态环境部门备案，登记备案号+附件；每3年或工艺/物料/法规变化评估修订；处置卡（黑料/稀释剂/废机油泄漏、设施故障、超标）随 MSDS 同步 PDA。
2. **物资与演练**：物资台账（干沙/吸油毡/防化服/防毒面具/防爆工具/围堰沙袋/洗眼器/干粉灭火器）定点存放临期预警；**每年至少1次演练**：计划→记录(照片视频签到)→评估→整改闭环，入执行报告。
3. **泄漏 SOP**（PDA 扫码即看）：黑料泄漏=防毒面具+化学防护服+通风禁明火+**干沙/惰性吸附收集严禁水冲**（遇水放热放气）+专用清洗剂，吸附物密封 HW49；稀释剂=断火源防静电沙土围堵；废机油=吸油毡禁入雨水沟。
4. **事件闭环**：PDA 一键上报→应急任务派发→处置拍照→**应急废物一律过秤贴签入危废台账（应急不绕过管控）**→事件报告（原因/数量/处置/危废桶码/整改）负责人签字→入当期执行报告。

## 九、异常总则 + 状态机 + 签字规则

**预警升级**：一般预警→超时催办→升主管→仍不处理锁定单据。

| 异常 | 系统动作 | 处理路径 | 签字 |
| --- | --- | --- | --- |
| 无 MSDS/资质不符 | 拒收 | 退货+门卫核对 | 环保员 |
| 复核 POLLUTED | 冻结隔离 | 退货/降级放行/无害化/转危废 | 环保主管 |
| 破损渗漏争议 | 差异记录 | 渗漏物按应急收集/让步/索赔 | 主管(让步) |
| 领用污染批 | 拦截 | 放行审批/退料/转处置 | 环保主管 |
| 超定额/衡算偏差 | 预警 | 核查单查原因 | 环保主管 |
| 危废错类/未贴签 | 禁提交/移位 | 纠正、补打留痕 | 环保员 |
| **超许可限值** | 报警+应急+关联工单设施 | 排查设施/限产停线 | 环保负责人 |
| **总量 80%/100%** | 黄警/**红线锁产线** | 减排排查/停限产/申请变更 | 环保负责人 |
| **设施未同步运行** | 开工拦截/运行报警 | 开机或停机按异常排放 | 环保主管 |
| **停运未申报** | 报警锁定 | 补报+生产同步停 | 环保主管 |
| **活性炭到期未换** | 预警升级 | 停机更换旧炭转 HW49 | 环保主管 |
| 称重离线/超差 | 冻结、出厂拦截 | 校验；补录主管授权留痕 | 环保主管 |
| **国家联单未申报/未生效** | 门卫硬拦 | 完成固废系统申报+三方确认 | 环保负责人 |
| MES 与国家系统数据不符 | 暂停闭环 | 差异核查更正 | 环保负责人 |
| 处置资质不符/过期 | 拦截 | 换合格单位 | 环保负责人 |
| 回执不符 | 退回核查 | 差异核查 | 环保负责人 |
| 泄漏/突发环境事件 | 启动预案一键派单 | SOP处置+废物建档+事件报告 | 环保负责人 |
| 执行报告逾期 | 催办升级锁定审批 | 立即编制上报 | 环保负责人 |
| 巡检异常 | 整改单 | 整改复核关闭 | 环保员 |

**状态机**（强制串行）：
```
批次：待检(冻结)→在库→领用(冻结/放行)→已耗用 ；隔离(污染)→退货/降级/无害化/转危废 ；过期冻结→转危废
危废：已产生(秤采+贴签)→暂存中(≤1年)→计划批准→单位核准→国家联单已申报→已生效(三方)→已转移(在途,地磅+四方会签)→已签收→已闭环(回执归档)
设施：运行⇄停运(已申报)；故障→应急停机(补报)；活性炭：正常→临期预警→更换中(旧炭转HW49)→已恢复
应急：上报→处置中(废物建档)→待报告→闭环 ；执行报告：待生成→草稿(自动取数)→待签发→已上报
单据：草稿→待审批→已批准/驳回→执行中→完成/关闭(整改)
```

**签字规则**：操作人+复核人每环节必签（双人制）；放行/让步/报废/处置计划/资质/联单/归档/年度备案/停运/报告签发/应急=环保主管(一级)/负责人(二级)；危废出厂=四方会签（移交环保员+押运司机+接收经手人+门卫）；外部确认=运输/处置单位国家系统在线。落地：账号即签名（人/时间/GPS）+关键节点 PDA 手写板；签字表**只增不改不删**，与操作日志/称重/IoT 多向印证。
