# WMS 角色菜单审批权限（2026-09-12）

## 管理员如何配置

系统管理 → 角色管理 → 对应角色 → 更多 → 菜单权限 → WMS系统。分别按职责勾选：

| 菜单位置 | 权限名称 | 权限键 | 本机菜单ID |
|---|---|---|---|
| 入库管理 | 入库单提交审批 | wms:receipt-order:submit-approval | 6740 |
| 入库管理 | 入库单仓库审批 | wms:receipt-order:approve-warehouse | 6741 |
| 出库管理 | 出库单提交审批 | wms:shipment-order:submit-approval | 6737 |
| 出库管理 | 出库单仓库审批 | wms:shipment-order:approve-supervisor | 6738 |

提交权限用于发起流程，仓库审批权限决定新任务候选人；还需相应单据查询与BPM待办页面、处理权限。角色名称不限。给启用用户赋予该角色后，重新登录，再发起新审批验证。当前宋凯80168的60096角色已配置两类仓库审批权限。

流程依次为：来源ERP/MES内部审批 → WMS草稿 → 验收/出库确认 → 仓库负责人审批 → 库存执行。采购/销售内部审批不在WMS重复建立。审批前库存不变化；入库只增加合格量，出库最终校验库存不足。

## 实现与限制

- 新BPM候选表达式由WMS专用 `wmsApprovalCandidates` 解析当前租户中明确获得对应菜单权限的角色用户。校验用户、角色、菜单、租户和套餐启用；套餐必须包含对应权限。不依赖角色名称、固定角色ID或固定用户ID，不将超级管理员通配权限隐式转为审批资格。
- 同一用户有多个合格角色时去重。采用或签，任意一个候选人通过即可，其余该节点待办结束；无候选人拒绝，关闭自动审批。
- 候选人在任务生成时确定。后续授予或取消角色/权限不会自动改派、撤销历史任务，应使用新单测试；历史待办需要管理员按既有流程另行处置。
- 当前两仓不区分审批人员范围，有入库/出库对应权限就能参与本租户该方向的新审批。未新增按仓库负责人字段分配。
- 旧“出库单上层决策审批”（6739）保留原菜单与授权，当前WMS模型不使用它；也不增加第二级审批。
