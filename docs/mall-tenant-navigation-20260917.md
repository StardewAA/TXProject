## 已完成

1. 新增 PC MallLink 公共组件，替换 29 个页面/组件里的 RouterLink。商品、店铺和私有页面链接的真实 href 在渲染时携带 tenantId，复制地址、右键新标签打开不再只依赖旧标签页 sessionStorage。
2. 原商城租户 1 也显式携带归属，防止其链接被收件人此前保存的外租户入口误解释。目标账号令牌隔离和后端目录核验保持不变。
3. PC 路由守卫在页面业务加载前校验租户别名/重复参数；冲突链接进入不可用提示，不把其他租户同编号资源改成当前租户资源。正常路由、过滤条件和锚点保留。
4. PC 登录后返回路径复用同一校验；站外、协议相对、非法或外租户订单返回地址改为当前商城会员中心，不跳到错误订单。
5. H5 统一拦截 navigateTo/redirectTo/reLaunch/switchTab；普通页面跳转附带当前租户，底部导航按框架要求不直接传查询串，在成功后给浏览器地址补归属；返回/页面显示继续校验和补写。
6. H5 公共 router 在底部导航丢弃 query 前检查矛盾租户；拦截失败有提示，并完成 fail/complete 回调。站外外链不附加租户或认证数据。
7. H5 分享链接、页面路径与转发路径使用相同的公开商品/页面参数和显式租户，兼容地址已有查询参数及 hash 路由；不复制配置地址中的令牌、登录 code 或 redirect 等查询数据。
8. H5 会员资料尚未加载时使用匿名分享者编号，不生成 undefined 分享参数；复制链接的分享来源取正确的 fromMap。
9. PC/H5 纯链接校验核心相同；保留 URL 只是提示、后端目录和账号鉴权才是权限的边界，不因客户端链接而放行目标租户。

外部支付/地图/客服连接和私有附件不由此链接组件授权；本批不表示这些能力已接通或完整验收。原生 App/小程序导航拦截未启用，本批验收范围为 PC 和浏览器 H5。
