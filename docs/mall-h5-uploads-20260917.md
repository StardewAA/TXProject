# H5 上传与会话回调隔离实施记录（2026-09-17）

## 本轮完成

接续方案 3.5 的资源隔离子项，保留此前未提交改动。本轮改动仅 H5 商城和文档；无 PC/后台/后端/ERP/WMS 源码变更、无数据库迁移或 SQL 执行。未使用真实账号验证码，未查看远程，尚未提交。

- 上传接口采用可测试的统一封装：成功只接受有效 HTTP 状态和 code=0 的非空文件地址；业务拒绝、异常 JSON、网络失败、同步异常、缺失回调及超时都结束 Promise，不再卡在上传中。60 秒网络超时，65 秒兜底；重复回调只处理一次。
- 并发上传计数管理上传提示。账号变化时终止旧上传任务，移除监听/计时器；终止客户端请求不代表撤销服务端已经接收的文件。
- 选文件、异步选择回调、读取二进制、S3 PUT、文件登记、服务器逐文件上传均检查原账号及页面当前性。直传仍使用现有预签名机制，不额外把会员令牌发给存储服务。
- 公共上传组件、云上传重试队列和延迟文件地址回填增加组件身份保护。云上传路径只做生命周期防护，不宣称已验证真实 uniCloud 权限。
- 个人资料页和客服页增加任务生命周期保护。换号后个人信息/草稿和聊天区域不再展示；等待选图、上传、确认解绑及发送的旧回调不得继续操作。页面隐藏使已捕获的任务失效，返回同账号后可开始新任务。
- 微信授权头像调用兼容新的上传失败语义；本轮只验证 H5，未进行微信真机验收。
- 旧客服 WebSocket 在换号/卸载时关闭并清理重连/心跳，旧连接消息不再回填；非原租户实时连接继续保持禁止，未启用多租户店铺客服。
- 浏览器补测发现并修复：图片组件旧地址加载失败后，新头像地址仍不显示。现在 src 改变会重置失败状态，失败后重试上传可正常预览。

按 find-docs 技能核对 uni-app 官方上传回调、HTTP 状态、超时与 UploadTask.abort；Context7 已知额度不足，使用官方资料 https://uniapp.dcloud.net.cn/api/request/network-file.html 。未升级依赖。
