# WMS 来源价格补充契约

适用现有 ERP 采购入库、销售出库、MES 完工入库、领料出库申请接口。申请地址、鉴权、租户、幂等及仓库审批要求沿用 `wms-erp-mes-interface-handoff-20260912.md`。

## 申请明细

新增可选 `items[].price`（人民币元单价）及 `items[].totalPrice`（人民币元行金额）。采用现有 WMS 单价/金额字段，不修改商品档案成本价、销售价，不新增库存计价模型。

```json
{"requiredQuantity":10,"price":12.50,"totalPrice":125.00}
```

- 未传单价和金额表示未提供价格，兼容已有接口使用方；与明确传入零元不同。
- 传单价时，金额可省略，由 WMS 按申请数量乘单价、四舍五入两位计算。
- 传金额必须同时传单价，金额必须与上述计算一致。折扣和税费应由来源系统折算为约定行单价后传入；本次没有扩展税额、币种或折扣模型。
- 单价及金额非负、最多两位小数、整数部分最多14位，超限或不一致采用现有申请参数错误返回；修改请求后按现有重试/幂等契约处理。
- 原始来源单价、金额保留在明细来源快照，计算出的金额写入 WMS 原有明细字段。WMS 仓库验收及出库确认不修改来源价格。已有无价格单据不自动补价。
- 来源金额表示申请数量金额；入库库存执行仍只按合格数量执行，未将来源金额当作本次全部实际入库金额。
- MES 的生产计价责任和时点待 MES 小组确认；支持约定后的金额传递，不代表 MES 已实现该契约。

## 模拟入口

入库、出库管理的“模拟 ERP/MES 申请”新增来源单价输入，金额预览随申请数量计算。模拟请求 `details[].price` 由 WMS 转换为相同外部申请明细，再生成真实 WMS 草稿。不会自动采用 SKU 档案价格，不发送真实 ERP/MES 通知。

## BPM 导航

出库详情与入库一致：当前路由已是同一流程实例时显示“当前已在本单 BPM 审批页”；从只读单据详情弹窗跳转审批页后关闭弹窗。与从“待办任务”还是“我的流程”进入无关。
