仅修改商城 member、PC、H5 及文档。未查看远程、未提交、未推送；未修改数据库、公共租户名单、运行配置或 Docker 镜像，未创建真实账号/验证码/会话。

**本批是独立浏览预览，不是主商城全上下文切换，也不是跨租户购物完成。** 原商城始终保留租户 1 入口；浏览其他商城不改当前账号租户、不清除原令牌、不把目标商品加入原购物车。新页面无注册、登录、加购、询价、支付、订单、上传或客服入口。

## 实现与约束

- 新增服务端 `mall.tenant.browse-preview-enabled` 配置，源码默认 false。仅总目录开启且公共租户与明确公开名单经过既有状态校验后，目录响应 `capabilities.browsePreview` 才能为 true。
- 现有 `browseSwitch`、`registrationSelection` 仍固定 false；新开关只描述独立匿名浏览，不表示目标账号认证/交易可用。未修改任何运行时配置。
- PC 原商城顶部增加按能力隐藏的“浏览其他商城”；独立路由 `/markets/:marketId?`，不复用带采购/销售/会员操作的布局。
- H5 首页增加按能力隐藏的浏览入口；独立页面 `/pages/market/index`，无原个人中心或购物车内容。选择仅保留在当前页面，不写全局租户缓存；本轮未增加 H5 跨租户商品分享链接。
- 无指定目标时浏览服务端目录明确配置的公共商城；未知目标报错，不回落租户 1 或任意其他商城。未初始化公共租户，不硬编码生产公共 ID。
- 独立 fetch 通道不读取令牌、不经过登录/刷新拦截器；目录请求不带租户，目标商品请求仅带所选租户及终端等公开请求头，credentials=omit、cache=no-store、redirect=error。
- 通道只允许 GET 到明确列出的店铺列表、分类列表、商品分页、商品详情四个路径；调用方不能传任意 URL、请求方法、Authorization 或 tenant-id 覆盖。
- 每次目标数据查询前重新核验公开目录。关闭、停用或移出名单时阻止本通道后续请求，不使用缓存目录继续查；数据查询仍由原商品服务租户拦截与可售审核逻辑控制。
- 上述客户端限制不是新的服务器权限边界。原商品公开接口的全局发布策略、直接 API 调用和完整多租户访问控制仍需后续专项验收，不能宣称只靠页面白名单完成系统级隔离。
- 商品详情继续复用既有公开详情接口：不改变库存、订单或客户关系，但既有接口会统计商品浏览次数。本轮浏览器全部拦截 API，没有调用真实详情或写浏览统计。
- 切换同步清除旧商品、筛选、详情和页码；递增请求版本，A→B→A、慢搜索、关闭详情、离页/隐藏后的旧响应不会回填。
- 无商品显示明确空态，失败显示错误与重试；未知价格不当成 0，详情校验 ID，异常列表记录/SKU 不进入渲染。展示名称/简介采用文本插值，不渲染服务端 HTML。
- H5 选择器改为保留实例并控制显示，避免确认选择过程中卸载控件引起 remove 异常。H5 页面隐藏/卸载终止本页结果接收，重新显示重新加载。
