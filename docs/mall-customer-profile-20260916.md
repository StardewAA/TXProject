## 已实现

- 新增 `GET /app-api/member/mall-tenant/customer-affiliation`，无 memberId/enterpriseId 入参。会员 ID 只取可信登录上下文，拒绝匿名、管理员、非正数身份、错误/缺失租户以及忽略租户隔离的请求。
- 普通无锁只读查询：显式按当前 tenant_id、member_id 和 deleted=false 过滤，保留现有租户拦截器；不复用注册的 FOR UPDATE 查询。不写客户关系，不授予企业/店铺权限。
- 使用已保存的 service_enterprise_id 查询 product 内部最小投影，不按最新平台企业配置改绑历史客户。缺失或删除的关系返回 NONE，不给存量账号自动补绑定。
- 返回仅包含 state 和 serviceEnterpriseName。企业不属于当前租户、企业 ID 不符、已删除/不存在或审核未通过时，不暴露名称。
- 企业 RPC 失败与企业失效分开，避免网络故障被误解为资质撤销。数据库失败仍为请求错误，不能伪装成“没有归属”。
- 关闭新认证或租户功能时返回 DISABLED，不访问新增关系表和企业 RPC。
- PC 会员中心、H5“我的”（包含装修模式和默认模式）接入归属卡片。只显示客户服务企业，明确“不代表企业认证、员工身份或采购／销售权限”。错误/失效可重新查询。
- 请求携带当前账号上下文；退出、切换账号/租户、重复重试、离开页面会丢弃旧响应。重试先清除旧企业名称，组件本地保存状态，不写 localStorage/持久化用户资料。
- 不修改既有企业认证、采购、销售权限判断，不提供重绑、删除关系或自助选择服务企业的接口。

## 响应状态约定

| state | 含义与展示 |
| --- | --- |
| DISABLED | 当前功能关闭，双端隐藏卡片 |
| NONE | 本人当前租户下没有有效关系，提示尚未关联 |
| ACTIVE | 返回当前有效服务企业名称 |
| OWNER_UNAVAILABLE | 原服务企业当前不可用，提示未自动改绑，不返回企业名称 |
| TEMPORARILY_UNAVAILABLE | 企业查询故障/异常响应，提示重试，不判断资质撤销 |

状态仅在加载/重新查询时更新；本批没有新增后台轮询、资质撤销事件推送或经营权限补偿。
