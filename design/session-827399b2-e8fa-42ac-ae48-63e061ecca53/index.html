01 · 查询区结构（行式属性 · 动漫门户式）

查询区（自上而下）

区块规则
① 关键词水平居中，= title 前缀（无全文，ES 二期）
② 属性查询区关键词正下方、整行铺开；每属性一行：属性名左对齐（如 公告性质 / 来源站 / 内容形态 / 行业 / 时间），右侧为该属性文字可选值（点击即筛，可多态切换）
③ 时间行只给快捷区间（全部 / 近7天 / 近1个月 / 近3个月 / 今年以来）；确有精确需求时点行尾“自定义”，才展开起止日期两输入框
④ 目录区选中条件后展示公告目录（对接文档 03 行结构 + 分页）

可选值行的交互规则

  • 行首“全部/不限”为默认选中；点击其它值即筛选（单选即可，可再点“全部”还原）
  • 值多放不下时该行横向可拖动（鼠标按住左右拖）查看更多
  • 不使用下拉框（点选即筛，减少操作）；选中项高亮深蓝底
  • “自定义”为虚线样式入口，展开后提供精确起止日期输入
