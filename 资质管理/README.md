## 二、版本与出处关系（重要）

1. **v2 → v3 数据字典**：v3 在 v2 基础上补齐 7 张子表完整字段、索引/约束/分区、L1-L4 安全分级、幂等/乐观锁/哈希链、HA 方案（v3 内附《v2→v3升级对照》与《瘦身对照说明》工作表）；**主表 certificate_info 43 字段两版一致**。
2. **DB 设计 md 与 xlsx v3**：同一版本的两份视图——整体设计以 md 为准（12+1 核心表 + 企业资质八表全景、自查流程、索引、安全基线）；字段级定义以 xlsx v3 为准；两者如有出入，以 md 为准并回改字典。
3. **docx 出处**：《一体化政务服务平台 电子证照 建设工程企业资质证书》电子证照标准，由住房城乡建设部办公厅以 **建办市〔2024〕51号**（2024-10-25 印发）通知印发，公开于中国政府网：
   https://www.gov.cn/zhengce/zhengceku/202411/content_6985130.htm
   本目录 docx 即该通知**附件1 原文**（标准正文无独立标准号，引用时以"建办市〔2024〕51号附件1"标注）。
4. ~~证书台账_数据字典v2.csv~~：损坏/残缺导出物（第 7~43 行为重复 `tenant_id`），有效内容已被 v2/v3 覆盖，**经确认已于 2026-09-02 删除**；
5. **v3.1 修订（2026-09-02，采纳 03 文档建议）**：主表新增第 44 字段 `e_cert_ident`（电子证照标识）、新增 `cert_item` 证照专业/等级明细子表、固化证照状态口径——同步反映在 DB 设计 md、v3 字典 xlsx 与 03 映射文档。
