## 二、资质许可法规与标准（14-2 资质标准库、达标核查依据）

| 文件 | 用途 | 备注 |
|---|---|---|
| 《建筑法》（1997 通过，2011/2019 修正） | 资质取得、不得越级承揽 | 基础法律 |
| 《建筑业企业资质管理规定》（住建部令第22号；2016年第32号、2018年第45号修正） | 施工资质序列/类别/等级框架 | docx 参考文献已列 |
| 《建设工程勘察设计资质管理规定》（建设部令第160号及历次修正） | 勘察/设计资质框架 | 同上 |
| 《工程监理企业资质管理规定》（建设部令第158号及历次修正） | 监理资质框架 | 同上 |
| 《建筑业企业资质标准》（建市〔2014〕159号） | **资质类别/等级划分、人员/业绩/资产/装备达标指标**；DB 设计 `qualification_standard` 的 std_version 初始值、"国标表110 资质等级 / 表111 资质类型"编码来源 | ⚠️ 改革过渡期，见下 |
| 《安全生产许可证条例》（国务院令第397号） | 14-8 安全生产许可证字段口径 | 现行 |
| 《注册建造师管理规定》（建设部令第153号）等执业注册人员规定 | 14-3 注册人员核查（注册专业/有效期） | 现行 |
| ⚠️ 资质改革动态：国发〔2021〕7号"证照分离"改革以来，资质类别压减/合并、过渡期有效期多次统一延期，**新版《资质标准》尚未全面落地** | 做"资质类别/等级标准库"时**不得静态固化** | 以住建部官网"建设工程企业资质行政审批"专栏现行发布为准；DB 已按 std_version 版本化设计，实现期直接读库换版 |

## 三、核验渠道（verification_status / official_verify_url / 验真设计依据）

| 渠道 | 说明 | 出处 |
|---|---|---|
| 全国建筑市场监管公共服务平台（四库一平台）`jzsc.mohurd.gov.cn` | 证书底账查询（docx 照面"查询网址"即此）；业绩/人员注册信息核验 | docx §7.1.1、§8.2 |
| 国家政务服务平台 / 一体化政务服务平台 · 电子证照共享服务 | 电子证照文件下载（**加注件**，不提供原件）、接口符合 GB/T 36906；持证主体可"出示代替实体证照" | docx §8.2、§8.3 |
| 照面二维码核验 | 扫码取「证照类型代码^电子证照标识^证书编号^发证机关^发证日期」→ 官方底账比对 | docx §7.1.2、§8.2(4) |
| 地方（陕西）政务/公共资源交易平台电子证照核验 | 企业资质在公共资源交易中的核验入口 | 需向陕西省住建/政务部门确认接口与授权（本项目对接陕西 V2.0 数据规范） |
