> 本字典按投标文件章节顺序编排，每个变量名对应模板中的一个 Word 书签（Bookmark），可直接在 Word 中按名检索。

## 1. 模板实现方式

模板采用 **Word 原生书签（Bookmark）** 作为变量占位机制，而不是把「{{变量}}」文本写入版面：

- 书签本身不占宽度，替换数据时不会因变量字符串长度改变表格列宽、行高或分页；打开文档时书签不可见，版式与原文件完全一致。
- 空白单元格内是**零长度书签**（`bookmarkStart` 与 `bookmarkEnd` 相邻），不含任何可见字符。
- 段落内的填空位（如「工程名称：______」「日期： 年 月 日」）由书签包住原有的空白片段，替换即写入该片段，左右文字保持不动。
- 除注入的书签节点外，`word/document.xml` 的其余部分与原文件逐字节相同，其余部件原样保留。

> 在 Word / WPS 中查看占位位置：**文件 → 选项 → 高级 → 显示文档内容 → 显示书签**，书签会显示为灰色方括号。

### 回填规则（按名回填）

- 同一个业务字段在文档中出现多次时，使用带 `_2`、`_3` 后缀的独立书签；替换程序按**基础变量名**统一回填（如填 `bidder_name` 会自动覆盖 `bidder_name_2`、`bidder_name_3` …）。
- 回填只改书签区域内的内容，不动区域外文字；带示例值的区域（「无」「长期」「合格」等）整段替换。
- 回填值的字体/字号继承书签所在位置原有格式。

## 5. 数据替换建议

建议项目系统内部使用结构化 JSON 对象维护数据，再通过书签名称映射到 Word。示例：

```json
{
  "tenderer": "…",
  "bid_no": "…",
  "section_no": "…",
  "bidder_name": "…",
  "project_name": "…",
  "bid_total_upper": "…",
  "bid_total": "…",
  "date_year": "…", "date_month": "…", "date_day": "…"
}
```

同一个业务字段在文档中出现多次时，模板中使用带 `_2`、`_3` 等后缀的独立书签；替换程序可以按基础变量名统一回填（如 `bidder_name` 自动回填 `bidder_name_2`、`bidder_name_3` …）。
